# Инженерная оценка готовности релиза

**4 ноября 2026 года: техническая приёмка остаётся открытой.** Это отдельная инженерная оценка по [политике доказательств релиза](QUALITY_AND_REPORTS.md#engineering-release-assessment). Она сохраняет полный MVP и все 67 подготовленных кейсов. Исходный аудит не создавал эксперимента или человеческой оценки. Датированное продолжение ниже описывает отдельно ограниченные наблюдения; публичного кандидата оно не создаёт. Измеренная польза для людей неизвестна.

## Метод и контекст ревью

Исполнитель аудита тикета 138 проверил исходные карты, квитанции хешей, выбранные сохранённые ответы и записи команд/чтений/записей независимо от контекстов прежних исполнителей. Предыдущие независимые ревью, указанные ниже, принимали точность артефактов либо код/механическую область; их вердикты `Ship` не являются семантическими или человеческими оценками. Независимое интеграционное ревью этой новой оценки — отдельная задача [изменения политики](../../openspec/changes/separate-release-evidence-from-usefulness-pilot/tasks.md).

Статусы относятся к указанному утверждению: **reusable-within-scope** — наблюдаемый подкритерий достаточно подтверждён для исходных входов/байтов; **insufficient** — относящиеся к нему материалы есть, но требуемое утверждение не установлено; **missing** — указанное наблюдение не найдено. Строка может повторно использовать механизм, пока решение агента остаётся insufficient или missing. Это не подсчёт принятых сквозных кейсов.

Аудит проверил существующие доказательства без повторных прогонов: 23 входа карты, 17 дополнительных входов, 43 привязки исходников runtime, 31 вход построения фикстур, 67 упорядоченных ID и 80 исходных имён успешных тестов плюс пять прежних и 13 позднейших регрессий в сохранённом gate. Двадцать из 23 входов карты побайтово совпадают; три руководства приёмки получили только датированную плашку политики. Удаление именно этой плашки воспроизводит каждый замороженный хеш, текст сценариев неизменен. Первая неудача строгой проверки хешей сохранена рядом с этим явным анализом влияния только на документацию. Пропущенные тесты не засчитаны. Все 86 путей текущего инвентаря дистрибуции совпадают с зафиксированными хешами; его 84 файла payload, кроме package, совпадают с соответствующими копиями исходников. Частная квитанция перечисляет эти пути/количества, не утверждая более широкое наблюдение runtime. Дайджесты фикстур динамически не пересчитывались; привязку дают неизменившиеся входы построения и прежняя успешная проверка matrix-lock. Частный индекс аудита сохраняет хеш фикстуры каждого кейса, точное имя/исходник/строку лога теста и хеши проверенных артефактов; публичные отчёты ниже дают очищенный контекст.
