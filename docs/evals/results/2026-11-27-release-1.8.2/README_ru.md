## Ограничения

Цикл управляется контроллером на macOS, с skills 1.7.4 и обычными правами ОС.
Восстановление использует сконструированные неполные папки и не доказывает обрыв
на каждой границе копирования. Замена/удаление скилла не обновляет инфраструктуру
проекта автоматически. Проверка секретов сохраняет заявленные ограничения ключей,
значений в кавычках и узкого текста без кавычек.

Нативная автозагрузка, общее поведение моделей, Windows-политики, человеческая и
причинная польза не проверены. [Оценка покрытия](../2026-11-27-coverage-followup-assessment/README.md)
сохраняет все прежние провалы, помощь, блокировки и незапущенное. Патч не закрывает
всю матрицу. Нового живого прогона моделей и платных API не было.
