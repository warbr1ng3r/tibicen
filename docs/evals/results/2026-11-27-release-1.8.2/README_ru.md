# Выпуск 1.8.2 — подготовка

Канонический отчёт — [README.md](README.md).

**Кандидат не опубликован.** 27 ноября 2026 владелец разрешил единым пакетом коммит,
push, CI/платформы, стабильную публикацию и метаданные сайта.

Совместимый патч закрывает выдачу/запись секретов сырого содержимого, объединяет
правила полных заполнителей/ключей с MCP, обрабатывает экранированные/повторные
JSON-токены и исправляет приоритет unsafe-path. Персистентные схемы и зависимости
сохранены. См. [оговорённую оценку](../2026-11-27-coverage-followup-assessment/README.md).

Прежний точный код прошёл 1 224 теста/ноль ошибок/два ожидаемых skip и независимое
Ponytail-ревью. Gate версии, локальный/публичный цикл, CI, шесть платформ,
ассеты и сайт **ожидаются**. Их заполняют фактические квитанции, а не прежний pass.
Идентичности исходников/поставки/тега/сумм — в [receipt.json](receipt.json).

Нативная автозагрузка, широкое поведение моделей, польза человеку и остаток
каталога этим патчем не устанавливаются. Прежние провалы/неизвестное/помощь
и неизменяемые ассеты 1.8.1 сохранены. Новые платные API не разрешены.
