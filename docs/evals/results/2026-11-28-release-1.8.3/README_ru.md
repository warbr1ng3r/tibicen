## Ограничения

Проверки установки выполнены контроллером на macOS с skills 1.7.4 и обычными правами ОС. Восстановление использует подготовленные неполные каталоги и не доказывает реальное прерывание на каждой границе копирования. Обновление или удаление скиллов не меняет настройки проекта автоматически.

[Оценка памяти](../2026-11-28-memory-guidance-assessment/README.md) поддерживает одно положительное наблюдение с помощью контроллера на побайтово той же инструкции. Нативная автозагрузка, чистота контекста, уникальная причинная роль памяти, общее поведение моделей и польза для человека не установлены. Прежние оценки [механических](../2026-11-27-mechanical-47-assessment/README.md), [агентных](../2026-11-27-agent-eight-assessment/README.md) и [дополнительных](../2026-11-28-four-agent-followup-assessment/README.md) случаев не пересмотрены. Проверка Windows относится к наблюдавшимся политикам хоста и не покрывает все корпоративные политики. Новых модельных прогонов и платных API-вызовов нет.
