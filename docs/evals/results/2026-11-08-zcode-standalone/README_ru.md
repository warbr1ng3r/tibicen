# Наблюдения самостоятельного маршрута ZCode — 8 ноября 2026

**Проверка закрыта: установленная CLI один раз запустилась, но запрос к модели и рабочий цикл Tibicen не наблюдались.** Два отдельно разрешённых запуска проверки готовности аккаунта остановились на разных границах.

Desktop 3.14.4 содержит неизменённую CLI 0.16.9. Штатный самостоятельный маршрут отделён от старого SDK-хоста; GUI не является единственным путём.

Повторов запуска со стороны оператора не было. Первый запуск отклонил правило буквального удалённого IP при компиляции политики: дефект частной подготовки до старта Node. Отдельно проверенный вариант разрешал обычный HTTPS поставщика на порту 443; изоляцию сети по конкретным хостам/IP он не подтверждает.

Затем CLI сообщила `turn.failed`, фаза `model_creation`, `CONFIGURATION_ERROR`: «Select a model before continuing». В сохранённых событиях нет `turn.started`, сводки запроса к модели и инструментов. Корректный выбор модели по умолчанию и резервный путь реестра поддерживаются; этот сбой не доказывает игнорирование модели по умолчанию.

## Обращение с данными и ограничения

При двух разрешённых операциях копирования credentials оставались непрозрачными: без значений в контексте агентов, хэширования содержимого, разбора или расшифровки. Оба временных стенда удалены. Вторая очистка удалила 556 элементов. Финальная инвентаризация остановилась на библиотеке комплектного кэша размером 16 001 776 байт, превысившей лимит проверяющего стенда 8 МиБ: последующие проверки не выполнялись, что не доказывает изменения данных. Полная финальная сохранность не проверена; метаданные исходного файла credentials независимо совпали.

Отдельное чтение только признаков наличия обнаружило пространство coding-plan, но не обязательную запись идентификации. Это исключает данный вариант аккаунта из стандартного хранилища по условию установленной программы; это не доказывает выход из Desktop, недействительность подписки или единственную причину сбоя. Значения, идентификаторы, хэши credentials и расшифрованные данные не сохранялись.

Авторизация, права подписки, тарификация и ответ модели не проверены. Вход, исправление личных настроек, API fallback, исправление продукта или смена версии не выполнялись. Опубликованная [1.5.2](../2026-11-08-release-1.5.2/README.md), [прежние рабочие счётчики](../2026-11-08-normal-workflows/README.md) и старые сбои неизменны. Эти наблюдения не добавляют покрытия Tibicen, задач с инструментами или памяти. [summary.json](summary.json) разделяет счётчики, лимиты и свидетельства.
