## Объём исправления и совместимость

Раньше при изменении одной строки предложение показывало весь файл удалённым и добавленным.
Локальный коммит `2932f67` убирает общий префикс/суффикс и показывает один общий
изменённый участок с не более чем тремя строками контекста с каждой стороны. Все изменённые
строки видны; разнесённые правки могут входить в один hunk. Исправление совместимо и не добавляет зависимостей.

Предпросмотр не нормализует согласованные байты. Полное содержимое, исходные хэши,
режимы файлов, CRLF и завершающий перенос остаются привязаны к согласию. Apply использует
полное согласованное содержимое; прежние предпросмотры всего файла сохраняют digest и совместимость.
Схемы, пресеты, writer’ы, разрешения выполнения и память проекта не изменены.
Миграция не нужна. См. [требования первого запуска](../../../../openspec/changes/validate-first-working-session/specs/agent-infrastructure-lifecycle/spec.md).

Упрощённый двуязычный лендинг выложен отдельно; его [запись о публикации](../../../../openspec/changes/simplify-first-use-landing/verification.md#publication)
не подтверждает доставку скиллов 1.4.1.

## Попытки, публичная доставка и сохранность

Исходный gate G01 сохраняет **929 успешно / один сбой / один стандартный пропуск**.
`process-skip-unexplained` завершился сбоем до запуска ветвей offline-протокола.
Задержка boundary preflight — гипотеза; точная историческая причина не доказана,
поскольку исходную preflight-квитанцию удалил cleanup теста. Отдельные наблюдения:
узкое 1/1, полный offline workflow-файл 42/42 и полный gate G02 прошли без
изменений исходников, assertions или лимитов времени. Нативная модель не запускалась.

A01 остановилась после пяти продуктовых CLI-вызовов: checker не включил точно
запланированный usage-файл собственного HOME в разрешённые эффекты. Исходный сбой сохранён.
Явно согласованная корректирующая A02 проверила новые ограниченные предпросмотры
обоих скиллов, применение полных байтов/режимов и неизменённых настоящих предложений
опубликованной 1.4.0 через 1.4.1. Исходные хэши/digest и защищённые файлы сохранены.
Четыре кейса вернули `complete`, структурные проверки прошли; продуктовая проверка
проекта осталась **`unverified` / `no-project-checks`**. Синтетические механические
токены от root — не согласие конечного пользователя; проверки приложения не запрашивались и не выполнялись.

D01 прошла universal-замену по локальному пути 1.4.0 → 1.4.1, идентичный повтор,
полное восстановление изменённых backup в настоящие папки установки и удаление.
Все 100 payload совпали; приложение, поздняя память владельца, соседние скиллы,
посторонние настройки и исходные входы сохранены. Доверенный установщик имел
ambient read capability и запись только в свои пути; OS sandbox/firewall не утверждаются. Частные квитанции сохраняют попытки, входы, выходы, составы и хэши.

P01 отдельно установила опубликованную 1.4.0 и заменила её по полному SHA реальной
публичной 1.4.1, затем повторила установку, восстановила полные изменённые backup
в настоящие пути установки и удалила их. Точные fetch/checkout/lock/payload-привязки,
оба установленных self-test и защищённые файлы прошли. Доверенные Git-процессы имели
обычные права ОС; OS-изоляция не утверждается. Полученные release notes, три файла,
101 файл/режим архива и 100 payload-сумм совпали; прежние релиз 1.4.0, файлы и
annotated tag сохранены. Независимое ревью возвращённых байтов: Ship.

## Сохранность и ограничения

Установка новой версии заменяет выбранные папки скиллов; сохраните локальные
правки и проверьте восстановление до удаления backup. Замена Tibicen не запускает
adopt и не переносит инфраструктуру проекта. Замена и удаление описаны в
[руководстве установки](../../../INSTALLATION.md);
локальный путь сам по себе не подтверждает публичную доставку.

Фонового обновления нет. Выпуск не подтверждает новую нативную сессию среды/модели,
автозагрузку, активацию/подключение MCP или общую совместимость моделей.
Запуск проектных команд в Windows не поддерживается; операции только для чтения доступны.
Синтетические assisted-проверки не измеряют человеческую пользу, экономию усилий или работу без помощи.
