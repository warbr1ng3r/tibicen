# Ресурсы точного кандидата вне checkout

3 ноября 2026 года оба скилла условной локальной **1.0.0** прошли настоящие проверки версии/ресурсов, причём скопированная дистрибуция и рабочая директория физически находились вне исходного checkout. Node **24.15.0**, macOS arm64; прошли четыре вызова, включая два `self-test`. Git отсутствовал в PATH, а разрешение чтения файлов Node ограничивалось скопированной дистрибуцией. Модели, установщик, команды проекта и сетевые запросы не входили в эти вызовы; изоляция сети средствами ОС не заявляется.

| tibicen-adopt | 1.0.0 | passed / available |

Исходные дистрибуция/архив и общая рабочая поставка не менялись. Точные argv, хэш Node, scope/окружение, stdout/stderr и квитанции с длительностью сохранены в локальном аудите делегированной приёмки.
