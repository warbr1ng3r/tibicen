- Дистрибутив/tag: `db03ebc988af1e38ea9f62c02027945ba40660fc`; хэши 86 файлов совпадают с точной пересборкой публичного исходника, замороженным кандидатом и фактическими установками по SHA/tag. Оба self-test установленных CLI прошли вне checkout.
- Чистый локальный gate 668/668 и независимый ponytail Ship. [Ubuntu CI после слияния в main](https://github.com/warbr1ng3r/tibicen/actions/runs/40437643480) и [деплой Pages](https://github.com/warbr1ng3r/tibicen/actions/runs/40438226284) прошли.
- Переход с предыдущей локальной 0.1.0 сохранил 11 внешних файлов до resume. Та же незавершённая сессия завершилась, прежняя история сохранилась, неизвестные схемы state/manifest были отклонены без записи. Удаление сохранило 16 внешних файлов и проверенные резервные копии.
- Три артефакта, скачанные из опубликованного релиза, совпадают с локальными байтами и SHA-256 digests GitHub. Их файл контрольных сумм проходит проверку. Архив содержит только два скилла и инвентарь их 86 файлов.
- Smoke публичной страницы: логотипы/ресурсы загрузились под `/tibicen/`, селектор pnpm изменил команду установки с tag, конструктор скачал корректный локальный пресет schema 1. Эта проверка не повторяет полный набор браузерных тестов.

[Машиночитаемая сводка](results.json) содержит публичные refs, результаты и ограничения. Полные логи, квитанции и скриншоты остаются локальными у сопровождающего; ссылки на них не выдаются за публично доступные артефакты.

Предыдущий кандидат был локальным, поэтому это не переход между двумя уже публичными выпусками. Замена установщиком удаляет локальные правки/добавленные файлы внутри установленных каталогов скиллов: сохраните их резервную копию вне каталогов установки. Закреплённый `skills update` остаётся на своём ref; новый выпуск выбирается явно. Полное покрытие компонентов/агентов/платформ, native loading, human/usefulness pilot и вопрос непубличных контактов поддержки остаются открытыми.
