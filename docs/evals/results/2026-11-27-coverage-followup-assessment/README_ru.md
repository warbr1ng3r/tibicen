Исходный failed и более узкое assisted-продолжение остаются разными наблюдениями.

Исправление root использует общие правила ключей и полных заполнителей. Каждое вхождение ключа/значения декодируется отдельно, сохраняя дубли JSON и допустимые экранированные заполнители.
