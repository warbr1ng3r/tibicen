# Нативный apply и захват вывода, 15 ноября 2026 года

**Нативный агент применил согласованные файлы, но полная приёмка не пройдена:
все четыре результата CLI пусты.** Последующие model-free контроли локализовали
взаимодействие захвата с политикой/runtime. Они не заменяют неудачную оценку и не
устанавливают дефект Tibicen. [Индекс свидетельств](evidence.json) связывает
приватные протоколы, helpers, результаты и очистку. Опубликованная **1.5.4 не меняется**.

## Одно нативное наблюдение

После [исправления доставки диагностики](../2026-11-15-executor-diagnostics/README.md)
одна свежая сессия Codex 0.157.0 использовала те же 66 входов/режимов, запрос и
проверенный digest сгенерированной памяти, что и прежний остановленный apply,
с новой фиксацией исходников/recorder. Синтетическое согласие контроллера покрывало
два файла плана, заявленные служебные эффекты и четыре captures; оно не было
человеческим. Независимое ревью до запуска исправило режимы, связь
manifest/usage/сессии и границы доказательства исполнения. Grader до GO прошёл
один положительный и одиннадцать отрицательных model-free контролей.

Нативный ход завершился за **41,734 секунды** (внешнее время driver — **41,784
секунды**), usage — **74 697 входных / 900 выходных токенов**. Оба файла плана,
`AGENTS.md` и `.agents/memory.md`, побайтно совпали с ним при режиме `0600`.
Все 62 неизменяемых именованных входа сохранили байты/режимы. Manifest и отдельный
usage завершены с совпадающими проектом/сессией/памятью; временный state отсутствует.

Наблюдавшийся helper агента вызвал apply, verify, status и report по одному разу,
использовав точный digest для apply. Все captures сообщают exit zero, но
stdout/stderr пусты; helper отбрасывал `spawnSync.error`. Grader правильно упал
на пустом JSON; агент сообщил об этом пробеле. Завершённый manifest и записанная
структурная проверка apply не заменяют самостоятельные результаты CLI. В логе
сохранено восстановленное чтение отсутствовавшего reference-файла. Терминального
отказа исполнителя не наблюдалось; пустая диагностика не доказывает вложенный успех.

## Диагностика захвата

Отдельный model-free контроль через настоящий RPC за **0,990 секунды** воспроизвёл
`status: 0`, `error.code: EPERM` и пустые потоки для синтетического вывода и
read-only status Tibicen. Затем сравнение за **2,753 секунды** в одном контейнере
меняло захват и внутреннюю политику; внешняя Docker `network=none` сохранялась:

| Внутренняя политика | Обычные pipes | Явные файловые дескрипторы |
| --- | --- | --- |
| Свободная файловая система, сеть ограничена | EPERM, status zero, пустые потоки | Без ошибки; ожидаемые stdout/stderr сохранены |
| Та же файловая система, внутренняя сеть разрешена | Без ошибки; оба потока сохранены | Без ошибки; оба потока сохранены |
| Внутренний sandbox не задан | Без ошибки; оба потока сохранены | Без ошибки; оба потока сохранены |

Это локализует взаимодействие в проверенном маршруте Node 24.15.0 / executor
0.157.0. Эти контроли не устанавливают проблему интернета, авторизации или генерации JSON Tibicen.
Точный запрещённый syscall неизвестен. Helper нативного хода отбросил поле ошибки,
поэтому его исходный EPERM остаётся выводом из воспроизведения, а не прямым
наблюдением. Ещё более ранний отказ исполнителя по-прежнему не объяснён.

## Решение и завершение

[Руководство хранения](../../REPRODUCIBLE_RUNS.md) теперь требует проверять ошибки
и сигналы до status и использовать совместимый захват без ослабления нативной
изоляции. Файловые дескрипторы прошли с ограниченной политикой. Это изменение
руководства проверок, а не поведения продукта или замороженных helpers. Для полной
приёмки вывода CLI нужно новое ограниченное нативное наблюдение; автоматический
повтор не выбран.

Независимое ревью специфики Codex проверило команды, сырые контроли, идентичность
протоколов/helpers и границы причинных выводов. Все три контейнера остановлены,
удалены и независимо подтверждены отсутствующими; временный HOME отсутствует.
Все 66 входов хоста и 22 замороженных исходника не изменились. Работающих заданий
нет. Пакет использовал **одну модельную сессию по подписке, два model-free
контейнера, ноль повторов вызывающей стороны и ноль новых платных API-вызовов**.
Прежний учёт пяти вызовов сохранён: эти пакеты сгенерированной памяти теперь
содержат шесть нативных вызовов, а не всю историю проекта. Исторический неудачный
usage и денежная стоимость неизвестны.

Для этих изменений документации полный source gate не повторялся; предыдущий
сохраняет 1 148 пройденных тестов, 0 ошибок и 1 прежний пропуск. Отдельное задание
для пользовательского GLM готово; результат GLM не получен. Восстановление
прерывания, сохранность adopt и память в другом харнессе остаются следующей
работой. Отчёт не заявляет автозагрузку, человеческую пользу, широкую поддержку
харнессов, коммит, push или релиз.
