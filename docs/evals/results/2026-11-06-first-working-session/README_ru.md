# Наблюдения первой рабочей сессии — 6 ноября 2026

Пять контролируемых случаев охватили рекомендации опубликованного Tibicen 1.4, три механических применения и последующие небольшие задачи в приложении. Эти этапы учитываются раздельно.

**Ограничения:** использованы синтетические примеры, принадлежащие проверяющей стороне, и внутренние субагенты с подсказками; иногда помогали автор примера или чтение реализации. Пути к инструкциям проекта передавались явно. Нативные хосты и модели не запускались; автоматическая загрузка, общая совместимость и измеренная польза для человека неизвестны. Корневой агент передал три имитированных механических одобрения после независимой проверки точных планов; **это не согласие конечного пользователя**.

Свежей установки из сети не было. Границы работы заданы в [предложении изменения](../../../../openspec/changes/validate-first-working-session/proposal.md) и [проекте решения](../../../../openspec/changes/validate-first-working-session/design.md). ## Отдельное механическое применение

После независимой проверки точных планов I1/A1/M1 корневой агент передал три имитированных токена одобрения тестовому драйверу разработки с замороженным API и собственными изолированными HOME. Каждый план применён один раз, вернул `complete` и прошёл проверку инфраструктуры `structure-only`. За пределами объявленных служебных файлов `.tibicen` и изолированной записи использования изменился только целевой файл инструкций/памяти; защищённые файлы приложения и режимы сохранены. Нативной интеграции, установки зависимостей и запуска MCP-сервера не было.

Исходные результаты проверки проекта в продукте остаются **`unverified`**: `unsupported-profile` для невебовых Node-модулей I1/A1, `no-project-checks` для M1. Продуктовые task/quiz-проверки не запрашивались; поздние наблюдения не повысили эти статусы. Отдельные тесты разработки после чтения кода прошли до и после применения: I1 2/2, A1 2/2, M1 1/1. Они подтверждают поведение примеров, но не поддержку продуктового профиля и не согласие.

Закрытые ожидаемые результаты и предыдущие ответы им не передавались. Позднюю корректировку памяти продолжил тот же агент M1; окончательную проверку только для чтения выполнил новый свежий агент. Сборка разработки не является новым опубликованным артефактом. Независимое ревью свидетельств/документации пройдено после уточнения этапов со свежими агентами; проверены происхождение истории, переводы, ссылки и сохранённые артефакты. ## Подтверждённое затруднение и остаток работы

Замороженные предложения A1/M1 правильно сохраняли содержимое, но показывали весь файл удалённым/добавленным ради одной строки. Ограниченное исправление разработки убирает общий префикс/суффикс, показывает один блок с тремя строками контекста и сохраняет полное одобренное содержимое, окончания строк и привязку одобрения. Регрессионные тесты охватывают границы файлов, окончания строк, права доступа, применение точных байтов, согласие и ранее одобренные планы. Неизменяемые опубликованные артефакты 1.4 это не затрагивает. Других дефектов продукта эти случаи не установили.

C1 ещё требует фактов из настоящего контекста запуска OpenCode: фактический источник конфигурации и доступность нужного **имени** переменной без раскрытия значения. Сервер здесь не запускался. Явная следующая задача N1 остаётся предложением начала, а не наблюдаемой нативной сессией. Небольшие примеры с подсказками подтверждают перечисленные технические результаты; сравнительной экономии времени и измерения пользы для человека нет.
