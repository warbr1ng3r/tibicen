# Tibicen 1.5.2

Исправляет первую настройку после установки Tibicen внутри проекта. Канонические папки `tibicen-init` и `tibicen-adopt` сами по себе больше не считаются существующей пользовательской настройкой. Другие инструкции, скиллы, зарегистрированная память и сохранённая настройка оставляют режим улучшения. Каталоги пользовательских правил, команд и MCP сохраняют приоритет над вложенными примерами.

Полный инвентарь, права файлов, защита непустого проекта, точное согласование и границы записи исходников прежние. Миграция, смена схем и зависимостей не нужны. Распознавание имени папки — подсказка для выбора маршрута, а не доказательство доверия или происхождения.

Проверки: 1048 успешных тестов и один прежний пропуск; три автономные проверки; все шесть ячеек macOS/Linux/Windows и Node 22/24; точные локальные/публичные установка, замена, повторное добавление, восстановление изменённой резервной копии и удаление. Один свежий цикл Codex по подписке завершил предложение, одобренное применение, полезную задачу с пятью независимыми тестами и повторную проверку без изменений. Это не доказывает измеренную пользу человеку или совместимость со всеми харнессами/моделями. В сохранённом нативном выводе другого предложения не было его скомпилированного плана; оно не применялось, пробел свидетельств сохранён.

Установка точной поставки:

```sh
npx skills@1.7.4 add https://github.com/warbr1ng3r/tibicen/tree/df15ae7e0ae67aee2bd278f7e4f265e03437e672 -g --agent universal --skill tibicen-init tibicen-adopt --copy
```
