## Статическое уточнение

В исходном Bash-наблюдении экспортированный результат инструмента содержит ноль байт; это не доказывает отсутствие stdout дочернего процесса. Сохранённая поздняя пара экспортирует 181 байт, затем 0 байт при одинаковом отображении команды чтения status и коде 0 в обоих случаях; место потери неизвестно. Исходные данные ошибок Docs и естественное завершение восстановить нельзя. Преждевременная остановка коллектором [уже исправлена](../../../../openspec/changes/archive/2026-11-08-await-codex-terminal-outcome/verification.md); исторические результаты неизменны.

ZCode имеет штатную CLI с поддержкой подписки; текущая готовность не проверена. Отдельному app-server нужны настоящие сведения об аккаунте и обработка авторизации со стороны хоста. GUI — не единственный возможный путь. В статическом обзоре новых обращений к авторизации/модели нет; чтение только наличия credentials пропущено, поскольку оно не подтвердило бы готовность.

Отдельный диагностический вызов завершил нативный ход за 19,318с общего времени вызова. CLI, tee и команда вернули код 0: эксклюзивный артефакт `0600` содержал допустимое предложение объёмом 6 381 байт, stderr был пуст, но экспортированный вывод команды составил 0 байт. Это воспроизводит пропуск выше stdout дочернего процесса, а не провал нативного хода. Все 120 входных файлов/права сохранены; возвращено 123 файла. Независимое ревью приняло это диагностическое наблюдение; принадлежащий проверке каталог удалён, нативные homes пусты. Точный вышестоящий слой, историческая причина и то, что увидела модель, неизвестны. Применение, исправление продукта или новый принятый рабочий цикл не заявляются.
