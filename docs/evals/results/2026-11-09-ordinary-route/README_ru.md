# Обычный HTTPS работает; нативный setup остановлен по дедлайну

Ограниченная проверка закрыта **без принятого предложения CLI**. Нативное применение, полезная новая задача и adopt не запускались.

AionCore 0.1.55/Aionrs 0.2.8 использовал закреплённый Qwen3.6-35B-A3B/PrimeIntellect-fp8 через Polza без fallback. Сгенерированный проект — утилита сумм заказов из четырёх файлов без зависимостей. Помощь оператора включала установку, разрешения и начальную подсказку чтения скилла; оператор не писал и не исправлял план, применения не было. Guidance оставался локальной Unreleased-работой; опубликованный 1.5.4 не менялся.

| Проверка | Фактический результат |
| --- | --- |
| Исходный sandbox исполнителя | Обычный HTTPS завершился `ENOTFOUND` |
| Те же Node/probe/env вне sandbox | HTTP200 с обычной проверкой TLS |
| Тот же sandbox плюс доступ к сокету системного resolver | HTTP200 с проверкой TLS; без proxy или изменений ОС/аккаунта |

Установленный sandbox-профиль Apple содержит точно такое разрешение mDNSResponder. Это исправление частной политики исполнителя, не runtime Tibicen. Подготовка сначала остановилась из-за устаревшей поставляемой ссылки; до запуска выполнены штатная пересборка и проверка всех 110 файлов. Эквивалентность восстановленного compact-конфига прежним входам не доказана, поэтому сравнение не изолирует только сеть.

Агент завершил 15 из 19 tool-вызовов. `sort` был запрещён, последующий обычный `find` успешен; три поздних Read отменены по дедлайну. Переданы полные актуальные тексты SKILL, scan/inventory/interview/proposal, формата и памяти. WS error-событий не сохранено, но это не доказывает отсутствие внутренних ошибок провайдера и не объясняет [прежний EmptyFinal](../2026-11-09-native-route/README.md).

В 600 с вошли разрешения оператора и проверка источников. В событиях нет времени: сумму ожиданий определить нельзя; успех с автоматизацией и влияние лимитов/инструкций не доказаны.

Сохранены 142 замороженных входа и ровно четыре файла проекта, добавлений нет. Host остановлен, порт 55780 закрыт, временный профиль/зашифрованная база удалены; личные настройки не менялись.
