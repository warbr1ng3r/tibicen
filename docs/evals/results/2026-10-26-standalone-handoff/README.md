## Исправления продукта

Обычный и сохранённый CLI report теперь перечисляют известные применённые пути/операции в `applied` и показывают сохранённую причину остановки в `reason` либо null. Это исправляет потерю ответа «что сделано» после завершения и причины `incomplete` после прерывания. Старые паспорта без истории attempts остаются читаемыми. Отдельный файл отчёта по-прежнему создаётся только по явному запросу; по умолчанию агент показывает результат в ответе.

Новые проверки охватывают stdout/saved report, отсутствие скрытой записи, согласие на сохранение, прерванное улучшение и старый паспорт. Полный `pnpm test`: **596/596**, 0 skipped; lint/format/types/build/strict specs прошли. Сборка и 84 суммы проверены, оба распакованных скилла прошли self-test с пустым PATH. Независимое Ponytail-review после исправления legacy-случая — без замечаний.

## Ограничения и служебная сводка

Временный host допустил ошибку только при сборке сводки: поле статуса сценария было перезаписано объектом результата CLI `status`. Поэтому первичный `outcome.json` сохранил `not-passed`. Его не переписывали и модели не перезапускали. Отдельная связанная проекция и независимая повторная проверка traces, планов, квитанций, деревьев и отчётов подтверждают фактическое завершение обоих циклов. В JSON сохранены первичный статус, его причина и hashes исходных свидетельств.

Проектные тесты, новая поведенческая задача, квиз и compat были исключены запросами этих случаев; их непроверенность явно раскрыта. Это проверка двух выбранных конфигураций и отчётов, без заявления универсальной семантической, человеческой или релизной приёмки. Предыдущие ошибки других когорт сохранены отдельно.
