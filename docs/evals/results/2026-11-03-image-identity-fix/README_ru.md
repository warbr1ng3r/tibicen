# Исправление идентичности образа: gate публичных исходников — 3 ноября 2026

Независимо проверенное [исправление идентичности образа](../../../../openspec/changes/stabilize-contained-image-identity/proposal.md), затрагивающее только eval-стенд, прошло полный офлайн-gate на новой **проекции из 645 публичных исходных файлов**. Все 86 файлов пересобранного Tibicen, права и контрольный манифест остаются идентичны условной поставке 1.0. Результат связывает изменённые исходники; прежний [gate из 632 файлов](../2026-11-03-public-source-gate/README.md) сохранён как отдельное историческое наблюдение.

Исправление хеширует версионированную проекцию ID образа, ОС, архитектуры, нормализованного variant, полного Config и полного RootFS. Порядок ключей объектов и служебные оболочки GraphDriver/Descriptor/Identity не определяют идентичность исполнения; порядок массивов и существенные изменения конфигурации/файловой системы остаются значимыми. Сохранены проверки обязательной формы данных, закреплённого образа/платформы/root/watchdog. Этот gate не создаёт нового настоящего наблюдения Docker/модели и не разрешает живой запуск. [Наблюдения установленных навыков](../2026-11-03-installed-skill-check/README.md) сохраняют прежние исходы и бюджеты.

## Вход и границы

До копирования и тестов root сообщил о независимом Ship и готовности итоговых документов. SHA-256 квитанции ревью — `dfd6c33088287fb1d497a61571a20eb624aeaf3258a7a87250b805c0959ecdd7`. Из существующих файлов, кроме документов, относительно входа из 632 файлов изменились только `scripts/evals/profiles/codex/contained.ts` и `tests/evals/contained-codex-profile.test.ts`; их хеши совпали с проверенным GO. Остальные изменения — проверенная документация: две пары отчётов и девять артефактов OpenSpec явно расширяют выборку с 632 до 645 файлов.

Предыдущая редакция staging из 632 файлов скопирована и проверена до обновления; квитанции 152 не изменялись. Проекция сохраняет лицензии, фикстуры, входы сборки и ровно семь прежних записей навыков исходников разработки. 180 ссылок на исключённые приватные записи пояснены прежним преобразованием только документов EN/RU. Только скопированный корневой `package.json` получает `1.0.0`; общая версия остаётся alpha. Runtime/тесты и исключения ради прохождения gate не менялись. В чистой копии исходников нет зависимостей и симлинков.

Использован прежний рецепт 152 с Node 24.15.0 / pnpm 11.21.0: новая одноразовая соседняя копия с отдельными source и собственными host/TMP-каталогами, 18 498 скопированных файлов зависимостей, 1251 внутренний относительный симлинк и 126 перенесённых сгенерированных запускателей. Проверены прямой и вложенный pnpm. Пустые собственные HOME/config-каталоги и разрешённый список окружения исключали унаследованные реквизиты провайдеров; telemetry/update checks отключены. Установки/скачивания пакетов, настоящих действий модели/API/auth, записи в общие зависимости/dist, коммитов/тегов/push, архивирования и публикации не было. `modelSessions` фиктивных контролей — синтетические счётчики. Эти настройки не являются общей сетевой изоляцией ОС.
