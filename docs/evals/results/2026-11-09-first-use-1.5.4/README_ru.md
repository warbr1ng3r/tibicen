# Первый запуск опубликованного Tibicen 1.5.4

Два искусственных проекта прошли предложение → точное согласование → нативное применение → полезную задачу в новой сессии. Использованы полные неизменённые [опубликованные скиллы 1.5.4](https://github.com/warbr1ng3r/tibicen/releases/tag/v1.5.4) из проверенных артефактов выпуска. Наблюдения дополняют [проверку выпуска](../2026-11-09-release-1.5.4/README.md) применением, которое в обоих случаях выполнил агент.

## Bash: подготовка существующего проекта

**До начала:** пять файлов содержали Bash-фильтр логов, тесты, пример данных и письменный контракт поведения. Пользовательских инструкций для агента и отдельной памяти не было. Установленные папки Tibicen не помешали настоящему CLI выбрать `init`.

**Запрос:** «Подготовь этот проект к работе с агентом: короткие инструкции, без новых инструментов. Сначала покажи предложение».

Агент изучил проект и составил предложение через настоящий CLI. План размером 7 960 байт добавлял только `AGENTS.md` с правами `0600` и ссылкой на существующий контракт. Отдельная память, зависимости, MCP и запуск проектных команд не предлагались. Оператор согласовал точный digest артефакта и заявленные служебные записи, затем новый агент сам составил вызов CLI для применения. Применение вернуло `complete`, структурная проверка прошла. Защищённые файлы сохранились.

Следующий обычный запрос требовал фильтр `--level ERROR` с учётом регистра и сохранением прежнего поведения, содержимого и порядка строк. В новой сессии агент явно прочитал `AGENTS.md`, README и контракт логов. Изменились только скрипт и его тесты. Все **14 Bash-тестов** и независимая контейнерная проверка поведения и сохранности прошли. Проверки охватывали точное совпадение поля, обратные слеши, пустые строки и входные данные, окончания последних строк.

## Документация: исправление существующих инструкций

**До начала:** восемь файлов включали инструкции агенту, решения владельца и опубликованную историю выпусков. Инструкции ошибочно требовали `npm test` и объявляли черновой патч 1.2.1 опубликованным.

**Запрос:** «Приведи существующие инструкции для агента в порядок. Сохрани решения и опубликованную историю. Сначала покажи предложение».

Агент сформировал через CLI план размером 7 340 байт, меняющий только `AGENTS.md` с сохранением прав `0644` и исходного абзаца об английском языке и истории. Удалены несуществующая тестовая команда и ложное утверждение о публикации. Существующий `docs/decisions.md` зарегистрирован как память с политикой чтения и изменения в заданных границах; второе хранилище не создано. После точного согласования новый агент применил план. Согласованные инструкции и manifest записаны, временного state нет, защищённые решения, история и файлы скиллов сохранили байты и права.

Новая задача просила подготовить черновик руководства для 1.2.1 с примером аннотированного тега и проверками перед отправкой, без выдуманной даты и публикации. Изменился только `docs/releasing.md`. Независимое смысловое ревью и конечная проверка документа прошли: девять примеров команд, статус черновика, согласование владельцем и прежняя история сохранены. Тесты программного обеспечения, Git-команды и публикация не выполнялись. События показывают явное чтение руководства; они **не подтверждают**, что эта задача обращалась к `AGENTS.md` или хранилищу решений.

## Что наблюдалось

Зафиксированный маршрут использовал Codex 0.157.0 с `gpt-6-astra` через существующую подписку, с нулевым бюджетом платного API.

| Случай | Вызов предложения | Вызов применения | Вызов новой задачи | Проверка полезной задачи |
| --- | ---: | ---: | ---: | --- |
| Bash init | 86,414 с | 56,319 с | 51,036 с | 14 тестов; независимая проверка 0,825 с |
| Docs adopt | 73,521 с | 67,641 с | 46,317 с | Проверка документа 0,857 с; смысловое ревью |

Шесть нативных вызовов по подписке заняли суммарно **381,248 секунды**, внешних повторных вызовов не было. Четыре отдельных контейнера без моделей проверили границу исполнения, контрольные случаи проверяющего кода и две полезные задачи. Все остановлены и удалены; принадлежащая наблюдению папка проекта удалена, изолированные домашние папки сессий пусты. Бюджет платного API — ноль.

Проверки настройки и последующих задач разделены. При применении Bash структурная проверка прошла, но отдельные команды status/report не собраны. Применение Docs вернуло три разобранных JSON-ответа verify/status/report в одной составной команде с нулевым кодом завершения. Проверка приложения на этапе настройки в обоих случаях осталась `unverified`; результаты новых задач приведены отдельно выше.

## Затруднения и ограничения

Оба хода предложения восстановились после первой команды сохранения: дочерний процесс завершился с нулевым кодом, а родительский `JSON.parse` сообщил `Unexpected end of JSON input`. Первоначальные данные перезаписаны до сбора: их точная длина и причина неизвестны; отсутствие данных, обрезанный JSON и ввод из одних пробелов различить нельзя. Затем прямое перенаправление CLI сохранило корректные планы внутри тех же вызовов. При применении Bash агент исправил угаданные имена справочных файлов; другие ходы сохранили поиск отсутствующего state, поиск без совпадений и замену недоступного Python на `awk`. Это обычные исправления, без внешнего повтора и подмены плана оператором.

После закрытия этого пакета **отдельный контейнер с диагностикой только для чтения** сравнил прямой вызов CLI с дочерним вызовом из Node. Оба завершились с нулевым кодом и вернули корректные планы размером 7 968 байт; отсутствие вывода **не воспроизвелось** за 2,952 секунды. Входные байты и права сохранены, очистка подтверждена. Модели, авторизация и сеть не использовались; этот контейнер не входит в четыре выше. Проверка не доказывает равенства с нативным окружением, не объясняет первоначальные ошибки сохранения и не меняет старые результаты.

Проекты, явная точка входа в скилл, передача артефактов, границы записи и точное согласие оператора подготовлены заранее. Предложения и вызовы применения составили агенты; новые задачи получили фактические файлы без прежних диалогов и специальных подсказок читать инструкции. Установка, повторный запуск, работа реального пользователя и второй харнесс здесь не проверялись. Автоматическое обнаружение, причинная польза и общее использование памяти не доказаны. Старые результаты сохраняют исходный охват; наблюдение не привело к исправлению продукта или смене версии.
