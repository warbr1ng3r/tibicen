**Закрыто:** Bash завершил полный цикл; документация завершила продолжение с помощью оператора после прерванного proposal. Все 110 файлов [опубликованной 1.5.2](../2026-11-08-release-1.5.2/README.md) побайтно неизменны. Изменена только инфраструктура оценки; версия не повышалась. ## Сохранённые сбои и исправления оценки

- В старом Bash полного proposal не было, хотя агент сообщил digest. Проверки CLI без записи прошли, но исходное отсутствие вывода не объяснили.
- Старая документация остановилась после общего события ошибки. Причина ошибки и несобранное продолжение остаются неизвестными; неуспешный результат не изменён.
- Первое свежее поколение выполнило один вызов: scan/status/report сработали, но вложенный Node из helper завершился `EPERM`. Ни proposal, ни apply не приняты; 119 защищённых файлов и права сохранились. Поколение закрыто, временные ресурсы удалены.

Исправленный захват использует опубликованные CLI `main` и `serializeData(result)`, одно чтение stdin и файл с правами 0600. Это сериализация реального результата CLI, а не stdout дочернего процесса или согласие. Контроль разрешений Node запретил старый helper с дочерним процессом и разрешил исправленный, сохранив входные данные; исходное ограничение Linux этим не установлено.

Второй подтверждённый дефект — collector останавливался на любом общем `error`. [Официальный emitter фиксированной версии](https://github.com/openai/codex/blob/00c972ed5d6ff6499317fd41b7f23605b8e6850d/codex-rs/exec/src/event_processor_with_jsonl_output.rs#L447-L458) после уведомления возвращает `Running`; конечный исход/код процесса приходят отдельно. [Исправление](../../../../scripts/evals/contained-codex.ts) прошло 57 профильных [тестов](../../../../tests/evals/contained-codex-result.test.ts) и независимое ревью. Прежние дедлайны и остановки при явных ошибках авторизации сохранены. Исправление привязано только к новому продолжению; старые результаты не пересчитаны.

Полный gate: **1 055 тестов прошли, ноль ошибок, один прежний пропуск**. Первая попытка gate остановилась на типизации теста; тест исправлен до успешного прогона.

Автоматических повторов не было; прежние 24 контроля использованы повторно. В свежей задаче прочитаны AGENTS/README/решения владельца без специальной подсказки, изменено только руководство релиза: остальные 118 файлов и 119 прав сохранились. Контейнерный оракул за 0,858 секунды проверил шесть Markdown-файлов; программных тестов, Git и выдуманной даты не было.

Bash изменил только фильтр/тесты; остальные 117 файлов и память сохранились. Отдельный конечный оракул прошёл за 0,879 секунды, его ресурсы удалены. Обычные исправления сохранены: отсутствие `shasum`/неверный поиск файла учёта обойдены через Node; поиск в задаче вернул 1 при отсутствии дополнительных инструкций; повтор исправил `scripts/filter-log.sh` на `bin/filter-log.sh`. Команда status во время apply завершилась с кодом 0 без тела: JSON-статус не наблюдался; приёмку подтверждают фактические apply/report и проверка структуры. В apply/задаче документации также сохранены отсутствующие пути/результаты поиска (коды 2/1) и недоступный Python (127); задача проверила цели ссылок через shell.
