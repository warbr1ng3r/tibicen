## Первый сбой и исправление

[Первая матрица](https://github.com/warbr1ng3r/tibicen/actions/runs/41124239471) на [`5dc6051`](https://github.com/warbr1ng3r/tibicen/commit/5dc6051486269cf4efecc12388b14de2b54d97a9) прошла четыре macOS/Ubuntu сочетания и упала в обоих Windows. Windows init добавил AGENTS.md, затем остановился с `baseline-changed`; adopt прошёл. Первые сбои сохранены, их статус не повышался и слепого повтора не было.

План и финальный снимок записывали запрошенный режим0600 нового файла инструкций, а Windows возвращала0666. Фикс явно задаёт обычный writable0666 для новых собственных текстов Windows, сохраняет POSIX0600 и существующие наблюдаемые права, отклоняет неподдерживаемые точные итоговые режимы в компиляции proposal, preflight сырого apply и прямых снимках. Upstream0644/0755, явный0600 и непроверенный readonly0444 молча не преобразуются. Чтение прежних/исходных режимов и точные сравнения байтов/прав сохранены. POSIX-биты и внутренние запросы chmod не подтверждают приватность Windows ACL; см. [ограничение Node для file modes](https://nodejs.org/download/release/v24.15.0/docs/api/fs.html#file-modes).

Три локальные регрессии политики падали до фикса, после него затронутые suites прошли21/21. Они эмулируют Windows-селектор платформы с настоящими локальными файлами; настоящее Windows-свидетельство даёт удалённая матрица выше. Независимое ревью приняло исправление. Финальный локальный gate pnpm11.21.0/Node24.15.0 прошёл715тестов/один намеренный пропуск portable-теста (всего716), включая lint/format/types/сборку сайта и строгую проверку активных/архивных OpenSpec. Локальные standalone-проверки прошли3/3 на каждом доступном runtime. Настоящий [Ubuntu offline CI](https://github.com/warbr1ng3r/tibicen/actions/runs/41125594821) также прошёл на исправленном коде, включая smoke распакованного дистрибутива.

Локально пересобранная macOS-поставка содержит86 проверенных файлов, SHA256 inventory `170fdef9501f0ffb85b7d418bd416364bf6f76fbde046f4c4e9e9bd799669447`, с16 отличиями от опубликованной alpha (десять core-копий и шесть копий references). Каждая удалённая job проверяет собственный пересобранный inventory; побайтно одинаковый архив между платформами не заявлен. Публичные технические snapshots сохраняют проверенные байты исходников, исключая приватную историю разработки/трекер/сырые свидетельства.

## Ограничения

Принят ограниченный standalone CLI flow на записанных ОС/runtime. Это не подтверждает native-обнаружение агентов, каждую конфигурацию компонентов/прав, человеческую пользу или весь MVP. Открыты публичная установка/обновление/восстановление backup точного кандидата, оставшаяся semantic-приёмка, реальный пилот и сопровождение по [процедуре выпуска](../../../RELEASING.md). Оценочные model/API-прогоны, изменения credentials, выпуск1.0 и Pages deployment не выполнялись.
