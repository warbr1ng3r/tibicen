или человеческую пользу.

## Проект, запрос и ожидаемые действия

Пример — небольшой форматировщик тикетов на Node без зависимостей, с рабочим
исходником и одним тестом. Среди семи файлов уже есть AGENTS.md и единственный
файл памяти проекта. Принятые решения: максимум семь тикетов в пачке и
согласование новых зависимостей. CSV-экспорт остаётся только идеей.

Первый запрос просит агента прочитать AGENTS.md, добавить chunkTickets(tickets),
сохранить порядок и существующий форматировщик, добавить тесты и выполнить
node --test. Размер пачки в запросе не указан. Агент должен прочитать контекст
проекта и менять только исходник и тесты. Просьба прочитать AGENTS.md — явная
помощь; автоматическое обнаружение инструкций здесь не проверяется.

Следующий отдельный запрос меняет лимит на четыре и разрешает соответствующие
правки памяти, исходника, теста и устаревшего места в README. Затем новая сессия
без изменений должна объяснить разбиение 13 тикетов по актуальному контексту
проекта. Эти исходные R2/R3 остановлены после отказа первоначального оценщика.

Первая проверка восстановления использовала настоящий сокет владельца и

нативного CLI. Предыдущие ревью исходников пропустили второй останов в этом

сессия завершилась успешно. Изменены только два разрешённых файла; все семь

Первоначальный оценщик запущен один раз и отказал на фильтре памяти: он требует

корректность кода; исходный grade от этого не становится успешным.

Отдельное явное **исправление измерения после наблюдения** применено к тем же
неизменным байтам и событиям R1. Его 32 контроля прошли. Полный вывод памяти из
составной команды требует независимой проверки чтения и порядка, без
автоматического зачёта. Эта проверка приняла исправленную оценку R1 с явной
пометкой «после наблюдения». Исходная оценка остаётся неудачной; модельная
сессия R1 не повторялась.

C1 использовала исправленное правило, закреплённое до запуска. Агенту предложили
изменить максимум на четыре, обновить единственный файл памяти, исходник, тесты

Оценщик оставил фактическое чтение, порядок и смысл памяти/README для независимого

сигналы не считались приёмкой смысла. Принятые семь файлов стали входами C2 после

C2 завершилась один раз за 35,98 секунды. Агент прочитал полную актуальную память

успешные тесты отделены от того, что в этой нативной сессии полный набор повторно
не запускался. Отдельный изолированный оценщик выполнил все восемь тестов проекта
и 14 проверок поведения. Сохранность проекта на хосте, входов, 106 файлов
закрытого прежнего пакета и очистка подтверждены. Итоговая независимая проверка
фактического чтения, порядка и ответа дала Ship; root принял результат.
