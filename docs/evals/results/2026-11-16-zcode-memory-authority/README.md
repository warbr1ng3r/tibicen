## Protocol deviation and resource accounting

Reported worker durations are **246.3 / 265.7 / 100.9 / 87.2 / 96.0 seconds**, summing to **796.1 seconds** at displayed precision; the executor separately reports **796.0 seconds**. The frozen protocol says that exceeding **180 seconds** stops admission of the next worker. After phase 1, phases 2–5 should therefore not have been admitted. Phase 2 also exceeded the threshold. A known completed outcome, aggregate below 900 seconds, absence of a technical timeout, or an earlier packet's timing does **not** waive that next-call rule. The reported overall `passed` is not accepted as full protocol compliance. Retained behavioral outcomes remain useful observations; this is not a product failure and does not require rerunning the study merely to change its label.

Five fresh contexts, concurrency one, zero retries and GLM-5.3 through an existing ZCode subscription are executor-reported. The host reports **1,619,878 subagent tokens** and zero new paid API calls; split usage, subscription monetary cost and model-only timing are unknown. ## Limits and next action

Worker restrictions were prompt-scoped, with no exported worker prompts/tool events or OS sandbox. Freshness, exact routing, input delivery and absence of out-of-scope reads cannot be independently established. The tasks explicitly asked workers to read AGENTS.md: assisted loading is not autoload. Synthetic consent is not human consent. There is no ordinary-agent comparison, human usefulness result, causal memory-only result, cross-harness guarantee or reliability rate.

The returned behavior supports taking the existing small guidance change through final engineering review toward a compatible **1.5.6 patch**. No additional product code or broad model matrix is justified by this observation. Commit and publication remain separate authorized actions; neither occurred during this assessment. Preserve per-phase source/memory snapshots and enforce next-call stops in future delegated protocols; do not spend another run repairing historical compliance.
