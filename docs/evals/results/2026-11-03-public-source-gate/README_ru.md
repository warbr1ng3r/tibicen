# Офлайн-проверка обновлённых публичных исходников — 3 ноября 2026

Проверенная обезличенная **копия из 632 исходных файлов прошла настоящий gate репозитория** на macOS arm64 с Node 24.15.0 и pnpm 11.21.0. Все 86 файлов пересобранной поставки и контрольный манифест совпали с существующим условным дистрибутивом 1.0 по байтам и правам. Это локальная проверка проекции; неизменяемая публичная доставка и полная техническая приёмка MVP остаются отдельными в [инженерной оценке](../../ENGINEERING_ACCEPTANCE.md) и [реестре готовности](../../V1_READINESS.md).

## Граница исходников и исполнения

Исходные квитанции задачи 150 на 630 файлов сохранены как revision 1. Revision 2 обновляет проверенные текущие файлы и явно добавляет [пару отчётов adopt/свежей задачи](../2026-11-03-adopt-fresh-task/README.md). Сохранены прежний allowlist из 593 файлов, выбранные публичные документы и ровно семь прежних записей навыков разработки OpenSpec. Они остаются только в исходниках разработки; CLI OpenSpec, навыки разработки, тесты и стенд не попадают в распространяемую поставку.

Преобразование только документов поясняет **180** ссылок на исключённые приватные записи, сохраняя исходный адрес обычным кодом и пояснение EN/RU. Только в копии корневой `package.json` получает `1.0.0`; общая версия остаётся `0.1.0-alpha.1`. Runtime, тесты, фикстуры, входы сборки и лицензии сохраняют текущие байты. Исправлений поведения/тестов, исключений ради прохождения или форматирования копии не потребовалось. В чистой копии исходников нет зависимостей и симлинков.

Gate выполнен в отдельной одноразовой соседней копии с физическими копиями имеющихся зависимостей: 18 498 обычных файлов и 1251 внутренний относительный симлинк. Только в 126 сгенерированных `.bin`-запускателях перенесён префикс общего checkout. Прямой и вложенный pnpm подтвердили 11.21.0. Разрешённый список окружения использовал пустые собственные HOME/config-каталоги, без унаследованных реквизитов провайдеров, с отключёнными telemetry/update checks. TMPDIR находился вне package scope исходников, исключая известную несовместимость CommonJS-фикстуры с ESM окружением. Установки/скачивания пакетов, настоящих вызовов модели/API, изменений входа/авторизации, коммитов/тегов/push, архивирования и публикации не было. `modelSessions` в логах фиктивных офлайн-контролей — синтетические счётчики, не настоящие сессии. Настройки окружения не доказывают общую сетевую изоляцию ОС.
