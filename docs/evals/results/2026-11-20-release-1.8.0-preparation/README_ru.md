# Tibicen 1.8.0 — подготовка локального кандидата

Основная версия — [README.md](README.md).

20 ноября 2026 года. **Локальный кандидат готов, публикации нет.** Владелец разрешил
логические коммиты и подготовку. Push, запуск публичного CI, тег/релиз и выкладка
сайта в этот пакет не входят. Опубликованная 1.7.1 и её установочные/контрольные
ссылки сохранены.

## Объём и совместимость

Совместимый minor добавляет квитанции согласия в результаты apply/resume,
status/report и сводки сохранённых сессий. Scan распознаёт канонический скилл по
существующему маркеру имени/версии в полном пути его каталога относительно проекта.
Интеграционное ревью исправило согласованность/наследование квитанций и коллизии
каталогов. Требования и выполненные задачи остаются в
[изменении квитанций](../../../../openspec/changes/retain-approval-receipts/proposal.md)
и [изменении маршрутизации](../../../../openspec/changes/detect-canonical-skill-provenance/proposal.md).
Новых зависимостей и персистентной схемы нет; старые сессии без квитанций допустимы.
Журнал содержит не более восьми записей. Сохранность новых полей при перезаписи
сессии старым runtime не обещается.

Четыре логических приватных коммита фиксируют ядро, scan, уточнённую оценку и версию:
`97483ee`, `61722db`, `639914b`, `6294bd5`. Отдельная локальная публичная ветка
переносит только эти изменения на последнюю проверенную публичную базу
`233ae1dcd42db3fe14ad4ab7d6335d89cc709fc2`; runtime-checkpoint —
`803044a35407a76803a194e4499844de35967c8c`. Публичная очистка и все 142 ранее
опубликованных scratch-файла сохранены, новых приватных scratch-файлов и предка
из приватной истории нет. Приватную ветку разработки пушить нельзя. Remote main
в этом локальном пакете не обновлялся; перед будущим push его нужно проверить.

## Что осталось до публикации и ограничения

Кандидат готов к отдельной публикационной последовательности: обновить/проверить
публичную ветку, push, обычный CI и шесть платформенных ячеек, установка/обновление/
восстановление/удаление из настоящего публичного источника, неизменяемые distribution/
тег/три ассета, сверка полученных байтов, затем метаданные сайта и проверка выкладки.
Порядок передачи записан в приватном `reports/PUBLICATION_PLAN.md`. Публичная команда
установки 1.8.0 не рекламируется, пока нет distribution SHA.
[Черновик release notes](release-notes.md) описывает поведение и пределы для пользователя.

Локальные контроли выполнены на macOS / Node 24.15.0. Новый нативный Windows/
платформенный CI кандидата, автозагрузка харнесса, аутентификация внешнего
согласовавшего и измеренная человеческая польза остаются непроверенными.
Канал квитанции — метка вызывающего; она не предотвращает самосогласование агента
с общими инструментами/файлами.
[Оценка исходного пакета](../2026-11-20-consent-coverage-assessment/README.md) сохраняет
прежние нарушения согласия, хронологию H6 и неполноту командных доказательств F3/H6.
Новых поведенческих модельных сессий и платных API-вызовов нет.
