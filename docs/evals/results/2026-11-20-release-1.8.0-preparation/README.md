## Scope and compatibility

This compatible minor adds retained approval receipts to apply/resume results,
status, report and saved session summaries, plus canonical-skill routing based on
the existing name/version marker in its complete project-relative directory.
Integration review fixed receipt consistency/inheritance and directory collisions.
Requirements and completed tasks remain in the
[receipt change](../../../../openspec/changes/retain-approval-receipts/proposal.md)
and [routing change](../../../../openspec/changes/detect-canonical-skill-provenance/proposal.md).
No new dependency or persisted schema is introduced; old sessions without receipts
remain valid. Receipt journals keep at most eight entries. Older runtimes are not
promised to retain these additive fields if they rewrite a session.

version bump: `97483ee`, `61722db`, `639914b`, `6294bd5`. A separate local public
branch projects only these changes onto the last verified public base
`233ae1dcd42db3fe14ad4ab7d6335d89cc709fc2`; its runtime checkpoint is
`803044a35407a76803a194e4499844de35967c8c`. Public sanitization and all 142 inherited
public scratch files are preserved, with no new private scratch files or private
history ancestor. Do not push the private development branch. Remote main has not
