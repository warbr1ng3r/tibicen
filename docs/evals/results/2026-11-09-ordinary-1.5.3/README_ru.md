# Обычный рабочий процесс Tibicen 1.5.3 — закрыт с пробелами

Обе настройки приняты; задача склада пройдена. Задача очереди не принята, хотя тесты зелёные; последующая сессия изменения памяти завершилась ошибкой после записанной правки. Свежая задача с памятью и оба повтора не запускались. Это синтетические наблюдения на [опубликованной 1.5.3](../2026-11-09-release-1.5.3/README.md).

## Проекты и действия

**Очередь: изначально шесть файлов:** package, README, исходник/тесты задач, данные и соглашения; инструкций агента и памяти нет. Нужно сохранять ID, приоритеты, порядок входа и прежнее поведение.

Агент предложил и применил короткий `AGENTS.md`; первая настройка выбрана правильно, несмотря на 110 установленных файлов Tibicen. Структурная проверка и status/report CLI успешны. Две попытки вызвать отсутствующий Python обработаны через Node без помощи оператора; тесты приложения при настройке не запускались.

Свежая задача фильтра приоритета прочитала инструкции/README без подсказки и изменила только исходник/тесты. Пять тестов и прежние заранее заданные проверки поведения пройдены. Ревью не приняло успех: `!job.done` стало `job.done === false`, исключая отсутствующие/null/нулевые значения даже без приоритета. Исходник и README противоречили друг другу, но агент изменил совместимость, не разрешив конфликт. Существующие инструкции это покрывают; наблюдается их несоблюдение на неоднозначной фикстуре, а не доказанный сбой runtime Tibicen. Исправления и переоценки не было.

**Склад: изначально двенадцать файлов:** package/README/конфигурация, корневые/вложенные инструкции, `.agents/memory.md`, решения, исходники/тесты каталога и отчёта, данные. Корневая алфавитная сортировка противоречит складскому порядку; команда lint отсутствует.

Агент исправил два файла инструкций и добавил политику чтения, обновления и исправления существующей памяти. Настройка сохранила приложение, решения и память. Один вызов предложения завершился ошибкой с пустым сохранённым выводом, причина неизвестна; последующий вывод реального CLI проверен. При применении Python заменён Node, также обнаружен отсутствующий Git. Структурные проверки/status/report успешны; тесты приложения не запускались.

Свежая задача наличия прочитала инструкции, решения и память без подсказки; семь содержательных тестов и прежние заранее заданные проверки поведения пройдены, формат и защищённые файлы/права сохранены.

## Ограничения и следующий фокус

Семь вызовов через подписку заняли 485,406 секунды с накладными расходами запуска, без подготовки/ревью: шесть ходов завершены, пять фаз приняты, одна задача не принята и один вызов памяти остался незавершённым. Выполнены три изолированные проверки без модели. Все семь нативных и три проверяющих контейнера удалены; временные копии удалены, домашние каталоги пусты. Повторов не было. См. [сводку](summary.json).

Пути скиллов, согласие оператора и передача плана — помощь. Разрешения изменения памяти называли `.agents/memory.md`, поэтому поиск хранилища был подсказан. Безопасная диагностика не объясняет причину сбоя. Польза людям, автоматическая загрузка и причинное улучшение не доказаны; прежние сбои не меняются. Следующий фокус: уточнить противоречивый контракт очереди и улучшить безопасную диагностику сбоев. Оснований для патча продукта этот прогон не установил.
