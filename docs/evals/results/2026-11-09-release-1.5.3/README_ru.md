# Отчёт о выпуске Tibicen 1.5.3

**Локальные проверки кандидата пройдены; публикация ожидается.** Кандидат 1.5.3 заморожен. Публичные проверки исходников и платформ, доставка по SHA, публикация и выкладка ещё ожидаются; этот отчёт их не подтверждает.

Совместимый патч исправляет две конкретные ошибки чтения проекта. Структурная проверка теперь распознаёт Markdown-фрагмент в ссылке на зарегистрированный файл памяти, сохраняя точный выбор хранилища и ограничения безопасного чтения. Команды чтения проекта принимают явный список запрещённых путей на один вызов, включая восстановление, сведения отчёта и поддерживаемые локальные проверки MCP. Эта область объединяется с запретами незавершённого плана; постоянным ACL проекта она не становится. Запрет обязательных внутренних метаданных останавливает операцию.

Инструкции скиллов также отличают обязательные внешние действия человека от чтения инструкций и будущих проверок, которые доступный агент может выполнить сам. Существующие незавершённые планы и правила завершения не меняются. В [отдельных наблюдениях рабочего процесса](../2026-11-08-normal-workflows/README.md) сохранены прежние сбои, продолжение с исправленной проверкой и предложение рабочей сборки; это не новая нативная приёмка 1.5.3.

Локальная доставка сохранила полные изменённые резервные копии, файлы приложения, поздние заметки памяти, соседний скилл и настройки. Проверки копий подтвердили связь памяти через фрагмент и явную область чтения после завершения, отклонение выхода из проекта, сохранность байтов и прав проекта/home/runtime и удаление обоих временных корней.

Локальные проверки используют синтетические проекты и отдельные временные домашние каталоги. Разрешения установщика не являются изоляцией средствами ОС. Self-test доставки и проверки скопированного CLI подтверждают только указанное техническое поведение, а не автоматическую загрузку инструкций, пользу для людей или совместимость со всеми харнессами и моделями. Этот этап не включает новых нативных вызовов или платного API. См. [установку и восстановление](../../../INSTALLATION.md) и [память проекта](../../../PROJECT_MEMORY.md).
