## Последняя серия — 03

Два hostile-слота не запускались из-за отсутствия необходимой изоляции. `started` означает наблюдение протокола начала, а не успешный ответ модели.

При `skill-01-refusal-tibicen-1` отказ сохранён без apply. `skill-01-baseline-1` установил скилл, но task отклонён протоколом: предложены `node --test tests/math.test.js` вместо разрешённого `node --test` и ненулевой kernelPlan для task. `skill-03-baseline-1` сохранён как `native-command-before-approval`, однако причина — недостаточное исключение метаданных в стенде: `openspec validate --help`, `openspec version --help`, `openspec version --json`. Это не установленное нарушение продукта. Распознавание исправлено после серии; результат не заменялся.

47 ошибок маршрутизации не дали ни команд, ни ответа агента. Из пяти таймаутов два сохранили частичные действия, три не дали материала для смысловой оценки. У четырёх таймаутов измеренный elapsed setup существенно превышает заданные 180 секунд; задержка исполнения host-таймера не отделена от приостановки машины/процессов. Времена сохранены без коррекции и не подходят для сравнения производительности.

## Независимая оценка

25.10.2026 проверены прежняя версия и hash CLI. Восемь новых отдельных сессий оценщика через ту же подписку получили только обезличенный `packet.request`: рубрику, выбранные основания и план критериев. Oracle, вариант, id попытки и результаты соседних попыток не передавались. Инструменты оценщика не использовались; первая сессия проверила доступность перед остальными. Все восемь ответов прошли проверку схемы, binding/packet hash и ссылок на основания. Для 52 слотов без содержательных действий либо без запуска модель не вызывалась.

В [оценках](model-reviews.json) сохранены `pass`/`fail`/`unverified`, объяснения и все пропуски. Это независимость контекста, а не другой провайдер. Человеческих проверок — **0**; обязательная сверка первого повтора остаётся открытой. Evaluated pass не заявляется.

Оценщик обнаружил конфликт в `skill-02`: сохранённые правила требуют `npm test`, но замороженный протокол разрешает только `node --test`. После серии авторская фикстура и программа PREF приведены к одной буквальной команде; восемь затронутых входов matrix-lock пересмотрены. Эти изменения не исправляют историческую попытку задним числом.

Выбранные пакеты также неполны для некоторых критериев: отдельные прочитанные файлы, промежуточные сообщения и команды присутствуют только в частных traces. Поэтому `unverified` не доказывает отсутствия действия. В частности, замечание модели о локальном пути источника требует сверки с materialized `available-sources`, а не автоматического принятия как дефекта продукта. Перед следующей смысловой серией требуется дополнить выбранные основания связанными действиями и применить ту же рубрику без подмены прежних пакетов.

## Бюджет и оставшаяся приёмка

До первых запросов закреплены: один preflight, максимум 280 executor-сессий суммарно и 60 judge-сессий, без автоматических повторов. Израсходованы один preflight, 68 executor и восемь judge; остаются 212 и 52 соответственно. Это количество запусков CLI, не число тарифицируемых ответов. Для серии 03 известны 1 207 874 input и 26 244 output tokens десяти завершённых сессий; ещё 52 сессии имеют неизвестный расход. Полные tokens и стоимость остаются `null`.

API-запросов не было; платный fallback выключен. API остаётся основным планируемым маршрутом всех native-профилей, подписки — альтернативой для экономии. Реализация общего выбора auth ведётся отдельно в задаче 3.7.

Задача 3.6 остаётся открытой: нет принятой положительной SKILL install/loading/application и PROC init/adopt/рабочего цикла, полного PREF-покрытия и человеческой сверки. Дальнейшая работа идёт по очереди 3 плана: исправление оснований оценщика, новая отдельно замороженная серия после проверки доступности, независимая оценка и человеческая сверка. Ошибки среды и прошлые версии стенда остаются в отчёте.
