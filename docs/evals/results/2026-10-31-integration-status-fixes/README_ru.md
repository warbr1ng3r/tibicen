# Исправления статуса интеграции — 31 октября 2026 года

В текущей рабочей сборке исправлены три воспроизведённых дефекта первого выпуска. Новый адаптер, схема или зависимость не добавлялись. Это механические исправления, а не новая приёмка качества агента или человеческого пилота. [Канонический отчёт](README.md).

## Наблюдаемое поведение

| Условие | До исправления | Исправленное поведение |
|---|---|---|
| План resume пропускает обязательный незавершённый ручной шаг | Исходная сессия могла стать complete и потерять запись о незавершённом шаге | Resume отказывает до записи как при сохранённом state, так и после его очистки ручной сессией. Явно подтверждённое завершение, сохранённые pending-шаги, необязательные шаги и отдельный свежий apply сохраняют прежнюю семантику |
| MCP Claude/Cursor ссылается на переменную только в команде/аргументах | Планирование и проверка пропускали зависимость и возвращали configured-unverified даже при неизвестной доступности или отсутствующей переменной | Оба пути учитывают поддержанные имена переменных и различают неизвестный, неполный и доступный контекст запуска. Не-env placeholders Cursor исключены; байты конфига и решения о доверии не меняются |
| Имя сервера Codex с точкой вставлено как вложенные bare-ключи TOML | Другая таблица считалась применённым запрошенным блоком | Проверяется идентичность нужной таблицы; сгенерированный quoted-блок и alias одного bare-ключа поддерживаются |

Исправление Codex следует [семантике ключей TOML](https://toml.io/en/v1.0.0#keys). Проверки не обращались к личному конфигу агента, значениям окружения или настоящему MCP-серверу. Тесты ручных шагов не выполняют и не выдумывают внешнее действие.

## Проверки и ревью

- Root независимо от аудиторов исходников воспроизвёл все три дефекта в собственном минимальном окружении; точные прежние ошибки и одобрения тестового проекта сохранены.
- Recovery-тесты до исправления выявили оба пути пропуска; финальный файл проходит **36/36**. Регрессии MCP сначала выявили семь ошибок; после исправления и замечания ревью файл проходит **18/18**. Отдельные проверки CLI/integration/process прошли **38/38** до последнего исправления nullish-входа MCP.
- Независимое ponytail-review приняло защиту ядра. Ревью MCP нашло введённую регрессию ранее допустимого null envNames; nullish-fallback и две регрессии сырого JSON её исправили. Повторное ревью: **Ship**, исходное замечание сохранено.
- Финальный gate на закреплённых Node 24.15.0/pnpm 11.21.0 прошёл **728 тестов, ноль ошибок, один намеренный portable-пропуск**, за **76.364 секунды**. Он включает линтер, форматирование, типы, сборку сайта, строгую валидацию активных/архивных спецификаций и сборку поставки. Все **768** замороженных исходных файлов остались неизменными во время gate.
- Оба self-test скопированных поставок прошли вне checkout без Git в PATH и с правом чтения только скопированного дистрибутива. Их scope — доступность ресурсов, а не загрузка или поведение агента.

Использовались собственные HOME/TMP/package configs; отключена лишь ранее диагностированная автоустановка pnpm перед запуском. Ограничение офлайн было процедурным, без дополнительного внешнего sandbox ОС или заявления сетевой изоляции. Зависимости не устанавливались.

Отдельный read-only overlay покрытия привязывает прежние80имён проверок, пять прежних регрессий и13новых тестов к фактически прошедшим строкам этого gate и текущим хэшам исходников. Распределение67случаев и fixture locks не изменились; прежняя карта сохранена. Root независимо проверил overlay без повтора тестов. Semantic/человеческая приёмка остаётся отдельной и открытой.
