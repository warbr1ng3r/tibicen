## Ограничения

Неоформленный и нераспознанный вывод сравнивается строго. Интерпретатор закреплён
только по пути; привязка скрипта покрывает входной файл. Virtualenv не воспроизводится,
исключение его папок не изолирует импорты. Нативная загрузка, реальное прерывание
копирования, skills-update/стабильность lock и измеренная человеческая/причинная
польза остаются непроверенными. Синтетические CLI-согласия контролируемых фикстур
не являются удостоверенным человеческим согласием. Старые оценки не меняются.
Первая попытка автономной проверки не создала папку для вывода; сборщик исправлен
и повторён на неизменном кандидате. Продуктового провала не было.

Точные идентичности и проверки: [receipt.json](receipt.json).
