- Все четыре run прошли `validateRun`; оба исходных отчёта воспроизведены через `buildPairedReport` с совпадением digest. Проверены хэши inventories, frozen conditions и harness.

- Все 236 assertion hashes совпали. В каждой попытке независимые механические grades `setup-invariants`, `task-result` и `task-invariants` имеют pass: всего 12. Результат задачи связан с успешной host-проверкой экспортов; это не оценка качества рекомендации или ответа.
- В обеих Tibicen setup-попытках присутствуют `reviewed-kernel-service-intent`, `approved-kernel-artifact` и `kernel-service-receipt` с совпавшими expected/actual hashes. Baseline не использует kernel plan; отсутствие этих трёх assertions у него ожидаемо.
- В SKILL-01 у обоих вариантов зарегистрированы два чтения `.agents/skills/ponytail/SKILL.md` в task-сессиях. Их content hash совпадает с выбранным источником: `9badd22a32e19cb884e46dfa8d3aae82bb81dfa5484105b8b4f0262df823a509`. Это наблюдённое чтение инструкций, а смысловое применение ещё требует независимой оценки.
