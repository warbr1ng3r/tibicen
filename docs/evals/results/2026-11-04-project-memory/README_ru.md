## Интеграция и независимое ревью

Итоговый общий прогон: **767 успешных тестов, ноль ошибок, один намеренный пропуск**,
включая lint, форматирование, типы, сборку сайта и строгую валидацию OpenSpec.
Прогон выполнен до изменения только метаданных версии; последующая сборка 1.1.0
закреплёнными инструментами прошла. Четыре самопроверки распакованных скиллов вне
репозитория прошли на локальных Node 24.15.0 и 22.23.4 без Git в PATH.

Ошибки сохранены: первый общий прогон содержал четыре ошибки из-за прежнего числа
файлов и неполных паспортов механических фикстур. Исправлены фикстуры и счётчики,
проверки продукта не ослаблялись. Ранее исправлена ошибка типов. Независимое
Ponytail review обнаружило блокирующее чтение FIFO вместо manifest: теперь
используется существующее ограниченное чтение обычного файла. Регрессии для FIFO,
каталога, слишком большого и некорректного файла прошли. Ревьюер повторно проверил
исправление и вынес **Ship**. Итоговое точечное Ponytail review также приняло
исправления числа файлов/фикстур, проверку nullable в тесте и удаление неиспользуемого
CSS; замечаний не осталось.

Отдельный [пакет лендинга L1–L6](../../../../openspec/changes/archive/2026-11-05-clarify-landing-first-use/verification.md)
прошёл 41 проверку сайта, 86 браузерных проверок с одним прежним пропуском и
независимое Ponytail review. Он сохраняет установку опубликованной 1.0 и пока
не выложен.

## Поставка, миграция и восстановление

Локальные установка, обновление, восстановление резервной копии и удаление через
кэшированный `skills@1.7.4` прошли для тестовых HOME Codex, Claude Code и Cursor:
12 исходных команд установки и 24 проверки версии/ресурсов. Дополнительная
проверка зарегистрированной памяти ниже добавляет три команды: **всего 15**. Все 91 файла архива совпали
с распаковкой по байтам и режимам. Явный пропуск обновления локального источника
сохранён. Это не проверка публичной установки из Git или нативного поведения
памяти в остальных агентах.

Отдельная фикстура с зарегистрированной памятью остановлена после первой
одобренной записи через контрольную точку продукта (exit 73). Реальный CLI resume
отказал при изменённом ожидающем файле памяти с `tamper-suspect`, без записей.
После восстановления точных исходных байтов/режимов и повторного явного одобрения
root того же digest resume завершился: состояние схемы 4 удалено, manifest схемы 3
завершён, прежняя история сессий и 49 защищённых файлов сохранены. Добавленная позже
заметка успешно прошла структурную проверку. Дополнительный локальный цикл Codex
установка → обновление → удаление сохранил весь зарегистрированный проект, включая
память, новую заметку и manifest/историю, побайтно и с прежними режимами.

Читатели реальной опубликованной 1.0 отказали до записей для proposal 2, manifest 3
и ожидающего состояния 4. Прежние сценарии без памяти сохраняют форматы; проектам
с памятью нужен совместимый runtime. Контролируемый сбой проверяет восстановление,
но не является спонтанной ошибкой или выполнением прикладной задачи.
