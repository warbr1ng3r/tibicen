Независимые ревью каждого кейса приняли зафиксированные безопасность, артефакты и указанный содержательный охват. **Область из шести контекстов закрыта 6/6, без повторов.** Это не шесть принятых целых кейсов и не публичный выпуск 1.0.

## Привязка и метод

SHA256 inventory кандидата из 86 файлов — `37b384c03e7ea0b83a82960ec6512771d391c694ed312b60ac6b50ef26fa88a3`; SHA256 архива — `7fed7ad4d3e27cf169ac29384f0807b9beae5689e6df0dbd1b11bac499ec7e55`. Каждый кейс использовал точную копию adopt из 43 файлов в соседнем tooling, отдельно от оцениваемого проекта. Все шесть использовали неизменный default contained image/profile; позднейшая private-сборка process-образа здесь не применялась.

Фактический Codex CLI 0.157.0 запрашивал `gpt-6-astra`; сборка серверной модели не сообщалась. Использован существующий подписочный доступ только с access-token, без refresh, платного API, вызовов судьи и автоматических повторов. Лимиты каждой попытки: 180 секунд общего времени/45 секунд запуска и проверенный contained-профиль. Оператор явно передал пути скилла, сведения о текущем агенте и границы вызовов; это загрузка с помощью, не неявное обнаружение.

В проекцию вошли только канонический setup-запрос, существующий диалог и тела файлов проекта. Скрытые ожидания, будущие ответы и последующие задачи исключены. Два исполнителя прошли три пары **разных кейсов**, с root- и независимым ревью команд/эффектов перед следующим раундом. Это не сравнения baseline/treatment. В каждом кейсе зафиксирован один фактически наблюдавшийся native-контекст.

## Сохранность и ограничения

Фактические записи команд содержат только объявленные чтения и разрешённые first-party scan/practices/proposal. Все 308 материализованных экземпляров файлов и собранные байты/режимы 0644 сохранены; привязки 60 источников/38 preparation-файлов и cleanup прошли проверку. Записей, запуска приложения/тестов, установки и коммитов не наблюдалось. Независимые ревью учитывают точные чтения, а не одну доступность файлов.

Завершённый scan PREF-01 содержит фактический JSON шести файлов. Завершённый scan PROC-04-team действительно имеет пустой вывод при exit 0: учитываются только вызов и отдельные полные чтения проекта. Реальный результат scan и причина пустого события неизвестны; отказ CLI или дефект кода не установлены. Результат PREF-02 `source-unavailable`/version-unverified остаётся пробелом, а не свежей проверкой официальных источников.

Исторические 24/24, блок из четырёх попыток 4/4 и отдельный merged-skill 1/1 остаются закрытыми. Текущие process-command/planning, остальные требования решений/кандидата/платформ/сопровождения и публичной доставки учитываются отдельно. Надёжность повторов, причинное улучшение, человеческая польза и приёмка полного MVP отсюда не следуют.
