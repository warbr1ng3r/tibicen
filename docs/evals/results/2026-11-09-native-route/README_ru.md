Частный обход DNS сработал; текущие обычные проверки DNS/TLS тоже успешны. Синтетический проект — утилита сумм заказов из четырёх файлов без зависимостей. Использованы установленные AionCore 0.1.55/Aionrs 0.2.8 и Qwen3.6-35B-A3B через Polza с закреплённым Prime Intellect/fp8 без fallback. Ранее обычный DNS lookup завершался таймаутом. Текущие запросы без авторизации через обычные DNS/TLS к Example, Cloudflare и Polza получили HTTP 200; Polza с закреплённым адресом тоже вернула 200. Сейчас базовая связность исправна; это согласуется с перемежающимся прежним сбоем и не доказывает дефект Tibicen. Временный relay сохранял сквозной TLS без изменения ОС/аккаунта или поставляемого транспорта. Сохранены первый сбой bare Host/default port и неклассифицированный `socketFailure=1` исправленного контроля при остановке.

SSE завершился; по сети пришло не ноль байтов. Сохранена категория finish reason `other`, но не точное значение upstream или тело in-band ошибки. Пробелы обработки неизвестных finish reason/error objects в закреплённом [парсере Aionrs](https://raw.githubusercontent.com/iOfficeAI/aionrs/v0.2.8/crates/aion-providers/src/openai.rs) — возможная граница интерпретации, не доказанная причина upstream или исправление продукта. Polza описывает [результат для каждого параллельного tool call](https://raw.githubusercontent.com/polza-ai/docs/main/gaidy/tool-calling.mdx).

[Проверка истории провайдера](https://raw.githubusercontent.com/polza-ai/docs/main/api-reference/history/generations.mdx) без записи нашла две failed-записи генерации в точном окне 18:52:55–18:53:10 UTC: у каждой одна попытка, нулевая стоимость для клиента, null finish reason/usage. Это две последующие неудачные генерации; начальный ответ с вызовами инструментов не входит в это окно и не объявлен бесплатным. Два GET логов собственной проверки вернули HTTP 404; сырые тела/ID не сохранялись, настройки логирования/аккаунта не менялись. Подготовительный guard сравнения строк с долями секунды остановился до любых GET логов; этот сбой сохранён. Фактическая причина **не восстановлена**. Это чтение метаданных, не дополнительные model-вызовы.

До удаления совпали все 134 замороженных входа, новых файлов проекта не появилось, временный профиль/зашифрованная база удалены, порты 54386/57831 закрыты. При native-очистке наблюдался расход 0,66131663 ₽.
