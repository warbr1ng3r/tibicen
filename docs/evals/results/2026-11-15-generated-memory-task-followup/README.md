required memory to equal the original setup bytes. The ordinary agent had
legitimately replaced obsolete implementation facts with tested current facts;
the intended correction input was the **actual working project**, not untouched
notes.

Instead, a separate controller projection copied exactly the six accepted initial
outputs, including the actual updated memory, without changing their contents.
Its source hash, upstream result/acceptance hashes, input bytes/modes, prompt and
explicit deviation were reviewed and bound to the correction's prospective
permission before launch. No extra model call, answer source, resource allowance
or research question was introduced. The report does not claim that the frozen
preparation helper produced the correction input.

This is an evaluator preparation defect, not a product memory-maintenance failure.
It is retained rather than silently rewriting the controller or restoring stale
memory to obtain a clean run.
