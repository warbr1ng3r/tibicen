# Завершение нативного apply, 15 ноября 2026 года

**Нативное наблюдение с исправленным захватом прошло apply → verify → status →
report.** Все четыре настоящих результата CLI сохранены и независимо проверены
grader. [Прежняя оценка с пустым выводом](../2026-11-15-native-apply-capture/README.md)
остаётся неуспешной; это новое направленное наблюдение после требования владельца
завершить работу. [Индекс свидетельств](evidence.json) связывает приватные протоколы
и результаты.

Изменился способ вызова в проверке: один замороженный helper использует файловые
дескрипторы, проверяет ошибки/сигналы до status и сохраняет ограниченный вывод со
строгой проверкой UTF-8. Нативные ограничения и код продукта не менялись.
Входы — те же 66 файлов/режимов и дополнительный helper проверки; предложение из
двух файлов, root и digest сохранены. Запрос теперь явно выбирает исправленный
helper, поэтому это не повтор с неизменным запросом.

Сначала отдельно замороженный model-free контроль выполнил четыре настоящих вызова
CLI за **3,671 секунды** и прошёл проверку артефактов. Это свидетельство контроллера,
а не нативного успеха. Helper проверен одним положительным/четырьмя отрицательными
случаями; grader — одним положительным/четырнадцатью отрицательными. Независимое
ревью до запуска обнаружило и исправило пропуск привязки исходников до допуска
любого исполнения.

Затем свежая сессия Codex 0.157.0 завершилась за **43,228 секунды** (внешнее время
driver — **43,279 секунды**), usage — **125 922 входных / 725 выходных токенов**:

| Настоящий шаг CLI | Результат |
| --- | --- |
| apply | `complete`, exit 0 |
| verify | `passed`, exit 0; **только структура** |
| status | `complete`, exit 0 |
| report | `complete`, exit 0 |

Во всех captures непустой корректный JSON, нет ошибки дочернего процесса, сигнала
или ошибки захвата. Оба согласованных файла побайтно совпадают с планом при `0600`;
все **63 неизменяемых именованных входа** (включая helper) сохранили байты/режимы.
Manifest, usage, сессия и согласованная память совпадают; временный файл сессии
отсутствует. Независимое ревью событий сверило реальные вызовы helper агентом и их
вывод с captures; одна проверка артефактов не доказывает исполнение.

Оба контейнера остановлены, удалены и независимо подтверждены отсутствующими;
временный нативный HOME отсутствует. Все 66 входов хоста и 22 замороженных исходника
не изменились. Пакет использовал **одну модельную сессию по подписке, один model-free
контейнер, ноль повторов вызывающей стороны и ноль новых платных API-вызовов**.
Исторический учёт сгенерированной памяти теперь содержит семь нативных вызовов в
отдельных пакетах, а не всю историю проекта; usage исторического сбоя и денежная
стоимость неизвестны. Работающих заданий нет.

Пробел нативной приёмки вывода CLI для этой точной сгенерированной настройки закрыт.
Загрузка была с подсказкой; согласие — синтетическое согласие контроллера.
Структурная проверка не доказывает поведение приложения, человеческое согласие,
автозагрузку, человеческую пользу и поддержку каждого харнесса. Прежние наблюдения
работы/исправления/свежей задачи с памятью сохраняют собственные результаты и
ограничения. Далее — восстановление прерывания, сохранность adopt и использование
памяти другим харнессом. Обычное ревью GLM остаётся опциональной внешней работой,
а не блокером этого завершения.

В пакете изменились только приватные helpers проверки и парная документация.
Опубликованная **1.5.4** и собранный кандидат не менялись. Проверяются форматирование,
ссылки, идентичность свидетельств и пробелы; полный source gate после изменений
документации не повторялся. Предыдущий результат остаётся 1 148 пройденных тестов,
0 ошибок, 1 прежний пропуск. Коммит, push и релиз не заявляются.
