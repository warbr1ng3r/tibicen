# Подготовка выпуска Tibicen 1.7.1

Основная версия — [README.md](README.md).

19 ноября 2026 года. **Локальный кандидат готов; публикация ожидается.**
Публичной версией по умолчанию остаётся 1.7.0. Совместимый patch включает
проверенные исправления сравнения и guidance из
[независимой оценки](../2026-11-19-scenario-sweep-assessment/README.md).

## Объём

Нормализуются распознанные строки времени Node spec/TAP и Python unittest,
сохраняются значимые различия утверждений/названий тестов. Требуется одинаковый
ненулевой exit code. Guidance первого предложения выбирает фактический профиль,
отделяет предлагаемое доверие от согласия, требует проверенной готовности
и не принимает сгенерированные ответы/значения по умолчанию за внешнее согласие.

Миграции CLI/схемы, новых зависимостей, фонового сервиса и изменений приложения
пользователя нет. Старые хэши не переписываются. Неизвестные форматы сравниваются
строго. Проверка digest не удостоверяет личность согласовавшего.

## Кандидат и проверки

Версия 1.7.1, candidate-01: 114 payload / 115 файлов архива с режимами.
Архив, манифест и внешний SHA256SUMS заморожены. Точные идентификаторы
и состояния завершения — в [receipt.json](receipt.json).

Закреплённая offline-установка по lockfile, pnpm test и pnpm build прошли:
**1 187 всего / 1 185 passed / 0 failed / 2 прежних skip**.
Независимое Ponytail-ревью кандидата: Ship. Копии исходников, три ассета,
хэши/режимы и оба изолированных self-test ресурсов вне checkout с пустым PATH
прошли. Локальный lifecycle и публичные наблюдения записываются по завершении.

## Публичная поставка

Перенести только новые проверенные файлы поверх известной публичной истории;
приватную историю не пушить. Пройти публичный CI и шесть платформенных ячеек,
проверить реальную установку/обновление/восстановление/удаление по полному SHA.
Опубликовать annotated tag и три точных ассета, сравнить полученные байты,
обновить установочные/контрольные метаданные и отдельно проверить выкладку.
Владелец разрешил эту последовательность.

Первое DNS-разрешение не сработало; позже обычный доступ Git/API восстановился.
Существующий SSH-вход работает. Новые учётные данные не создаются. Браузерный
доступ отклонён политикой среды и не используется.
