## Conditions and observations

Both copies contained the same 482 public files from source `1cb52ab72d9a668be59659296c1dbf6aec8650fb`. Ordinary Codex ran first, then Tibicen; the earlier result was withheld. Both received the same request to assess infrastructure for full MVP work, preserve team decisions/process/application files, and stop at proposed edits. No writes, project commands, installation or network were authorized. This was an instruction-level boundary with hash checks, not OS isolation.

The Tibicen method additionally received the frozen installed `tibicen-adopt` from alpha.1 and permission for one exact first-party read-only scan. There were two app assessment sessions, no retries or external CLI model/API calls.
