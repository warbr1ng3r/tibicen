# Нативная задача Codex после исправления диагностики

28.10.2026 одна заново разрешённая подписочная сессия Codex CLI **остановилась до завершения полезной задачи**. Она неявно выбрала и прочитала точный установленный скилл Ponytail, затем контейнер сообщил о завершении процесса с кодом **1**. Новая диагностика сохранила это событие; конкретная неуспешная команда и причина остаются неизвестными. Повтора не было.

Это свежая копия и отдельно разрешённая попытка после [офлайн-исправления диагностики](../../../../openspec/changes/containerize-native-evaluation-execution/diagnostics-verification.md). [Прежняя неуспешная попытка](../2026-10-28-published-alpha-native/README.md) сохранена без изменений. Этот результат не подтверждает успех полезной задачи или полную MVP-приёмку.

## Входы и ограничения

Сгенерированный проект числовых функций восстанавливает девять точных файлов после настройки из прежнего published-alpha кейса: установленный Tibicen скилл Ponytail, его MIT-лицензию, AGENTS и исходный manifest. Настройка не повторялась. Ponytail закреплён на `DietrichGebert/ponytail@09c434ab73ca43761c5d8b0c5d341926c2fba710`; SHA256 тела — `9badd22a32e19cb884e46dfa8d3aae82bb81dfa5484105b8b4f0262df823a509`.

Обычная задача просит добавить `clamp(value, min, max)`, включительные границы, проверку конечных чисел, ошибку при обратном порядке границ, сохранить `double` и добавить целевые тесты. Она не называет Ponytail или команду чтения инструкций. В контейнере разрешены изменения только `src/numbers.js` и `tests/numbers.test.js`. Остальные семь входов защищены.

Закреплённая среда: Codex CLI 0.157.0 / `gpt-6-astra`, существующий изолированный подписочный маршрут, двадцать закреплённых исходников harness и принадлежащий прогону контейнер инструментов без сети. Digest freeze: `89323eeff8d95233f8e192216ab865b1a13fc8da510a7060b1b4e38420932483`. Лимит: одна сессия, 120 секунд с подготовкой, 45 секунд на запуск, без автоматического повтора, бюджет платного API — ноль. Число HTTP-запросов и токены не проверены; одна сессия не означает один HTTP-запрос. Login, OAuth и SDK не менялись.

Независимое предварительное `ponytail-review` одобрило точные хэши скрипта, протокола, freeze, oracle и grader. До запуска модели в приватном grader нашли и исправили гонку: Docker-команда начиналась раньше готовности контейнера. Исходная неуспешная проверка и её скрипт сохранены. Исправленный baseline прошёл два исходных теста; скрытый oracle отказал именно из-за отсутствия `clamp`. Оба контейнера офлайн-проверки остановлены и удалены. Oracle находится вне девяти входных файлов модели и проверяет обычные и предельные конечные значения, неверные аргументы, обратные границы и сохранение `double`.

## Свидетельства и продолжение

Рядом сохранены [обезличенные наблюдения](results.json). Приватные материалы содержат проверенные протокол/freeze, маркер единственной попытки, исходный и исправленный baseline, сырую нативную траекторию, итоговый результат, root-проверки сохранности и независимое приёмочное ревью. JSONL-траектория CLI и результат контейнера — разные каналы свидетельств; остановленный turn может не успеть выдать соответствующую неуспешную команду.

Целевые регрессии текущей среды прошли 17/17. Прежний полный офлайн-набор остаётся 700/700; во время попытки код среды не менялся, для изменений отчётов набор не повторялся. Root проверил ссылки, соответствие английской и русской версий, сохранность и отсутствие приватных путей. Независимые ревью артефактов и EN/RU документации дали **Ship для достоверного отчёта о неуспехе/частичных наблюдениях**; они не принимают полезную задачу или MVP.

Следующий шаг — офлайн-сопоставление первой ошибки исполнителя с вызвавшим её запросом по сохранённому событию и закреплённой реализации протокола. Ещё одна живая сессия требует новых проверенных freeze и лимита; этот результат не разрешает повтор. Код продукта/поставка, обратная запись на хост, коммиты и публикация не менялись.

Для общего контекста автоматизации CLI и учётных данных использованы официальные [non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode) и [authentication](https://learn.chatgpt.com/docs/auth). Эти документы не подтверждают доступ модели или приёмку этого прогона; их подтверждают наблюдения выше.
