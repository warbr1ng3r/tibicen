# Tibicen 1.4.0 — неопубликованный черновик

Tibicen помогает агенту настроить инструкции нового проекта или улучшить
существующую настройку через проверяемый план. Версия 1.4.0 добавляет объяснение
под конкретную задачу и локальную диагностику MCP, не ограничивая общий маршрут
списком названий харнессов.

## Изменения

- **Объяснение настройки для следующей задачи.** Необязательные сведения о
  харнессе/версии, рабочем каталоге и пути задачи проходят через отчёт и передачу
  работы init/adopt. Полезные области действия инструкций и решения памяти
  проекта сохраняются.
- **Диагностика локального MCP.** Один выбранный stdio-сервер изучается максимум
  в четырёх разрешённых файлах проекта ограниченного размера. Результат объясняет
  неопределённость источника, отключение и условия запуска, предлагая
  поддерживаемое исправление либо следующий шаг в нативной среде.
- **Общий путь для остальных харнессов.** Любой корректный ID позволяет выбрать
  известный формат либо передать очищенные наблюдения, связанные SHA-256 с
  изученным источником. Восемь явных контрактов охватывают Claude, Cursor,
  Gemini CLI, OpenCode V2, нативный/общий JSON ZCode, текущий JSON Kimi Code и
  ограниченный TOML Mistral Vibe.

Это совместимый минорный релиз. Прежние вызовы и сохраняемые схемы поддерживаются;
миграции и автоматического обновления проекта нет. Наблюдения передаются на время
запроса. Выбор формата не разрешает новую запись или запуск сервера; прежние
границы записи и одобрение точного плана сохранены.

## Установка и обновление

Итоговая команда должна фиксировать полный SHA принятого публичного дистрибутива
с `skills@1.7.4`, выбирая только `tibicen-init` и `tibicen-adopt` с универсальной
целью. Привязка ожидается; после публикации используйте каноническое
[руководство установки](../../../../README.md).
Перед явной заменой скиллов сохраните локальные правки. Для проверяемого изменения
конфигурации проекта отдельно запустите adopt.

## Проверки и ограничения

Зафиксированный `1.4-candidate-01` прошёл свежий полный gate: **891 тест прошёл**,
ноль ошибок, один ручной standalone пропущен. Пропущенный жизненный цикл запущен
отдельно: **3/3 прошли**, вместе с обеими самопроверками, 12 MCP CLI-кейсами и
отчётами с контекстом задачи/прежним вводом. Локальная универсальная замена
1.3→1.4, повтор, восстановление изменённых резервных копий в установленные
каталоги и удаление прошли независимую приёмку; проект, последующая память,
соседние скиллы и настройки сохранены.

Свежие наблюдения с переданными исходниками сохранили существующую конфигурацию
неизвестного харнесса и предложили однострочное исправление отсутствующей команды
проверки существующего проекта. Оба остановились до применения и прошли независимое
ревью результата. Итоговое инженерное ревью локального релиза вернуло Ship,
включая точный коммит дистрибутива. Локальный gate отобранного экспорта исходников
также прошёл 891 тест с одним ручным пропуском standalone. Публичный CI, шесть платформенных ячеек,
публичная установка по полному SHA/обновление/восстановление/удаление, полученные
файлы и Pages **ожидаются**. Это отдельные этапы после локальных проверок из
[отчёта релиза](README.md).

Разбор MCP и наблюдения, привязанные к источнику, не подтверждают нативную
активацию, подключение, обнаружение инструментов, поведение модели или
безопасность. Нативные приложения и полезность для людей в этом пакете не
оценивались. Общий маршрут наблюдений сохраняет эту неопределённость и не
заявляет универсальную нативную поддержку.
См. [форматы и свидетельства](../../../MCP_FORMATS.md).
