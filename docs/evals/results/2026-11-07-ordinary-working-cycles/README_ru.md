# Обычные рабочие циклы с Tibicen 1.5.1

**Остановлено; ни один полный рабочий цикл не принят.** Два реальных предложения приняты; следующая сессия применения в очереди завершилась ошибкой до команд и сообщений, после чего замороженный оценщик остановил весь пакет. Все 24 проверки без модели остаются пройденными. Срез: `2026-11-07T20:10:54+00:00`. Канонический текст: [English report](README.md).

Проверяем простую последовательность: попросить настроить агента, одобрить фактическое предложение, выполнить полезную задачу в новой сессии, затем спросить, нужно ли ещё менять настройку. Это четыре небольших сгенерированных проекта, а не человеческий пилот или сравнение с другим продуктом. Ниже сохранены реальные формулировки запросов. Подготовлены все двенадцать; завершённые ответы получены только на два исходных запроса настройки. Ни полезная задача, ни повторная проверка не запускались. Активация скилла и разрешения среды задавались отдельно.

Строки **«Что уже было»** описывают подготовленный проект до локальной установки 110 опубликованных файлов Tibicen. Фактический вход агента включал их: 116 файлов для очереди, 118 для Bash, 122 для TypeScript и 117 для сборника документации. Последние два проекта были подготовлены, но агент в них не запускался.

## Где остановился фактический прогон

| Сессия агента | Время агента | Наблюдавшийся результат |
| --- | ---: | --- |
| Предложение настройки очереди | 73,126 с | Фактическое CLI-предложение и запрос согласия приняты root и независимым ревью; проект не менялся |
| Предложение настройки Bash | 90,857 с | Две точные правки инструкций и сохранение существующей памяти приняты root и независимым ревью; проект не менялся |
| Одобренное применение в очереди | 37,061 с | `error` / `turn.failed`, `pass: false`, код выхода `null`, команд и сообщений нет; одобренный AGENTS не создан |

Причина ошибки агента **неизвестна**: вместо деталей сохранены обезличенные хэши, stderr пуст. Вызовов CLI Tibicen apply, verify, status и report не наблюдалось. Затем приватный оценщик потребовал результат успешного применения до обработки неуспешной сессии; проверка отсутствующего `AGENTS.md` превратила отказ без изменений в **общий STOP**. Такая ошибка порядка проверок не доказывает дефект применения продукта; исходный STOP остаётся обязательным.

Все **117 входных файлов и их права остались прежними**; лишних файлов, AGENTS, manifest и state не появилось. Остановка и удаление контейнера, сохранность хостовых копий, исходников и конфигурации проверены. Затем root удалил проверенные хостовые копии из принадлежащего прогону каталога; исходные артефакты сохранены. Пакет агента **закрыт: три вызова агента и два контейнера без модели** (проверка среды и оценщика). Подготовка применения Bash заблокирована до исполнения. Настройка TypeScript/документации, все полезные задачи, их отдельные проверки и повторы не запускались. Повторных запусков и переоценки не было.

## Выполненные проверки и границы наблюдения

Используется точная опубликованная [поставка 1.5.1](../2026-11-07-release-1.5.1/README.md): по 55 файлов на скилл, всего 110 файлов, коммит дистрибутива `287ef7b22630482aca7996e5a0faad601cede778`. Оба полных скилла размещаются внутри каждого проекта; это наблюдение локальной установки, а не поиска скиллов в глобальном домашнем каталоге. Используется существующая подписочная среда Codex CLI 0.157.0 с запрошенной моделью `gpt-6-astra`, Node 24.15.0 и Bash 5.2.15. Python отсутствовал, поэтому выбран Bash, а подготовка CSV/Python не используется. Зависимости и новый образ не устанавливались.

Контейнер проверок оценщика завершился один раз за **3,709 секунды**: четыре базовых проекта, четыре правильные реализации и шестнадцать отрицательных вариантов с проверкой конкретной причины отказа. Все 228 входных файлов и их права сохранены, включая приватный и исполняемый контрольные файлы; остановка и удаление контейнера проверены. Root принял фактический результат. Более ранняя подготовка C01 остановилась из-за представления JSON до исполнения; исправление сериализации и исходный STOP сохранены. Ни один подготовительный шаг не засчитывается как результат работы агента.

У остановленного пакета был предварительный предел: двадцать сессий агента / 2280 секунд на четыре случая, включая необязательные уточнения, с нулевым бюджетом платного API и без автоматических повторов. Запущены три вызова агента. Неиспользованные слоты не разрешают продолжение. Фактические предложения и точное согласие root сохранены; сессия очереди явно получила одобренный артефакт, но не выполнила ни одной команды. Проверки полезных задач и повторы без изменения настройки планировались, но не запускались. Предел проверочных контейнеров был восемь, включая проверку среды и ограниченные попытки подготовки оценщика до запуска агента, с пределом 20 секунд на каждую проверку. Из проверок без модели выполнены только проверка среды и успешные проверки оценщика.

Обычный запрос не принуждается к конкретному режиму CLI: из-за предустановленных скиллов первая настройка инструкций может определиться как improve. Успешная задача не доказывает, что инструкции были загружены, вызвали результат, принесли пользу человеку или работают во всех других моделях и средах агентов. Утверждения об использовании инструкций и памяти требуют фактических свидетельств. Сравнительной ветки, измерения пользы реальными пользователями, публикации и изменения глобальной конфигурации агентов здесь нет. Метод описан в [native-run guide](../../NATIVE_RUNS.md).

## Отдельная проверка CLI без модели — выполнена

Два отдельно одобренных одноразовых контейнера применили неизменённые планы очереди и Bash напрямую опубликованным CLI 1.5.1 `2026-11-07`, за 3,834 с и 1,976 с соответственно (предел 20 с на каждый). Это **два дополнительных контейнера**, без сессий модели, чтения/изменения авторизации, сети, установок или выполнения приложения. Они не входят в закрытый пакет агента и не завершают и не переоценивают его три вызова.

| Случай | Фактический CLI и собранный результат |
| --- | --- |
| Очередь | `apply → verify → status → report`, все коды выхода `0`. Добавлен точно одобренный `AGENTS.md` с правами `0600`. Apply, status и report вернули `complete`; проверка инфраструктуры — `passed`, `structure-only`. |
| Bash | Те же четыре команды CLI, все коды выхода `0`. Обе точно одобренные правки инструкций записаны с правами `0644`. Существующая `.agents/memory.md` сохранена побайтно с правами `0600`. Apply, status и report вернули `complete`; проверка инфраструктуры — `passed`, `structure-only`. |

Фиксированная программа проверки прочитала фактические итоговые инструкции и существующую память Bash. До применения проверены оба полных набора входных файлов (117/119, включая одобренное предложение); после него сохранены все защищённые байты и права, включая все 110 файлов runtime. В отчётах остаются `verify:unverified/no-project-checks` и `task`/`quiz:unverified/not-requested`; compat не содержит пар, MCP — проб. Структурное завершение не доказывает прохождение тестов приложения, использование инструкций или памяти новым агентом, успех полезной задачи, стабильность повторной настройки или пользу человеку.
