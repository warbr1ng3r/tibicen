# Независимая оценка полученного прогона сценариев 1.7.0

Оценка от 19 ноября 2026 года охватывает подписочный пакет ZCode/GLM
`scenario-sweep-1.7.0-20261118` и интеграцию двух предложенных исправлений.
Это не новый поведенческий прогон, не переписывание исходных результатов и не
релиз. Опубликованная 1.7.0 и исходный пакет сохранены.

## Что подтверждают свидетельства

Итог исполнителя — **46 passed, один с помощью (D5), один заблокирован (G5),
ноль failed** из 48 пунктов каталога. Это полезные функциональные наблюдения,
а не 46 независимо принятых сквозных сценариев. По
[инвариантам продукта](../../../PRODUCT_VISION.md) неудачные попытки согласования
остаются неудачными, даже если позже получились полезные файлы.

| Область | Независимая оценка |
| --- | --- |
| Целостность | Все 151 замороженный вход сохранили хэши и режимы. Оба дерева/архива совпадают с описями по 115 записей. Исходник и reference совпадают с candidate-02. Патч из 16 файлов совпадает с незакоммиченным worktree исполнителя. |

По отчёту пакета после уточнения про опросник в 20+ сессиях самосогласования
больше не было. Реальные тексты этих запусков и новая ревизия протокола не
сохранены. Это сообщённая связь, а не доказательство устранения проблемы.
Механизм выдуманных ответов в хосте неизвестен. Это сбои надёжности агентского
пути/хоста; существующий запрет в скилле не делает их заведомо чужими продукту.

Сохранены только шесть сводок setup-исполнителей и одна сводка проверки
возможностей. Большинство поздних потоков исполнителей/ревью и структурированные
записи внешнего согласия отсутствуют. 40 контекстов, 26 продолжений, параллельность
и около 5,2 часа сообщены координатором. Денежная стоимость подписки неизвестна;
пакет сообщает нулевые расходы платного API. При интеграции новых поведенческих
и платных API-вызовов не было. Независимый общий счётчик успешных кейсов не выдуман.

## Исправления после ревью

1. **Существующие ошибки с меняющимся временем.** Репро исполнителя подтверждает
   ошибочный `changed-failure` из-за длительности. Его фильтр по всему тексту
   также стирал значимые различия утверждений `(1s)` и `(5s)`. Root воспроизвёл
   пропуск и ограничил обработку распознаваемыми строками/контекстом Node spec/TAP
   и Python unittest. Имена тестов, значения, счётчики и неизвестные форматы
   по-прежнему сравниваются строго.
2. **Смена кода ошибки.** Ревью нашло существующий пробел: одинаковый вывод при
   смене exit code с 1 на 2 считался прежней ошибкой. Регрессия сначала упала на
   старом коде; теперь `pre-existing-red` требует одинакового ненулевого кода.
3. **Доверие и готовность в первом предложении.** Точный первый план может
   предлагать доверие командам; готовность задаётся только по проверенным фактам.
   Root убрал общий жёсткий `web`, чтобы Bash/Python/docs выбирали фактический
   профиль. Собственный опросник исполнителя, сгенерированный ответ, значение по
   умолчанию и разрешение инструмента явно отделены от внешнего ответа о согласии.
   CLI по-прежнему удостоверяет digest, а не личность согласовавшего.

Сохранённый manifest RET1 имеет green/complete, его guidance совпадает с
candidate-02; проверочный исходник отличается только комментарием. Первое
предложение и журнал согласия отсутствуют, поэтому один цикл согласования остаётся
сообщением исполнителя. Для исправленного root-текста **нового поведенческого
наблюдения в свежей сессии нет**. Более явное правило остаётся инструкцией,
а не техническим удостоверением личности человека.

Требования и задачи находятся в
[стабилизации сравнения](../../../../openspec/changes/stabilize-check-failure-comparison/proposal.md)
и [правилах первого предложения](../../../../openspec/changes/clarify-first-proposal-check-trust/proposal.md).
Их verification хранит финальные локальные проверки. Исходный кандидат с широким
фильтром сохранён и не является исправленной интеграционной сборкой.

## Привязка исходников и локальные проверки

[receipt.json](receipt.json) содержит точные исходные идентификаторы, хэши выбранных
сырых артефактов, оценки по областям и результаты локальных проверок.
Приватные потоки и пути песочниц остаются вне репозитория. SHA-256 принятого патча:
`58a87427ac85647ecd84ef1609160823f8c26ebbcb87e2cbc86ba9dddc66446e`.

Локальная интеграция завершена: сфокусированные проверки **19/19**, полный
`pnpm test` **1 185 passed / 0 failed / 2 прежних skip** (1 187 всего), строгая
OpenSpec-валидация 48 активных пунктов / 20 архивов, независимое Ponytail-ревью
и оба изолированных self-test ресурсов прошли. Вторая сборка вне checkout
совпала со сборкой gate: **114 payload-хэшей / 115 файлов всего**. Байты
runtime/reference совпадают в обоих скиллах. Финальный guard замороженных
входов исходного пакета прошёл.

Эти проверки не доказывают автозагрузку, человеческое согласие, измеренную пользу,
исполнение Windows-политики или повтор всех 48 сценариев. В интеграцию не входят
версия, коммит, push, тег, ассет релиза и выкладка сайта.

## Следующая ограниченная работа

Сначала поставить проверенные совместимые исправления отдельным разрешённым
patch-релизом. Затем адресно проверить сбой канала согласия, сохраняя внешние
разрешения, конверты, авторство и реальные запросы, не стирая неудачные попытки.
Закрывать именно пропущенные варианты A5/F3/H6 и среду G5 по доступности условий.
Больше названий моделей не восполнит эти свидетельства. Нативная загрузка
инструкций и добровольная оценка человеческой пользы остаются отдельными вопросами.
