# Второй харнесс: AionCore — setup HOLD, свежая задача с помощью оператора PASS

**Автономная настройка так и не дала настоящего предложения CLI Tibicen и digest.** Отдельная настройка, созданная оператором, позволила успешно выполнить полезную задачу в новой беседе AionCore. Это разные результаты: задача не превращает прежние попытки настройки в успешные. Ограниченная работа завершена с сохранённым пробелом покрытия setup.

Маршрут использовал **AionCore 0.1.55 / aionrs 0.2.8** с уже настроенным ключом Polza.ai. Ранние проверки выбрали **Qwen3-32B / `deepinfra/fp8`**; поздние проверки и новая задача использовали **Qwen3.6-35B-A3B / `primeintellect/fp8`**, без переключения провайдера. Владелец разрешил **100 ₽ суммарно**.

Созданная оператором утилита суммы заказа начиналась с четырёх файлов JavaScript-проекта без зависимостей, инструкций и памяти; три исходных теста прошли. Первые проверки установили все **110 файлов опубликованного Tibicen 1.5.4** в изолированный глобальный профиль вне проекта; исходники поддерживают этот [глобальный каталог skills](https://raw.githubusercontent.com/iOfficeAI/aionrs/v0.2.8/crates/aion-skills/src/paths.rs). Runs 07–08 использовали локальную сборку **Unreleased**: 110 файлов, 106 неизменённых и 4 изменённых текстовых — два SKILL и две копии architecture-reference. Изменились три абзаца guidance; прошли 17 офлайн-проверок, одна ручная пропущена. Опубликованная 1.5.4 не изменена.

| Попытка | Фактический результат |
| --- | --- |
| Локальная модель | Официальные веса Qwen3-4B проверены; запуск не удался до инференса; маршрут закрыт |
| Проверки провайдера | Принудительный выбор Qwen3.5 вернул 400; автоматический достиг 64 токенов. Qwen3-32B дал корректный вызов инструмента |
| Нативный run03 | Общий план, 0 инструментов/CLI |

Ранняя отдельная проверка backend прошла за **512,694 мс**, синтетическая проверка границ — за **248,524 мс**, с проверками сохранности и очистки. Передача официального [Qwen3-4B Q4_K_M](https://huggingface.co/Qwen/Qwen3-4B-GGUF/blob/bc640142c66e1fdd12af0bd68f40445458f3869b/README.md) потребовала отдельно проверенного продолжения после таймаута. Собранный файл прошёл проверку целостности, но запуск сообщил **«no backends are loaded»**. Около 5 ГБ ресурсов удалены после совпадения 128 входов. Поздний сбой компиляции API-политики остаётся отдельной ошибкой подготовки.

В отдельной ветке оператор создал минимальный корневой AGENTS из четырёх фактов проекта, независимо проверил настоящий CLI-план и дал искусственное точное согласие. Это не нативное предложение/применение и не согласие человека. Проверка инфраструктуры была структурной; проверки приложения остались `unverified`/`no-project-checks`.

Новый запрос добавлял валидируемую необязательную процентную скидку, округление итоговой суммы и обратную совместимость. Модель изменила исходник и тесты. Первый запуск провалил один из 11 тестов из-за неверных новых ожиданий; модель сама их исправила и получила 11/11. Независимый oracle прошёл **10 положительных, 14 невалидных случаев и проверки неизменяемости**. Ревью воспроизвело все три правки и сравнило зафиксированные байты/режимы: оператор не исправлял результат. Прямого чтения AGENTS не наблюдалось, поэтому использование инструкций или причинная польза не доказаны.

Защищённые файлы проекта и **134 зафиксированных входа** сохранены. Хост остановлен, порт закрыт, временный профиль, зашифрованная база и staging draft удалены; личные ресурсы не удалялись. Последний наблюдаемый суммарный расход API — **0,63553834 ₽**, около 0,64 ₽. Три последующих GET только метаданных завершились таймаутом, поэтому независимый окончательный расчёт не подтверждён.

Явные подсказки чтения, установка и настройка оператора были помощью. Aionrs способен тихо финализировать ответ по лимиту раундов LLM; влияние этого лимита на ранние остановки не установлено. Допущение watcher v1 о монотонности расхода не было обосновано и не доказывало превышения бюджета. Внутренние повторы провайдера отличаются от повторной отправки клиентом. Полный нативный setup, общее покрытие харнессов, повторное использование памяти и польза для человека не заявляются.
