# Установка и явная загрузка Tibicen

Tibicen предоставляет `tibicen-init` для первой настройки и `tibicen-adopt` для
улучшения существующей агентской инфраструктуры. Используйте их в среде, которая
читает файлы проекта, весь установленный скилл и запускает его Node CLI. Модель и
провайдера выбирает среда; отдельный аккаунт модели или API-ключ Tibicen не нужен.

Этот общий путь запуска — работа в исходниках/Unreleased. Команды и файлы ниже
по-прежнему устанавливают **опубликованную 1.2.0**, а не неопубликованный кандидат
1.3. Механические проверки опубликованного релиза охватывали Codex, Claude Code и
Cursor. Явное чтение не подтверждает нативное обнаружение, автоматическое
использование или наблюдаемый результат для другой среды/модели. См.
[область релиза](RELEASING.md#published-120--5-november-2026-utc).

## Требования

- Опубликованной 1.2.0 нужен Node **≥22.20** для установленного CLI. Обычному
  установщику также нужны Git и npm, pnpm или Yarn 2+. Для архива не нужны Git,
  менеджер пакетов, исходный репозиторий и зависимости разработки.
- Среде нужен доступ к целевому проекту и файлам скилла. Она должна запускать
  нужные Node-операции; иначе согласованные команды выполняет локальный оператор
  и передаёт фактический результат. Текстовый чат может дать рекомендации, но без
  локальных операций не изучит непрочитанные файлы и не применит изменения.
- Запись в проект, установки и проектные команды требуют согласия на точный
  план. На Windows Tibicen не запускает build/test/lint-команды проекта; чтение
  доступно. Недоступную проверку нельзя считать пройденной. У нативной загрузки и
  поведенческих проверок есть собственные ограничения.

## Установка в общую папку

Выполните в терминале, независимо от пакетов проекта:

```sh
npx skills@1.7.4 add https://github.com/warbr1ng3r/tibicen/tree/0656f12e00ea83d84229180d331f3178bf253407 -g --agent universal --skill tibicen-init tibicen-adopt --copy
```

Для pnpm замените только `npx` на `pnpm dlx`, для Yarn 2+ — на `yarn dlx`.
Сохраните `--agent universal`, оба имени скиллов, полный SHA дистрибутива и
`--copy`. Закреплённый установщик размещает полные папки здесь:

```text
~/.agents/skills/tibicen-init/
~/.agents/skills/tibicen-adopt/
```

`~` — домашняя папка (`$HOME` на macOS/Linux, `$env:USERPROFILE` в PowerShell).
Общая папка служит явным источником файлов скилла; среда не обязана обнаруживать
её автоматически. Не убирайте `--agent` и не подставляйте `--all`, `*` или
выдуманный флаг агента: это меняет выбор целей установщика. Для другого места
используйте ручной путь.

Переустановка заменяет эти папки скиллов. Заранее скопируйте полные папки с
локальными правками за пределы места установки. Установщик не обновляет
согласованные инструкции проекта. См. [обновление и удаление](INSTALLATION.md#update-and-removal).

## Первая сессия в проекте

Откройте целевой проект в своей среде. Отправьте подходящий обычный запрос:

```text
Прочитай ~/.agents/skills/tibicen-init/SKILL.md и следуй его инструкциям.
Подготовь этот проект для моего агента.
```

```text
Прочитай ~/.agents/skills/tibicen-adopt/SKILL.md и следуй его инструкциям.
Проверь инструкции проекта и исправь устаревшее.
```

Замените `~` абсолютным домашним путём, если среда его не раскрывает. Для ручной
установки подставьте выбранную папку. Если среда принимает только вложения,
прикрепите файл скилла способом из её документации и дайте доступ к остальной
папке. Одного `SKILL.md` недостаточно: должны быть доступны связанные инструкции
и `scripts/tibicen.ts`. Пути ресурсов разрешаются от установленной папки скилла,
а не от рабочей папки целевого проекта.

Перед согласием проверьте предложенные файлы, команды и ручные шаги. Если хватает
одного общего `AGENTS.md`, сохраните этот файл и существующее хранилище памяти.
В следующих сессиях явно просите среду читать согласованный `AGENTS.md` проекта,
если автоматическая загрузка неизвестна. Отсутствие нативного пробника не даёт
новых прав и не превращает явное чтение в нативное обнаружение. Подробнее:
[переносимый процесс](HARNESS_PORTABILITY.md).

## Ручная установка из архива

Выберите **новую пустую папку** под вашим контролем; в пути могут быть пробелы.
Не распаковывайте поверх существующих скиллов и файлов приложения. Скачайте в
эту папку следующие файлы одного опубликованного релиза:

| Файл | SHA256 |
| --- | --- |
| [tibicen-1.2.0.tar.gz](https://github.com/warbr1ng3r/tibicen/releases/download/v1.2.0/tibicen-1.2.0.tar.gz) | `fa33bdfbad280cba71b199671e280d71fcda1fc0b568b66130b0a1036aba47d9` |
| [distribution-SHA256SUMS](https://github.com/warbr1ng3r/tibicen/releases/download/v1.2.0/distribution-SHA256SUMS) | `9c4853a038fec91a37ad430e50184ef3364e9ebb1f7569ff2010ba7a39cb70c5` |
| [SHA256SUMS](https://github.com/warbr1ng3r/tibicen/releases/download/v1.2.0/SHA256SUMS) | `b81625fc6b24efd63a5b655e0f7d58a3fc76e2168e3b43c176daac8d2e527772` |

Например, на macOS/Linux после перехода в выбранную пустую папку:

```sh
curl -fLO https://github.com/warbr1ng3r/tibicen/releases/download/v1.2.0/tibicen-1.2.0.tar.gz &&
curl -fLO https://github.com/warbr1ng3r/tibicen/releases/download/v1.2.0/distribution-SHA256SUMS &&
curl -fLO https://github.com/warbr1ng3r/tibicen/releases/download/v1.2.0/SHA256SUMS &&
shasum -a 256 SHA256SUMS
```

До использования манифеста сравните последнюю сумму с таблицей. Затем проверьте
оба скачанных файла, распакуйте архив и проверьте все файлы дистрибутива:

```sh
shasum -a 256 -c SHA256SUMS &&
mkdir unpacked &&
tar -xzf tibicen-1.2.0.tar.gz -C unpacked &&
cd unpacked &&
cmp ../distribution-SHA256SUMS SHA256SUMS &&
shasum -a 256 -c SHA256SUMS
```

На Linux вместо `shasum -a 256` можно использовать `sha256sum`. При ошибке
скачивания, несовпадении суммы или ошибке распаковки остановитесь; не переходите
к загрузке. Эти суммы проверяют опубликованные байты, а не подпись или
совместимость среды.

На Windows скачайте те же три файла по ссылкам в выбранную пустую папку. В
PowerShell сначала выполните `Get-FileHash .\SHA256SUMS -Algorithm SHA256` и
сравните сумму с таблицей. Затем проверьте две записи, распакуйте архив и
проверьте дистрибутив (немедленно остановитесь при ошибке команды):

```powershell
$ErrorActionPreference = 'Stop'
Get-Content .\SHA256SUMS | ForEach-Object {
  $expected, $relative = $_ -split '  ', 2
  if ((Get-FileHash -LiteralPath $relative -Algorithm SHA256).Hash.ToLower() -ne $expected) { throw "Checksum mismatch: $relative" }
}
New-Item -ItemType Directory unpacked
tar -xzf tibicen-1.2.0.tar.gz -C unpacked
if ($LASTEXITCODE -ne 0) { throw 'Archive extraction failed' }
if ((Get-FileHash .\distribution-SHA256SUMS).Hash -ne (Get-FileHash .\unpacked\SHA256SUMS).Hash) { throw 'Payload manifest mismatch' }
Set-Location unpacked
Get-Content .\SHA256SUMS | ForEach-Object {
  $expected, $relative = $_ -split '  ', 2
  if ((Get-FileHash -LiteralPath $relative -Algorithm SHA256).Hash.ToLower() -ne $expected) { throw "Checksum mismatch: $relative" }
}
```

Распакованная папка содержит `tibicen-init/`, `tibicen-adopt/` и `SHA256SUMS`.
Сохраните **обе папки скиллов целиком**, включая `SKILL.md`, `scripts/`,
`references/`, `package.json` и `LICENSE` каждой. Их можно оставить здесь или
целиком скопировать в другое выбранное место. Если среда документирует нативную
папку, следуйте её документации; эта инструкция не угадывает такой путь.

Для папки `/Users/me/Tibicen 1.2.0/unpacked` явные файлы входа:

```text
/Users/me/Tibicen 1.2.0/unpacked/tibicen-init/SKILL.md
/Users/me/Tibicen 1.2.0/unpacked/tibicen-adopt/SKILL.md
```

Подставьте фактические пути в [запросы первой сессии](INSTALLATION.md#first-project-session).
На Windows укажите свой путь, например
`C:\Users\me\Tibicen 1.2.0\unpacked\tibicen-init\SKILL.md`. При вызове CLI в
терминале заключайте пути с пробелами в кавычки:

```sh
node "/Users/me/Tibicen 1.2.0/unpacked/tibicen-init/scripts/tibicen.ts" self-test
node "/Users/me/Tibicen 1.2.0/unpacked/tibicen-adopt/scripts/tibicen.ts" self-test
```

Эти локальные самопроверки проверяют установленное ядро и ресурсы. Они не
доказывают, что среда/модель загрузила скилл или выполнила задачу проекта.

## Обновление и удаление

Фонового обновления нет. Перед заменой на явно выбранный релиз сохраните полную
копию каждой установленной папки скилла. Для возврата локальных правок удалите
папку замены и скопируйте соответствующую полную резервную папку обратно в тот
же корень скиллов. Сохраните соседние скиллы и посторонние настройки среды.

Для удаления общей установки удалите только две установленные папки
`~/.agents/skills/tibicen-init` и `~/.agents/skills/tibicen-adopt`. Для ручной
установки удалите эти две папки из выбранного места. Остальные файлы сохраните.
Удаление скилла не отменяет инструкции, state и память проекта; их изменение
остаётся отдельной проверяемой операцией в проекте.

Для отдельного пути разработки см. [сборку из исходников](../README.md#build-and-install-from-source).
Не устанавливайте из корня несобранного репозитория.
