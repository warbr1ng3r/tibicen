## Next priorities

Use direct CLI execution for captured proposals and check child-process errors before parsing. A new native diagnostic observed `EPERM` on a nested launch while direct execution succeeded; the older capture cause and the responsible system layer remain unknown. Broader harness coverage requires a concrete authorized route; static candidates alone do not establish readiness.

Voluntary use on real projects can measure necessary user corrections, time to a useful task and repeated use. The [quality metrics](PRODUCT_VISION.md#14-usefulness-and-quality-metrics) distinguish these observations from engineering checks.

Further adapters, application verification profiles, MCP health checks and third-party libraries stay behind a demonstrated user need and their own scope. This package includes no paid API, personal authentication changes, purchases, external posts or new release.
