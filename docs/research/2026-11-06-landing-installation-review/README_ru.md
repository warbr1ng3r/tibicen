# Как показать установку: один основной путь

Проверено **6 ноября 2026 года**. [Основной отчёт на английском](README.md); рядом поддерживается русский перевод. Это ограниченное сравнение и предложение изменений, а не реализация или исследование конверсии.

**Рекомендация:** показывать в Tibicen одну проверенную команду установки с кнопкой копирования, а сразу после неё — запрос, который нужно отправить агенту. Предпочтения npm/pnpm/Yarn и установку из архива вынести под одну ссылку «Другие способы установки». Сохранить точную версию установщика, ревизию дистрибутива, выбор обоих скиллов и копирование полных папок из принятой команды.

## Какие решения сейчас приходится принимать посетителю Tibicen

В локальном [компоненте установки](../../../landing/src/components/Installation.astro) есть селектор **трёх способов запуска команды**: npm (`npx`), pnpm (`pnpm dlx`) и Yarn 2+ (`yarn dlx`). Это три запуска одного закреплённого установщика в одну папку, а не три разных продукта Tibicen. [Генератор команды](../../../landing/src/scripts/install.ts) всегда выбирает оба скилла, универсальную папку и копирование полных каталогов. Ручная установка из архива уже вынесена в ссылку на документацию.

Текущая команда по умолчанию:

```sh
npx skills@1.7.4 add https://github.com/warbr1ng3r/tibicen/tree/7b3b08f58276034b1609e44ef393e5f7c0e01a1b -g --agent universal --skill tibicen-init tibicen-adopt --copy
```

[Руководство установки](../../INSTALLATION.md) объясняет проверенную область и пути файлов. Публичный URL Tibicen не удалось получить веб-инструментом во время сравнения; поэтому наблюдения о Tibicen здесь основаны на проверенном локальном исходном коде 1.4.0, а не на заявлении о новом просмотре сайта в браузере.

Лишний первый выбор — «чем запускать?», когда посетитель ещё не попробовал продукт. Полезный выбор дальше — настроить проект впервые или исправить существующую настройку. Кроме того, в текущем [исходном коде страницы](../../../landing/src/components/Landing.astro) отдельно представлены копирование команды, открытие установленного скилла, выбор задачи и отправка запроса. Понятнее показать первую сессию как непрерывную последовательность. Это редакторская оценка структуры, а не измерение поведения пользователей.

## Что предлагается изменить

1. **Оставить один основной путь.** Написать «Установите оба скилла», показать текущую точную команду `npx` и одну кнопку копирования. Сохранить существенные требования: Node ≥22.20 и Git для этого установщика. В проекте может использоваться pnpm, а разовую установку можно запускать через npx: продукту не обязательно наследовать пакетный менеджер проекта.
2. **Сразу показать следующее действие.** Открыть проект в привычном агенте и отправить запрос с явным путём установленного скилла. Оставить выбор новой или существующей настройки как выбор задачи обычными словами. Установка файлов сама по себе не доказывает, что среда их загрузила.
3. **Перенести альтернативы в руководство.** Одна ссылка «Другие способы установки» может содержать pnpm, Yarn 2+, архив, контрольные суммы и нестандартные пути. Обновление, удаление и подробные свидетельства совместимости тоже относятся к документации. Не удалять само руководство и сведения о восстановлении.
4. **Показывать ограничения в нужном месте.** Рядом с первым использованием уместны короткое требование доступа к файлам/Node и ссылка на совместимость. Native-автозагрузка остаётся экспериментальной. Универсальное распространение не означает, что проверены все среды, модели и native-плагины.
5. **Сохранить принятый механизм поставки.** Не сокращать исполняемую команду до `npx skills add warbr1ng3r/tibicen` и не подменять принятую ревизию незакреплённой основной веткой ради внешнего вида. Не добавлять новый curl-установщик, npm-пакет или отдельный плагин только ради сходства с чужим продуктом. Более короткий стабильный адрес — отдельная работа над поставкой со своими проверками; для улучшения текста и расположения блоков она не нужна.

Собранные данные поддерживают сокращение числа решений при установке. Они **не** доказывают рост конверсии, выигрыш производительности или необходимость полностью переделать лендинг. Первый разумный шаг — убрать малополезный выбор из основного пути и понятнее показать первую полезную сессию.

## Дополнительная проверка живой страницы Tibicen

Веб-извлечение и браузерный коннектор сначала не смогли открыть Tibicen. Затем новая локальная сессия Chromium загрузила живой HTTPS-сайт с обычной проверкой сертификата. Проверена отрисованная desktop-страница при размере окна 1440 × 1000; заголовок, язык и версия соответствовали исходникам 1.4.0. Исходное сравнение Tibicen выше опиралось на код; эта проверка добавляет отдельное визуальное наблюдение.

Высота страницы в этом окне — 5497 CSS-пикселей; это характеристика вёрстки, не оценка удобства. Конструктор пресета, расширенные подсказки проекта, совместимость и помощь с загрузкой скилла уже свёрнуты. Тринадцать подсказок харнессов находятся внутри расширенных настроек пресета, а не являются обязательным выбором при установке.

Основная редакционная проблема — повторение первого запуска: установка, открытие скилла, выбор задачи, объяснение процесса, затем два полных примера по шесть шагов. Предлагается один непрерывный блок установки и вызова; один короткий пошаговый диалог пользователя и агента, второй пример — вкладкой или по раскрытию. Начальное состояние проекта и итоговое изменение должны оставаться видимыми, как ранее просил владелец. Пресет можно вынести во вторичный раздел или предложить после первого запуска. Существенные требования и ограничения команд Windows нужно сохранить рядом со стартом; подробные свидетельства — за ссылками на документацию.

Опубликованная 1.4.0 и инженерные проверки подтверждают публичный MVP. Измеренная экономия времени, успешный первый запуск без помощи и широкая нативная совместимость моделей/сред этим релизом не установлены. Следующий предлагаемый пакет — упрощение первого использования; это ещё не утверждённый план реализации. Правка только сайта не требует новой версии поставляемых скиллов. Мобильная сессия, исследование конверсии и изменения продукта в этом ревью не выполнялись.
