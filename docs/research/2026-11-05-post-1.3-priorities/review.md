# Focused evidence and synthesis review

Reviewed **5 November 2026, Europe/Moscow**. Scope: the five English/Russian
pairs in this study, their source-ledger classifications and their claims
against the already inspected 1.3 diagnosis, memory and portability contracts.
This review is independent of the root synthesis, but its author produced the
context/memory lane; that lane is not independently re-audited here.

**Verdict: no substantive blocker to delivering this as a research recommendation.**
The [synthesis](README.md) preserves existing 1.3 capabilities, labels the ranking
as inference and narrows the proposed work to a concrete adopt diagnosis and
version-bound local integration repair. It does not establish demand magnitude,
causal benefit, broad native compatibility or approval to implement.

## Findings

- **Existing capability is not misreported as absent.** The synthesis and lanes
  retain the current one-store/correction policy, explicit common-file route,
  candidate inventory, manual/native limitations and complete-folder update
  backups. Task/path applicability and target-process evidence are identified
  as narrower gaps. [Current comparison](context-and-memory.md),
  [integration boundary](integrations.md), [update boundary](reuse-and-updates.md).
- **Competing explanations survive the recommendation.** Corrected configuration,
  upstream fixes, a withdrawn loading diagnosis, an archived integration and
  native alternatives are not converted into current universal defects.
  NEW/RECHECK labels distinguish URL discovery from prior project knowledge.
  EN/RU recommendations and material limits agree.
- **Decisive primary-source checks passed within their scope.** The cross-format
  paper distinguishes divergent guidance from actual contradiction and reports
  different applicability scopes; the study preserves that distinction. Claude's
  official page confirms the version-gated native instruction audit and AGENTS
  support, weakening a generic replacement pitch. The APM release page confirms
  the cited release exists; this review does not independently revalidate all
  tagged ownership semantics or release API metadata. [Paper](https://arxiv.org/html/2611.02383v1),
  [Claude documentation](https://code.claude.com/docs/en/memory),
  [APM release](https://github.com/microsoft/apm/releases/tag/v0.35.0).
- **The Habr denominator is handled correctly.** R5 describes the authors' own
  seven-session subset, separate from their file corpus and from task benefit;
  it is not promoted into an independent failure-rate or effectiveness result.
  This is a check of the recorded source interpretation, not a new Habr retrieval.
  [Critical ledger](critical-evidence.md).

One editorial issue was reported and corrected during review: the English
README's Russian-document link was changed to a plain filename, preserving
canonical English instruction links. No other required change was identified.

## Method and limits

This was a bounded review of source paragraphs, ledgers, synthesis and translation
coherence, not another broad search. A batched web open of the three decisive
URLs did not return before the bounded wait was stopped; direct read-only HTTP
retrieval of those same three URLs then succeeded. The paper's relevant table
and scope paragraph, Claude's audit/version paragraphs and APM's release page
were inspected. The rest of the source bodies were not independently reopened.

A ranking can be defensible without proving that a feature will help. The next
implementation decision still needs a concrete deficiency beyond existing adopt
and native diagnostics. No implementation, native/model trial, installation,
commit, publication or test execution was performed by this review.
