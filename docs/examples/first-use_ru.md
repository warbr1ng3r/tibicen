# Записанный пример: обновить инструкции и использовать память

Это краткое изложение одного принятого наблюдения **1.5.4**, а не пилот с реальным пользователем и не дословная переписка. Проект искусственный; оператор согласовал и применил точный план агента. Полные свидетельства и ограничения — в [отчёте выпуска](../evals/results/2026-11-09-release-1.5.4/README.md).

## До начала

В складском проекте из двенадцати файлов уже были работающий код, семь тестов, устаревшие инструкции и файл памяти. Одна строка README обещала сортировку по SKU, хотя код, тесты и принятое решение сохраняли входной порядок. Отдельное принятое исключение для `renderAssemblySheet(items)` требовало положительных остатков, их возрастания и стабильного порядка при равенстве.

## 1. Попросить проверить настройку

В записанном запросе было:

> Приведи инструкции для агентов в этом проекте в порядок. Сохрани код, тесты и принятые решения. Покажи изменения до применения.

Агент прочитал проект и оба нужных справочных файла Tibicen. Он отделил устаревший README от принятых требований, написал рабочую политику и сформировал предложение настоящим CLI. План менял корневые и вложенные инструкции `AGENTS.md`; существующая память сохранялась. Получен настоящий CLI-план размером 11 107 байт, а не ожидаемый ответ, написанный оператором.

## 2. Проверить и применить точный план

Оператор проверил фактическое предложение и его digest, затем согласовал план вместе с создаваемыми служебными записями. Он запустил CLI кандидата в изолированном контейнере и применил неизменённый план. Структурная проверка прошла; apply/status/report вернули complete.

Применение выполнил оператор, а не нативный агент. При настройке функциональность приложения не добавлялась.

## 3. Дать полезную задачу в новой сессии

Свежая сессия получила получившиеся файлы проекта без первой переписки и подсказки читать память:

> Добавь renderAssemblySheet(items): строки sku:stock, заголовок # assembly. Допиши тесты.

Агент прочитал существующую память и реализовал именованное исключение. Изменились только исходник и тесты; прежнее поведение `renderStock`, точные SKU и входные данные сохранились. Девять тестов проекта и независимая функциональная проверка прошли. Обе нативные сессии и все четыре контейнера без модели очищены.

## Что это подтверждает

В одном искусственном проекте настройка с помощью оператора дала политику, которую новая сессия использовала для полезной задачи. Это не подтверждает автоматическую загрузку, нативное применение агентом, исправление памяти, причинное улучшение, совместимость с любым хостом и измеренную пользу человеку. Чтобы попробовать текущий маршрут самостоятельно, начните с [README](../../README.md).
