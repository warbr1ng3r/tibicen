# Issue tracker

Public bug reports and proposals belong in [GitHub Issues](https://github.com/warbr1ng3r/tibicen/issues). Follow [CONTRIBUTING.md](../../CONTRIBUTING.md) when preparing a change.

For implementation order and current scope, read [the development plan](../DEVELOPMENT_PLAN.md). Requirements, scenarios and detailed implementation tasks live in the corresponding [OpenSpec change](../../openspec/changes/). Select a change with ready inputs and keep concurrent assignments in separate paths.

## Current effort

Publication of the limited `0.1.0-alpha.1` and landing deployment were authorized by the owner on 2026-10-27, including commits, pushes, tags and assets. Completion requires actual Git delivery, remote CI and GitHub Pages results.

This first public source snapshot omits the local development tracker and private run records. Historical verification notes describe their original scope; they do not imply full public MVP acceptance.
