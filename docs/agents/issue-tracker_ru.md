## Операции Wayfinder

- Карта работы: `.scratch/<effort>/map.md`; метка `wayfinder:map`.
- Дочерняя задача: `.scratch/<effort>/issues/NN-<slug>.md`; путь служит её идентификатором, текст ссылки содержит название задачи.
- Поля: `Type: grilling|prototype|research|task`, `Labels: wayfinder:<type>`, `Status: open|claimed|resolved`, `Assignee: none|<session>`, `Blocked by: none|NN, NN`. Карта использует только `wayfinder:map`, задачи — только `wayfinder:<type>`.
- До начала работы назначить исполнителя и `Status: claimed`. Разрешённые пути и проверки задаются контрактом задачи и связанными задачами OpenSpec.
- Зависимость завершена только при `Status: resolved`. Доступные задачи — открытые, неназначенные и незаблокированные, по порядку номеров. Пакеты выполняются последовательно; внутри пакета параллельны задачи с готовыми входными данными и непересекающимися путями.
- При завершении записать результат и свидетельства в `## Answer`, установить `Status: resolved`, снять исполнителя и добавить ссылку с кратким итогом в `Decisions so far` карты. Решение человека требует его ответа.
- Подробности существенных изменений и флажки реализации хранятся в OpenSpec. Задача содержит вопрос/результат, границы ответственности и ссылку на точную группу задач. План задаёт порядок этапов.
- `dashboard.md` отображает задачи и обновляется после изменений состояний и зависимостей. Визуализация в чате — снимок, а не второй трекер.
