## Проверки и ограничения

- Site unit: 65/65 на сборке с исходным origin, затем 65/65 на сборке Cloudflare после замены только ожидаемого origin в одноразовой копии тестов.
- Chromium: сначала 30/35. Три теста ожидали старый SHA поставки 1.4.1; эти три прошли после замены ожидания в одноразовой копии. Тесты репозитория не менялись.
- Два мобильных сравнения скриншотов отличаются от эталонов. Оба сбоя воспроизводятся и со старым origin: фактические картинки 390 px между origin идентичны; при 320 px отличаются восемь пикселей. Эталоны не обновлялись. Полный неизменённый браузерный набор не объявляется успешным.
- На публичном сайте при 390 px прошли переходы с обеих главных в конструкторы, корректное локальное скачивание `preset.yaml` и смена языка с сохранением маршрута конструктора. Переполнения по горизонтали, ошибок страницы и запросов с синтетическим ответом пресета не обнаружено.
- Первая публичная навигация завершилась таймаутом; последующие браузерные и HTTP-проверки прошли. Это не подтверждает доступность из каждой сети или индексацию Google.

Загружены только статические файлы. Код продукта, релизные артефакты, учётные данные, настройки GitHub и существующие проекты Cloudflare не менялись. Коммитов нет. Точный загруженный ZIP и изменения одноразовых тестов проверены; после сравнения с исходным origin сборка Cloudflare восстановлена и все 22 локальных хеша проверены повторно.
