# Автодеплой — 9 ноября 2026 года

Существующий проект Direct Upload [tibicen.pages.dev](https://tibicen.pages.dev/) теперь публикуется автоматически через GitHub Actions при push в `main`. Доступен и ручной запуск на `main`; другие ветки и pull request сайт не публикуют.

## Настройка и разрешение

Владелец явно разрешил закоммитить и отправить только `.github/workflows/cloudflare-pages.yml` и изменение ожидаемого origin в `tests/site/site.test.ts`. Коммит [`583c8ab`](https://github.com/warbr1ng3r/tibicen/commit/583c8abcb6535709a16a61a4ef093a3b3aac418e) содержит ровно эти два файла, основан на remote `main` `714a148f73adce5c15c85d9e3ab42f4ce6514670`. Он подготовлен в отдельном worktree и отправлен обычным push, без force и изменений параллельной незакоммиченной рабочей копии.

[Workflow](https://github.com/warbr1ng3r/tibicen/blob/583c8abcb6535709a16a61a4ef093a3b3aac418e/.github/workflows/cloudflare-pages.yml) использует прежние закреплённые SHA actions, Node 24.15.0, pnpm 11.21.0 и неизменённый lockfile. Он собирает сайт для `https://tibicen.pages.dev` с base `/`, запускает все site unit с `TIBICEN_SITE_ORIGIN` этого origin, затем публикует через Wrangler 4.159.0. Значение по умолчанию в тесте сохраняет совместимость со сборкой GitHub Pages. Production-выкладки выполняются последовательно.

Настроены Actions secrets репозитория `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`. Их получает только шаг выкладки. Токен аккаунта `tibicen-github-actions` имеет Pages Write в существующем аккаунте Cloudflare, без прав на другие продукты и срока истечения. Его значение передано напрямую в секрет, без возврата в вывод инструментов и записи в файл. Для ротации/отзыва используйте Account API tokens; при ротации замените секрет GitHub. Workflow имеет `contents: read`; credentials checkout не сохраняются.

Внешний CI для существующих Direct Upload описан в [официальной инструкции Cloudflare](https://developers.cloudflare.com/pages/how-to/use-direct-upload-with-continuous-integration/). Сайт не пересоздавался, исходный адрес сохранён.
