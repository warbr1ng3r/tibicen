# Tibicen skill distribution

Limited 0.1.0-alpha.1 distribution for tibicen-init and tibicen-adopt.

The source, scope, release notes and checksums are in https://github.com/warbr1ng3r/tibicen/releases. Install from the immutable release tag or full distribution SHA, selecting only the two Tibicen skills. Back up local edits before replacing installed skill directories.
