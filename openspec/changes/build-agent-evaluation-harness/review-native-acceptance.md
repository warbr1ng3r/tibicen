# Review — shared native acceptance, 23.10.2026

Изменение отделяет общий SKILL/PREF/PROC-протокол от профилей агентов и добавляет discovery встроенного CLI desktop ZCode. Оно сохраняет отдельные согласования стадий, наблюдения, расход и пакеты для независимой оценки; живую приёмку само по себе не подтверждает.

Проверены все незакоммиченные изменения, вызывающий код, контракты, механические/смысловые оценщики, сохранение, сборка, README и связанные тесты. Нагрузка: один оператор, последовательные локальные сессии с явным бюджетом; это не сервер и не hostile arbitrary-shell sandbox. Пользователь явно запросил ревью, исправления и коммит; ограничение skill «changes no code» перекрыто этим запросом.

## Must fix — resolved

1. **Ошибка apply скрывала доказанное нарушение** ([native-runner.ts](../../../scripts/evals/native-runner.ts#L311)).
   - **Что это:** Host сверяет эффекты агента с точным согласованным планом.
   - **Проблема:** Apply мог изменить защищённый package.json и затем завершиться с exit 1. Проверка diff пропускалась, а результат становился error с unverified инвариантами вместо fail.
   - **Исправление:** Одна проверка наблюдаемых эффектов используется после apply и в обработчике ошибки. Доказанная чужая запись остаётся fail; невыполненная разрешённая запись при исчерпании бюджета не объявляется нарушением. Оба случая проверены.
   - **Если оставить:** Обязательное нарушение теряется среди ошибок среды и может быть скрыто будущим повтором.

2. **Некорректный native-поток терял всю серию** ([native-runner.ts](../../../scripts/evals/native-runner.ts#L99)).
   - **Что это:** JSONL-поток даёт наблюдаемый start, сообщения и tool-события каждой сессии.
   - **Проблема:** Строка null вызывала необработанный TypeError в callback. Сообщение/tool-output без turn.started создавало события setup до launch и затем обрушало validateRun. В обоих случаях оставшиеся слоты не сохранялись.
   - **Исправление:** До callback допускаются только объекты; невалидный окончательный протокол остаётся ошибкой. Каждая сессия требует собственного start; command/loading без него не публикуются. Две регрессии запускают host отдельным процессом и требуют сохранения обеих попыток.
   - **Если оставить:** Отказ или дефект CLI удаляет ошибочные попытки из парного сравнения.

3. **Склеенные shell-токены принимались за другую команду** ([native-workflow.ts](../../../scripts/evals/native-workflow.ts#L69)).
   - **Что это:** Разбор буквальных команд связывает согласие и наблюдаемое исполнение с известным recipe.
   - **Проблема:** node"--test" трактовался как node --test, хотя shell получает имя node--test. Перевод строки между словами также принимался за пробел, хотя разделяет команды.
   - **Исправление:** Поддержанные токены разделяются пробелом/табуляцией; склейка и перевод строки отклоняются. Проверены parser, recipe и отказ review, включая shell wrapper; обычные quoted tokens работают.
   - **Если оставить:** Согласие и свидетельство исполнения относятся к команде, которую агент фактически не запускал.

4. **Граница чанка портила русский текст** ([native-runner.ts](../../../scripts/evals/native-runner.ts#L89)).
   - **Что это:** Вывод дочернего процесса читается произвольными порциями байтов.
   - **Проблема:** Каждая порция отдельно превращалась в строку. При разрыве двухбайтного символа «С» предложение «Сохраняю…» сохранялось как «��охраняю…»; полный JSON при этом оставался синтаксически валидным. Аналогично терялось подтверждение чтения исходных инструкций.
   - **Исправление:** Native runner, общий CLI probe и перенесённый Codex preflight используют потоковый UTF-8 decoder Node. Контроль намеренно пишет половины символа двумя системными записями и проверяет точный текст и loading.
   - **Если оставить:** В согласование/отчёт попадают другие байты, а правильное чтение инструкции может остаться unverified.

5. **Повторные чтения ломали пакет судье** ([native-runner.ts](../../../scripts/evals/native-runner.ts#L154)).
   - **Что это:** Host отбирает ограниченный набор оснований для независимого оценщика.
   - **Проблема:** 205 чтений одного небольшого AGENTS.md укладывались в лимит native-потока и давали raw pass, но создавали больше 200 одинаковых оснований. Collector отказывался формировать отчёт.
   - **Исправление:** Одинаковое содержимое выбирается один раз отдельно для setup/task. Все tool-события остаются в run; другая редакция получает своё основание. Контроль повторяет чтение и доводит обе попытки до collector.
   - **Если оставить:** Длинная, но допустимая сессия завершает работу без пригодного пакета оценки.

6. **Отказ пользователя обнулял стоимость предложения** ([report.ts](../../../scripts/evals/report.ts#L48)).
   - **Что это:** Отчёт суммирует наблюдённую стоимость стадий.
   - **Проблема:** После предложения за 5 USD setup=skip сохранял usage=5, но сумма брала только non-skip стадии. При launch=0 итог получался 0; неизвестная стоимость также могла скрыться.
   - **Исправление:** Итог включает стадии с наблюдённым usage независимо от skip. Проверены известные 5 и null, а не начавшийся task сохраняет отсутствие counters. В native-подписочных сериях денежная стоимость по-прежнему неизвестна.
   - **Если оставить:** Расход занижается или выдаётся за известный ноль.

7. **Таймаут с exit 0 принимался за успешное завершение** ([native-runner.ts](../../../scripts/evals/native-runner.ts#L216)).
   - **Что это:** Лимит действует на native-сессию и её потомков, а не только на родительский CLI.
   - **Проблема:** Родитель печатал completed и завершался с exit 0, но потомок удерживал stdout до дедлайна. После остановки группы wrapper возвращал status=0/timedOut=true; setup без изменений получал pass и начинал task.
   - **Исправление:** Timeout всегда исключает успешную сессию/runtime probe. Независимые Node/OpenSpec проверки тоже не получают успешный exit после дедлайна. Регрессия реально оставляет потомка с унаследованным stdout и проверяет оба сохранённых error/skip и trace с exit 0/timedOut=true.
   - **Если оставить:** Стенд сообщает успех за пределами замороженного бюджета и запускает следующую стадию после таймаута.

   - **Что это:** Матрица агентов входит в обе установленные поставки и читается на стадии архитектуры.
   - **Проблема:** Новая ссылка на docs/evals/results/… работала в checkout, но этот каталог намеренно не поставляется. Установленный скилл получал ENOENT.
   - **Исправление:** Ссылка на development-артефакт убрана из поставляемой инструкции; публичная проекция остаётся связанной в документации стенда. Существующий build-тест теперь проверяет все локальные ссылки поставляемых Markdown-файлов в default/external output.
   - **Если оставить:** Пользователь установленного скилла не может открыть указанное основание, хотя resource self-test зелёный.
