# Review — 23.10.2026

Изменение добавляет явный внешний запуск, 67 сценариев с закреплёнными источниками и первые парные диагностики настоящего Codex. Setup и следующая задача наблюдаются отдельно; независимое качество и приёмка SKILL/PREF/PROC остаются открытыми.

Проверены все незакоммиченные файлы, связанные контракты, runner, оценщики, хранение, сборка и документация. Нагрузка: один разработчик, последовательные локальные сессии; сохранение артефактов допускает одновременные записи без перезаписи результата. Пользователь явно разрешил исправления и коммит.

## Must fix — resolved

1. **Авария независимой проверки давала pass** ([codex-diagnostic.ts](../../../scripts/evals/codex-diagnostic.ts#L181)).
   - **Что это:** Host независимо выполняет согласованный Node-тест после работы агента.
   - **Проблема:** При завершении сигналом или ошибке запуска код равен null. Он трактовался как отсутствие проверки, setup получал pass и запускал task.
   - **Исправление:** Требуемая проверка успешна только при exit 0; ей передаётся оставшееся время стадии. Офлайн-CLI, погибающий от SIGKILL, теперь даёт fail и task skip во всех четырёх слотах.
   - **Если оставить:** Стенд продолжает работу и сообщает успех после несостоявшейся проверки.

2. **Ненаблюдаемый файл терял всю серию** ([codex-diagnostic.ts](../../../scripts/evals/codex-diagnostic.ts#L157)).
   - **Что это:** Снимки файлов подтверждают область и точные байты согласованного изменения.
   - **Проблема:** Симлинк вызывал исключение при основном снимке и повторно в catch. Попытка не сохранялась; оставшиеся слоты не выполнялись. Вместе с ней терялось видимое изменение защищённого файла.
   - **Исправление:** Используется общий ограниченный наблюдатель дерева. Неполный снимок сохраняется, проверка проекта блокируется; доказанное нарушение остаётся fail. Две регрессии проверяют все четыре сохранённые попытки и пропуск task.
   - **Если оставить:** Ошибочные попытки исчезают из сравнения, а обязательное нарушение может остаться без записи.

3. **Отмена preflight оставляла CLI с потомками работать** ([codex-preflight.ts](../../../scripts/evals/codex-preflight.ts#L29)).
   - **Что это:** Preflight запускает отдельную группу процессов и при явном startup подключает родительскому CLI существующую авторизацию.
   - **Проблема:** SIGINT/SIGTERM завершал host без finally; отсоединённая группа продолжала работу, временный scope оставался на диске.
   - **Исправление:** Отмена убивает группы, запрещает следующие команды и удаляет scope. Регрессия ждёт настоящего потомка офлайн-CLI, отправляет SIGTERM и проверяет cleanup и отсутствие его отложенной записи. Уточнено описание использования авторизации.
   - **Если оставить:** После отмены могут продолжаться запросы и сохраняться временная ссылка на авторизацию.

4. **Сценарии требовали запрещённое или чужое исполнение** ([matrix.ts](../../../scripts/evals/matrix.ts#L192)).
   - **Что это:** Отдельные сценарии проверяют отказ, достаточную настройку и неподдержанный профиль приложения.
   - **Проблема:** В 26 случаях setup запрещал команды, но oracle требовал Node-тест. Пустой React-проект дополнительно наследовал Node-задачу double/triple и запрет на стартовый package.json.
   - **Исправление:** Скрытая проверка должна входить в разрешённые команды. Отсутствие подходящего application-checker остаётся unverified; React-сценарий использует собственные пути и задачу. Проверены реальная положительная оценка сохранения достаточных правил и новый lock матрицы.
   - **Если оставить:** Корректное поведение не проходит стенд либо оценивается по задаче другого проекта.

5. **Collector выдавал неполные или чужие данные за полный расход** ([collect-native.ts](../../../scripts/evals/collect-native.ts#L16)).
   - **Что это:** Обработчик объединяет сохранённые попытки и proposal/apply counters без новых вызовов модели.
   - **Проблема:** Потерянный apply-файл просто пропускался. Переставленные файлы попыток одной когорты не отклонялись, а digest условий не сверялся; токены могли оказаться у другого варианта.
   - **Исправление:** Потеря ожидаемой сессии делает итог стадии неизвестным. Проверяются id слота и digest условий; регрессии удаляют apply, меняют местами попытки и изменяют conditions.
   - **Если оставить:** Сравнение показывает заниженные расходы или приписывает их другому варианту.
