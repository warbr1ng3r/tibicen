# Design

## Context

См. [предложение](proposal.md). Файлы в поддержанных папках скиллов правильно входят в инвентарь как инфраструктура. Тот же широкий признак сейчас выбирает improve и при наличии только установленного Tibicen.

## Goals / Non-Goals

Меняется только маршрут. Сохраняются все файлы, хэши, права, признаки инфраструктуры, наблюдения харнессов, кандидаты памяти и исключения чтения. Физическая пустота и разрешения плана/применения независимы. Без пропуска обхода, проверки подлинности, флага принудительного режима и переделки процесса скиллов.

## Decisions

Использовать поддержанные общие/нативные корни скиллов и точные зарезервированные имена папок `tibicen-init`, `tibicen-adopt`, включая вложенные. Остальные имена и корни остаются консервативными. Имя не доказывает доверие или байты upstream: файлы видимы и защищены. Разрешения записи по общему признаку инфраструктуры прежние.

## Risks / Trade-offs

- Локально изменённая каноническая папка тоже получает подсказку маршрута; файлы остаются в инвентаре, правки требуют согласия. Переименованные копии остаются improve.
- Установленный скилл делает каталог физически непустым. init не разрешает стартовые исходники, package/Git init; прежние защиты проверяются.
- Незарегистрированная память остаётся кандидатом; зарегистрированная память или паспорт сохраняют improve. Распознавание памяти не расширяется.

## Outer owner correction — 8 November

Пример с каноническим именем внутри распознанной области пользовательских правил/команд/инструкций/MCP принадлежит внешнему владельцу. До подсказки по внутреннему имени проверяется ранний префикс существующим классификатором инфраструктуры. Примеры Markdown-инструкций и JSON покрывают нынешние грамматики каталогов без второго каталога корней. Исправлен пропущенный случай вложенного владельца; доверие и разрешения записи прежние.
