# Proposal

## Why

Installing Tibicen inside a project currently makes its first scan choose improve solely because it finds its own skill files. The ordinary-cycle observation reproduced this confusing route in a project with no user instructions.

## What Changes

- Select initial setup when canonical Tibicen skill folders are the only observed infrastructure.
- Keep other skills, rules and registered memory eligible for improvement.
- Preserve the complete inventory and all existing empty-project, consent, path and execution protections.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `agent-infrastructure-lifecycle`: distinguish the installed setup utility from pre-existing user setup when selecting the initial route.

## Impact

A narrow scan mode predicate and regression tests, with paired capability documentation and an Unreleased changelog entry. No dependencies, schema changes, version bump, native rerun or publication. Canonical folder names are only a routing hint, never proof of trust, provenance or ownership.
