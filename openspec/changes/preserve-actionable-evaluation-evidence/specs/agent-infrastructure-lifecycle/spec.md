## ADDED Requirements

### Requirement: Generated guidance remains independently maintainable

Generated instructions SHALL preserve owner-authorized maintenance by ordinary working agents after handoff without requiring installed Tibicen. Init SHALL remain first-time setup and adopt SHALL remain review/update. Managed markers SHALL indicate replaceable provenance, not exclusive editor authority; owner sections and approved scope remain protected.

#### Scenario: A later agent maintains the setup

- **WHEN** the owner requests an ordinary update after setup and Tibicen is unavailable
- **THEN** the generated policy permits the authorized agent to maintain instructions and selected project memory
- **AND** it preserves owner sections, registered connections and applicable consent without requiring init

#### Scenario: Existing generated instructions need a Tibicen review

- **WHEN** a project already has generated infrastructure and requests its review
- **THEN** guidance permits the adopt route and its exact approved changes
- **AND** no generated init-only restriction overrides the owner's authority
