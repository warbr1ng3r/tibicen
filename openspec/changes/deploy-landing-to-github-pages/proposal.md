# Proposal

## Why

Лендинг уже статический, но корневые ссылки ломаются при размещении под `/repo/`, а workflow публикации отсутствует. Страницу нужно подготовить к GitHub Pages отдельно от релизных гейтов скиллов.

## What Changes

- Разрешать ресурсы, лицензии и preview-ссылки относительно настроенного Astro base.
- Добавить ручной GitHub Pages workflow с закреплёнными Actions, pnpm и Node; адрес получать из Pages.
- Проверить root/project-path сборки и работу конструктора в браузере; описать запуск и непроверенный remote run.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `landing-experience`: работа статической страницы под project base и отдельная ручная доставка на GitHub Pages.

## Impact

Страница Astro, тесты сайта, один deployment workflow и документация. Зависимости, CLI/дистрибутив скиллов и пользовательские проекты не меняются. Этот change подготавливает размещение: push/настройка Pages и сама публикация не выполняются. Пустой публичный репозиторий и origin созданы отдельно по ответу владельца.
