# Design

## Context

Ретроспективно зафиксировано 22.10.2026: `site/` заменён отдельным статическим Astro-приложением. Старые два коммита не меняются. Подробные интеракции и кроссбраузерные исправления принадлежат `landing-ui-controls`.

## Goals / Non-Goals

**Goals:** ясный старт init/adopt, автономная статическая сборка, выбранные оформление и логотип, согласованные команды установки, воспроизводимые локальные проверки.

**Non-Goals:** backend, аналитика, React, публикация, готовые live evals, расширение продуктового MVP.

## Decisions

- `landing/` — pnpm workspace с Astro-страницей, типизированными компонентами и клиентскими скриптами. Удаляются старые `site/*` и отдельный `tsconfig.site.json`; результаты сборки игнорируются. Корневые команды запускают typecheck/build сайта отдельно от Node runtime продукта.
- Единый `pnpm-lock.yaml`, закреплённый `packageManager`, явный патч Starwind runtime. npm/Yarn остаются вариантами запуска установщика для посетителя, а не менеджерами разработки репозитория. `node scripts/build.ts` не импортирует зависимости сайта.
- AstroWind используется как адаптированные секции с MIT-уведомлением. Для Select подключён один Astro-примитив Starwind; оформление локальное. Нет второго компонентного runtime или полного шаблона с лишними разделами.
- Нейтральный фон `#1c1c1c`, акцент `#79d98b`, наклонённая иллюстрация, общий SVG-знак «Точная сборка» в шапке/подвале и адаптивном favicon. Новый знак получен отдельно; его исходники включаются вместе с сайтом.
- Canvas рисует плоский граф; loop ограничен видимостью и reduced motion, есть SVG fallback. Allowlist preview-геометрии не меняет фон главной без параметров. Другие фоны используют ограниченное смещение через requestAnimationFrame.
- Локальные обработчики копирования сохраняют иконку/подпись и сообщают результат, в том числе при fallback. Пресет использует общий валидатор; никаких ответов серверу. Команды установки закрепляют `skills@1.7.4` и `--copy`.

## Risks / Trade-offs

- Canvas и SVG дают декоративную графику без трёхмерного runtime, но не гарантируют одинаковый raster на всех устройствах.
- Автотесты трёх движков и диапазона ширин не доказывают работу любого исторического браузера или физического устройства. Скриншоты привязаны к macOS; ограничения фиксируются в verification.
- Патч Starwind требует пересмотра при обновлении зависимости. Deprecation hint запасного `execCommand` не мешает основной Clipboard API, но требует внимания при будущей смене поддержки браузеров.
- Общий roadmap описывает последующие очереди, включая OSS и релизы; их наличие в документации не означает внедрённый CI или опубликованный релиз.
