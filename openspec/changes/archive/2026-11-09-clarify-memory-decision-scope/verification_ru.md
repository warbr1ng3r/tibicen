# Verification

## Result

Общая политика памяти и два примера создаваемых инструкций теперь сохраняют данное имя операции, изменяемое поведение и границы исключения. Однозначно подходящее принятое исключение применяется; неизвестная связь и неразрешённый конфликт той же операции требуют уточнения. Приоритет запроса, одно хранилище и границы записи/согласования сохранены. Нового процесса, схемы, зависимости или версии нет.

[Отчёт трёх сессий](../../../../docs/evals/results/2026-11-09-memory-scope/README.md) разделяет исправление, свежее использование и отрицательный конфликтный вариант. Все три завершены и приняты root и независимым reviewer. Полезная задача прошла девять тестов проекта и закреплённый функциональный oracle. Три нативных вызова заняли суммарно 106859 мс; три контейнера без моделей проверили изоляцию, контроли и фактический результат. Все шесть контейнеров остановлены/удалены, собственный временный корень удалён. Четвёртого вызова, повтора, платного API и ремонта авторизации/настроек не было.

## Checks and review

- Независимое Ponytail review приняло общую политику, примеры, парную документацию, предварительный протокол и три фактических исхода. Точные записи остаются в частном каталоге наблюдения.
- Типы, сборка сайта, строгая проверка текущих/архивных OpenSpec и сборка поставки прошли.
- Итоговый offline Node: 1075 успешных тестов, ошибок нет, один штатный пропуск переносимой проверки. Промежуточная проверка формулировки отмены упала, затем прошла после восстановления явного правила; тест не удалён и не ослаблен.
- Отдельный переносимый цикл собранной поставки: 3/3 на macOS arm64 / Node 24.15.0. Self-test обоих скиллов прошёл; обе копии инструкции памяти равны исходнику.
- Исходный `pnpm test` остановился на форматировании трёх JSON параллельного исследования продвижения. Файлы сохранены. Форматирование с исключением ровно этих трёх путей прошло, остальные части gate выполнены отдельно. Это не утверждение, что `pnpm test` всего рабочего дерева зелёный.

## Evidence limits

Это один синтетический кейс, Codex 0.157.0 / gpt-6-astra и проверенная локальная Unreleased-сборка с метаданными 1.5.3. Root поместил рабочую политику в существующие подготовленные блоки AGENTS; это не свежая нативная настройка Tibicen, автоматическая генерация или обнаружение. Владелец явно дал новое имя операции. Прежний HOLD без явной связи названий неизменен. Причинное сравнение до/после, общая совместимость харнессов и измеренная польза человеку не заявлены.

Прежние отчёты, свидетельства, HEAD, package/lock и отложенная работа сохранены. Параллельное исследование продвижения не редактировалось. Изменения остаются Unreleased; коммита, push и публикации нет.
