# Design

## Context

См. [предложение](proposal.md). Report сериализует сохранённую сессию; scan и verifyInfrastructure уже дают ограниченные текущие данные без исполнения. Инструкции требуют минимальных согласованных правок и отдельных результатов проверок.

## Goals / Non-Goals

Цели: дополнительная текущая диагностика, честные границы инструкций, короткий итог adopt/без изменений, прежние согласования и восстановление.

Вне объёма: новая команда, симулятор загрузки, смысловой парсер правил, нативные прогоны, чтение глобального/приватного состояния, новое хранилище памяти, миграция схем, версия и публикация.

## Decisions

1. Report использует свежие scan и структурный verify с прежней областью. Общий сборщик допустим для исключения дублирования обработки конфликтов незавершённой памяти. Старые поля сохраняются; добавляется diagnosis. Запись отчёта по-прежнему требует save/requested.
2. Чистая summarizeDiagnosis получает ScanResult, CheckResult и минимальные сведения сессии/действий. Она не читает файлы, не исполняет, не обращается к сети и не меняет записи. Результат: текущие находки и пробелы, кандидаты инструкций с относительным каталогом, исходная сессия/статус и осторожное следующее действие. Факты версии/точки входа матрицы — контракт адаптера, не установленная версия.
3. Кандидаты инструкций — инвентаризация, не активная область загрузчика. Вложенные AGENTS/CLAUDE и правила Cursor сохраняют каталоги; различие каталогов не означает конфликт. Агент объясняет выбранную версию, cwd, цель и применимую документацию. Приоритеты, overrides, импорты и загрузка без свидетельств неизвестны. Для общих правил используются прежние проверки.
4. Текущая диагностика и исторические проверки разделены. Прошлый complete совместим с текущим дефектом. Пробел или нативная незарегистрированная настройка не превращаются в успех, рекомендацию ничего не менять или новую завершённую сессию. Достаточность оценивает агент с указанием охвата.
5. Представление выдаёт пути, причины и статусы, не тела инструкций, вывод команд и секреты. Порядок стабилен; без времени и счётчиков файлов для одинакового report/save. Завершённая память остаётся данными пользователя. Запретные пути, симлинки и чувствительные файлы сохраняют защиту.
6. Инструкции дают короткое объяснение исходного состояния, свидетельств, сохранения/правок, проверок и следующего шага. Точный diff доступен до согласия; обязательной анкеты и таблицы терминов нет. При новом аудите старый отчёт явно исторический.

## Risks / Trade-offs

- Дополнительное сканирование: ограниченный прежний механизм без исполнения/сети; status остаётся быстрым.
- Ложная загрузка: найденное и контракт формата отделены от наблюдаемой загрузки/использования.
- Совместимость: дополнительное поле, детерминированность, прежние сохраняемые схемы.
- Неясная область: известные пути/каталоги и явные пробелы; AGENTS.md не выбирает агента автоматически.

## Migration Plan

Миграции нет. Старые поля сохраняются. Документация отмечает Unreleased; версия 1.1.0 остаётся до отдельного кандидата. Целевые тесты, полный закреплённый gate/build, smoke самостоятельных скиллов и независимое Ponytail review. Коммит/публикация не входят.
