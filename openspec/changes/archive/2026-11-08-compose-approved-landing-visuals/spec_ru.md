# Spec Delta

## ADDED Requirements

### Requirement: Distinct truthful illustration roles

Двуязычный лендинг SHALL показывать наполненный статический пример в начале, короткий обычный запрос/предложение и отдельную схему границ настройки. Необязательные память, скиллы и подключения SHALL быть явно отмечены. Пример путей SHALL NOT обещать одинаковый результат всем. Иконка `.tibicen/` SHALL быть папкой с часами снизу справа.

#### Scenario: A visitor scans the page

- **WHEN** открыта любая языковая версия
- **THEN** в начале один возможный состав без переключателя стадий, в процессе запрос/предложение, перед FAQ схема границ
- **AND** установка/пресеты сохранены, элементы управления прототипом отсутствуют

#### Scenario: A visitor needs the complete example

- **WHEN** пользователь открывает нативные подробности под коротким процессом, в том числе без JavaScript
- **THEN** оба init/adopt-примера доступны с исходным состоянием, точным diff, согласием, результатом и ограничениями сохранения
- **AND** примеры явно учебные, а не запись успешных прогонов

#### Scenario: A visitor uses a narrow screen or keyboard

- **WHEN** любая версия открыта при 280/320/390 CSS px либо управляется клавиатурой
- **THEN** нет горизонтального переполнения и обрезанных подписей, начало компактно, нативные подробности и выбор примера доступны
