- Поля установки дополнительно просмотрены на desktop и 390 px. Палитра, граф и секции AstroWind сохранены. Git-коммиты не создавались.

## Limits

Настоящие телефоны, Windows/Linux, старые браузеры и VoiceOver не проверялись. WebKit в Playwright не равен установленному Safari на iPhone. Установленный Google Chrome не удалось запустить через Playwright: процесс завершился SIGKILL; Chromium проверен отдельно. Масштаб эмулирован через CSS viewport и deviceScaleFactor, без ручного изменения browser UI zoom. Эталоны сняты на macOS; другие ОС требуют собственных просмотренных эталонов. Патч Starwind следует пересматривать при обновлении зависимости.
