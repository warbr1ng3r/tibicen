# Proposal

## Why

Нативные меню не соответствуют оформлению лендинга, мобильные поля обрезают значения, а мелкие подписи и разные способы показа ошибок затрудняют заполнение пресета.

## What Changes

- Единый кастомный Select для пяти полей с управлением клавиатурой и корректной передачей значений.
- Центрированная SVG-иконка раскрытия, читаемые подписи и доступные области нажатия.
- Адаптивная сетка полей и связанные с полями сообщения об ошибках.
- Браузерные сценарии для меню, формы и мобильного представления.

## Capabilities

### New Capabilities

- `landing-interactions`: доступность и предсказуемое поведение интерактивных элементов статического лендинга.

### Modified Capabilities

Нет. Контракт пресета и поведение распространяемых скиллов не меняются.

## Impact

Только `landing/`, браузерные проверки и lockfile. Адаптированные секции AstroWind сохраняются; добавляется только Astro-примитив Select из Starwind UI и его runtime. Палитра, фоновый граф, структура страницы и продуктовый MVP сохраняются. React и полный шаблон Starwind не добавляются.
