## ADDED Requirements

### Requirement: Structural memory checks recognize permitted nested instructions

Структурная проверка памяти SHALL учитывать явные ссылки от корня проекта в разрешённых существующих корневых и вложенных инструкциях поддержанных форм. Распознавание SHALL сохранять безопасное чтение и права записи и SHALL NOT доказывать нативную загрузку или применимость ко всей задаче.

#### Scenario: Only an existing nested native rule connects memory

- **WHEN** безопасно найденное вложенное `.cursorrules`, правило Cursor или Claude содержит точную каноническую ссылку на память от корня проекта
- **THEN** проверка признаёт структурную связь без избыточного корневого указателя
- **AND** применимость, загрузка и использование остаются непроверенными без отдельных свидетельств

#### Scenario: An unsafe or unrelated file contains a pointer

- **WHEN** единственная ссылка находится в запретном пути, симлинке, постороннем Markdown или неподдержанном расширении либо не совпадает с точным поддержанным путём памяти
- **THEN** она не подтверждает структурную связь
- **AND** проверка не читает исключённое содержимое и не меняет заметки, состояние или файлы пользователя

#### Scenario: Recognition does not permit editing a protected nested rule

- **WHEN** план пытается изменить вложенное нативное правило вне прежнего разрешения записи инфраструктуры
- **THEN** план по-прежнему отклоняется как application-protected
- **AND** распознанная структурная связь не расширяет согласие или права записи
