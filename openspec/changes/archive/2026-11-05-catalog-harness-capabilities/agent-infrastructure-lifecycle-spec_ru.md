## MODIFIED Requirements

### Requirement: Practice discovery accepts explicit version context

Существующая read-only команда practices SHALL принимать необязательный структурированный ввод версий выбранных корректных ID harness, сохраняя прежний вызов только с agents. Неверные или не относящиеся к выбору версии SHALL отклоняться до сети. Отсутствующие версии SHALL оставаться явными gaps. Ввод SHALL оставаться данными и SHALL NOT запускать агента или записывать состояние проекта/пользователя.

#### Scenario: Selected versions are supplied through stdin or a file

- **WHEN** practices получает выбранные ID каталога и корректные необязательные версии
- **THEN** записи источников сохраняют переданную версию соответствующего агента
- **AND** stdin и существующий файл дают одинаковую привязку без state, кэша или правок проекта

#### Scenario: Some versions are unavailable

- **WHEN** practices вызвана без версий или с версиями части выбора
- **THEN** источники выбранных агентов могут проверяться
- **AND** каждый агент без переданной версии сохраняет agent-version-unverified gap

#### Scenario: Invalid version input is rejected before reads

- **WHEN** форма ввода, невыбранный/неверный ключ агента или пустая, длинная либо содержащая управляющие символы версия недопустимы
- **THEN** команда возвращает структурированную ошибку до чтения источников
- **AND** поля не подменяют выбранных агентов, разрешённые источники или границы исполнения

#### Scenario: Unknown selected harness has a supplied version

- **WHEN** корректный выбранный неизвестный ID имеет переданную вызывающим версию
- **THEN** проверка принимает контекст, но возвращает unsupported-agent gap
- **AND** не предполагаются запрос документации или проверенная совместимость

## ADDED Requirements

### Requirement: Practice reads share a fixed global budget

Поиск практик SHALL принимать максимум шестнадцать корректных ID, убирать повторы в порядке выбора и выполнять максимум два запроса источников на ID и шесть HTTP-запросов суммарно. Источники SHALL оставаться на явно проверенных официальных HTTPS hosts. Прежние защиты чтения, редиректов, учётных данных, содержимого и времени SHALL сохраняться. Не выполненный из-за бюджета выбор SHALL сохранять явные gaps.

#### Scenario: More than three harnesses are selected

- **WHEN** корректный выбор требует больше шести запросов
- **THEN** выполняется максимум шесть в определённом порядке выбора/источников
- **AND** каждый не прочитанный из-за общего лимита источник получает source-budget-exhausted без выдуманной проверки

#### Scenario: Sources fail or identities repeat

- **WHEN** ID повторяются или попытка чтения завершается ошибкой
- **THEN** повторы не увеличивают число чтений, неудачные попытки расходуют общий бюджет
- **AND** ошибка сохраняет фактическую причину без повторов или редиректов

#### Scenario: Invalid selection is supplied

- **WHEN** выбор содержит больше шестнадцати элементов или неверные/нестроковые ID
- **THEN** весь вызов отклоняется до сети
- **AND** выбор не задаёт произвольные домены и не меняет права возможностей
