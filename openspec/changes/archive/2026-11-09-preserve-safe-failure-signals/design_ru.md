# Design

Каноническая версия: [design](design.md).

## Context

`parseCodex` извлекает ограниченные совокупные признаки, затем заменяет ошибку хэшем. Вызывающий contained-код отдельно повторяет ту же проекцию. Исходные детали последнего незавершённого изменения памяти утрачены; эту причину не восстановить. Правило существенных противоречий уже есть, но у составления новых инструкций нет локального указателя к нему.

## Goals / Non-Goals

**Goals:** признаки отдельного события; один проектор приватных ошибок; короткий указатель при переносе утверждений; различающий проверочный пример.

**Non-Goals:** сохранение исходных ошибок, автоматическое восстановление, новые нативные прогоны, общий анализатор контрактов кода, новые полномочия и доказательство широкой совместимости.

## Decisions

1. Переиспользовать существующее извлечение и типы `messageId/httpStatus/serverCode`. Только эти три поля попадают в необязательный объект `diagnostics` события; `requestIdHash`, `retryAfterSeconds`, `internalRetryCount` туда не копируются. Пустой объект не добавляется, неизвестная запись остаётся типом/хэшем. Совокупные поля и их приоритет не меняются.
2. Добавить `context-window-exceeded`, `request-timeout`, `stream-disconnected`, `retry-limit-exhausted`. Фиксированные сообщения сравниваются точно, переменные формы — с начала до конца в известном формате. Новый предел — 2048 байт UTF-8, управляющие символы и переводы строк отклоняются. Окончания не сохраняются; идентификатор означает совпадение текста, а не установленную причину или разрешение повтора.
3. Основание — [зафиксированный исходник Codex](https://github.com/openai/codex/blob/00c972ed5d6ff6499317fd41b7f23605b8e6850d/codex-rs/protocol/src/error.rs). Root проверил литералы публичным чтением; полная локальная загрузка не удалась из-за DNS. Локальный pinned-blob не заявляется. JSONL теряет более подробные категории; выдумывать отсутствующие поля нельзя.
4. Один краткий указатель в архитектурной инструкции ведёт к действующему интервью. Правила вопросов, автономности и gaps остаются там. Безусловного приоритета README либо кода нет.
5. Один авторский JSON-пример в `scripts/evals/fixtures/project-contract-conflict.json`, пара руководств в `docs/evals/cases/project-contract-conflict/` и небольшой Node-тест. Поддержанные прежние данные различают truthiness и strict false; явное решение владельца проверяется отдельно. Автоматический каталог математических диагностик не расширяется. Проверки данных не доказывают соблюдение инструкции моделью.

## Risks / Trade-offs

- Имитация известного сообщения → ограниченный формат, негативные примеры и маркировка как наблюдения текста.
- Секрет в окончании ошибки → только фиксированные поля; оба пути проверяются синтетическими приватными значениями.
- Первое событие скрывает последующее → отдельные признаки при неизменной старой сводке.
- Новая формулировка может не помочь модели → одна ветка, без заявления о нативном исправлении.

## Migration Plan

Схемы, зависимости и опубликованная версия сохраняются. Общая инструкция — Unreleased. При откате убираются расширение диагностики и короткая ветка; старые свидетельства остаются читаемыми и неизменными.
