# Проверка переносимого процесса — 5 ноября 2026

Локальная реализация завершена, но ещё не выпущена. Опубликованные скиллы и ссылки
установки остаются на 1.2.0. Процесс использует существующую среду пользователя
с доступом к файлам/Node и выбранную модель/провайдера; наличие в каталоге больше
не является условием входа.

## Implemented behavior

- Универсальная установка явно выбирает `--agent universal`, оба полных скилла
  и прежнюю точную опубликованную привязку. Ручная установка полных папок
  и явное чтение `SKILL.md` описаны на двух языках.
- Ядро и браузер используют общую проверку известных/неизвестных строчных ID
  harness: не более шестнадцати различных значений. Старые корректные дубликаты
  остаются читаемыми. Локальная форма принимает свои ID с доступными локализованными ошибками.
- Инструкции позволяют использовать один согласованный общий `AGENTS.md` и одно
  хранилище памяти. Доступность файлов/Node/записи/активации отделена от harness,
  провайдера, модели и необязательных нативных проб. Недоступные обязательные
  операции остаются пробелами; отсутствие необязательной пробы не запрещает структурную настройку.
- Схемы, защита путей, цели нативной записи, адаптеры и права исполнения не изменены.
  Клиент моделей, учётные данные провайдера и фоновое обновление не добавлены.

## Retained corrections and limits

- Первая браузерная попытка: 34 успешных проверки и восемь ошибок. Более короткий
  текст и ожидание наблюдаемого фокуса исправили причины; пороги не менялись.
  Позднейший успех 42 проверок учитывается отдельно, исходные ошибки сохранены.
- Независимые Ponytail review кода и инструкций дали Ship. G01 ограничило
  требование Git маршрутом установщика. G02 связало команды скачивания/проверки/
  распаковки через `&&` для остановки при ошибке; блоки двух языков совпадают
  и синтаксически корректны. Первый агент инструкций получил ошибку capacity
  после сохранения ревью; root проверил артефакт и хэши входов, не выдумывая новый прогон.
- Первое ревью приёмки остановилось на A01: проверке лишних файлов проекта
  и точных одобренных байтов/режимов. Исправление проверено независимо до запуска.
- U01 завершился ошибкой после одного вызова установщика и нуля CLI: `fs.cp`
  Node потребовал метаданные родительских папок вне разрешённого дерева чтения.
  Код 0 установщика не доказывал успех; точная сверка поставки обнаружила пустые
  цели. Proposal/apply не выполнялись, защищённые файлы сохранены. U01 не повторялся.
- Отдельно запланированный и проверенный U02 дал только закреплённому доверенному
  установщику общее право чтения файлов, сохранив запись внутри тестового дерева.
  Обнаружение также может проверять системные пути приложений/конфигурации.
  Чтение/запись CLI продукта ограничены своим деревом. Полная изоляция чтения
  файлов и сетевой firewall ОС не заявляются.
- Candidate-01, его прежняя поставка для трёх целей и неиспользованные H01/H02
  остаются историческими. U02 — механическая приёмка, а не новый семантический
  прогон модели. Здесь не проверены нативное обнаружение/загрузка, последующее
  использование памяти LLM, совместимость новых моделей, тесты приложения
  и публичная установка по полному SHA.
