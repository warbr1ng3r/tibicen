# Spec Delta

## MODIFIED Requirements

### Requirement: Consistent custom selection

Элементы выбора SHALL показывать оформленные меню, выбранные значения и доступные имена. Они SHALL поддерживать управление с клавиатуры, Escape, закрытие при действии снаружи и размещение в границах viewport. Элементы установки SHALL выбирать средство запуска команды для явного универсального маршрута. Необязательные подсказки harness в пресете SHALL разрешать предложения каталога и корректные ID вне каталога без изменения установки или предоставления возможностей.

#### Scenario: Keyboard selection

- **WHEN** пользователь открывает список через Enter или Space, выбирает стрелками и подтверждает через Enter
- **THEN** значение обновляется, меню закрывается и фокус возвращается к его элементу управления
- **AND** подтверждение варианта не скачивает пресет

#### Scenario: Installation and form values

- **WHEN** пользователь меняет средство запуска команды или предпочтения пресета
- **THEN** универсальная команда установки и скачанный пресет отражают этот выбор
- **AND** подсказка языка программирования по умолчанию по-прежнему отсутствует

#### Scenario: Dismissal and viewport edges

- **WHEN** меню закрывается через Escape или щелчок снаружи либо открывается около края viewport
- **THEN** оно предсказуемо закрывается или размещает варианты без обрезания

## ADDED Requirements

### Requirement: Unknown harness hints remain local and accessible

Необязательная форма SHALL сохранять корректные ID harness вне каталога с той же проверкой, что и ядро. Неверные подсказки или избыточное число различных подсказок SHALL показывать локализованную ошибку соответствующего поля, доступную вспомогательным технологиям, и предотвращать скачивание. Исправление поля SHALL убирать эту ошибку. Ввод предпочтений SHALL оставаться локальным для браузера.

#### Scenario: A user enters a private harness

- **WHEN** посетитель объединяет предложение каталога с корректным ID частного harness
- **THEN** скачанный пресет сохраняет обе идентичности без создания записи каталога
- **AND** ни один ответ не отправляется на сервер

#### Scenario: An invalid custom identity is corrected

- **WHEN** посетитель пытается скачать пресет с неверным пользовательским ID, а затем исправляет его
- **THEN** первая попытка показывает ошибку у соответствующего поля и переводит туда фокус
- **AND** исправленный корректный пресет можно скачать без устаревшего недопустимого состояния
