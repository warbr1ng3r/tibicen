# Spec Delta

## MODIFIED Requirements

### Requirement: Preset hints follow the catalog

Проверка пресетов ядра и браузера SHALL принимать одинаковые корректные ID-подсказки harness, включая отсутствующие в каталоге, сохраняя schema 1 и существующие пресеты. Локальная форма SHALL показывать записи каталога как необязательные предложения. ID SHALL использовать существующий ограниченный синтаксис строчных slug: не более шестнадцати различных подсказок; повторяющиеся подсказки SHALL не увеличивать этот счётчик. Подсказки SHALL NOT предоставлять нативные, сетевые возможности, права записи, установки или исполнения.

#### Scenario: A user selects Gemini CLI and OpenCode

- **WHEN** локальный пресет создаётся с этими ID каталога
- **THEN** проверка браузера и ядра согласованно сохраняет их ID
- **AND** ID остаются предпочтениями, независимыми от маршрута установки и закреплённой поставки

#### Scenario: A private harness is absent from the catalog

- **WHEN** пресет содержит корректный ID вне каталога, например team-agent
- **THEN** ядро и браузер принимают и сохраняют его без требования добавить запись в каталог
- **AND** нативные инструкции, документация и возможности проб остаются неизвестными, пока не установлены отдельно

#### Scenario: A malformed or excessive hint is submitted

- **WHEN** подсказки содержат неверные или нестроковые значения, пропущенные элементы массива либо более шестнадцати различных корректных ID
- **THEN** проверка возвращает понятную ошибку с указанием способа исправления без скачивания или записи состояния
- **AND** существующие корректные пресеты, включая повторяющиеся известные ID, остаются читаемыми

## ADDED Requirements

### Requirement: Explicit portable skill workflow

Tibicen SHALL предоставлять явный рабочий маршрут через файл скилла для хоста, способного читать проект и запускать требуемую версию Node, без требований к записи в каталоге, бренду агента, модели или провайдеру. Маршрут SHALL сохранять существующий согласованный путь общих инструкций и одно хранилище памяти проекта, когда этого достаточно. Явное чтение SHALL NOT представляться нативным автообнаружением.

#### Scenario: An uncatalogued host configures an existing application

- **WHEN** хост с доступом к файлам и Node явно читает tibicen-init, а пользователь просит выполнить настройку
- **THEN** он может изучить проект и предложить согласуемые изменения общих AGENTS.md без подстановки известного бренда
- **AND** файлы приложения, полезные решения, согласие на точный план и ограничения записи сохраняются

#### Scenario: Several hosts use the same project instructions

- **WHEN** явного чтения одного согласованного AGENTS.md достаточно для работы пользователя
- **THEN** рекомендация может сохранить этот единственный файл без требований нативных связанных копий или версий
- **AND** передача результата даёт точный шаг чтения и оставляет автообнаружение непроверенным

### Requirement: Available operations are separate from model identity

Init/adopt SHALL различать доступные операции с файлами проекта, Node, записью и активацией и необязательные нативные пробы. Отсутствующая операция SHALL давать конкретный пробел или ручной шаг без требования сменить модель/провайдера или harness. Существующие нативные методы SHALL сохранять ограничения доверия, startup, версии и учётных данных.

#### Scenario: The user changes the host model or provider

- **WHEN** тот же хост выполняет необходимые операции с файлами и Node с выбранной пользователем LLM
- **THEN** обычному маршруту настройки не нужны список разрешённых моделей Tibicen, клиент провайдера или новые учётные данные
- **AND** ненаблюдаемые идентичности модели/версии остаются непроверенными, а не выдумываются

#### Scenario: The host cannot execute Node or read local files

- **WHEN** операция, необходимая для фактического изучения или применения, недоступна
- **THEN** агент объясняет именно это ограничение и предлагает применимый локальный или ручной следующий шаг
- **AND** он не утверждает, что непрочитанные файлы были изучены, а неприменённые изменения и невыполненные проверки завершены

#### Scenario: The host has no checked automatic behavior probe

- **WHEN** настройка общих инструкций доступна, но поддержанный нативный метод задачи, квиза или загрузки не установлен
- **THEN** доступная настройка продолжается в пределах согласия и структурной области
- **AND** недоступные необязательные проверки поведения остаются явными, не превращаясь в выдуманный успех или полный отказ от использования продукта
