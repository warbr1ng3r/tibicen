# Spec Delta

## MODIFIED Requirements

### Requirement: Equivalent installer commands

Установка SHALL предлагать npm, pnpm и Yarn 2+ с одинаковыми закреплённым установщиком, точной опубликованной поставкой, двумя выбранными скиллами Tibicen и поведением копирования. Основная команда SHALL явно выбирать цель universal установщика вместо бренда или неявного автоопределения. Сборка скиллов из исходников SHALL оставаться независимой от зависимостей лендинга.

#### Scenario: A visitor switches package manager and agent

- **WHEN** посетитель выбирает npm, pnpm или Yarn 2+ для обычного маршрута установки
- **THEN** команда сохраняет skills@1.7.4, точный pin поставки, оба имени скиллов, глобальное копирование и --agent universal
- **AND** README и лендинг описывают тот же маршрут через общий каталог без обязательного выбора агента

### Requirement: First use has a direct route and recovery guidance

Лендинг SHALL объяснять два скилла внутри существующего агента пользователя с доступом к файлам и Node для первоначальной настройки или улучшения. Первое использование SHALL показывать универсальную установку, явное чтение файла скилла в сессии проекта и обычный запрос до необязательных предпочтений. Оно SHALL отделять явную загрузку от нативного обнаружения и сохранять существенные ограничения платформы/операций и полный резервный маршрут через ручное размещение каталогов.

#### Scenario: A first-time visitor follows installation

- **WHEN** посетитель открывает любой языковой маршрут и следует основному действию
- **THEN** он может определить оба скилла, общий каталог установки в пользовательской области, место запуска команды и точный первый шаг чтения/запроса
- **AND** его harness, модель и провайдер могут отсутствовать в каталоге Tibicen

#### Scenario: The agent does not find the skill

- **WHEN** автоматическое обнаружение скиллов отсутствует или неизвестно
- **THEN** страница даёт маршрут явного чтения SKILL.md вместо требования другого harness
- **AND** маршрут не заявляет автоматическое обнаружение или совместимость

#### Scenario: The installer is not a usable route

- **WHEN** посетитель выбирает ручную установку
- **THEN** руководство называет опубликованный архив и проверку контрольных сумм, оба каталога скиллов с полными ресурсами, выбранное место размещения и точный шаг явной загрузки
- **AND** оно не предлагает копировать только SKILL.md и не выдумывает нативный каталог загрузки

#### Scenario: The host lacks local operations

- **WHEN** выбранный хост не может читать файлы проекта или выполнять необходимые операции Node
- **THEN** посетитель видит конкретное локальное/ручное требование и относящиеся к нему ограничения платформы
- **AND** страница не подразумевает завершённую автоматическую настройку и не требует новых учётных данных провайдера
