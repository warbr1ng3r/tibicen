# Proposal

## Why

Изолированный проверочный стенд останавливает Codex 0.157.0 при каждом событии `error`. CLI этой версии может продолжать работу после такого события, поэтому стенд обрезает окончательный исход. Это наблюдалось после сохранения предложения для проекта документации; причина самой ошибки и исходы старых прогонов остаются неизвестными.

## What Changes

- Дождаться окончательного исхода после общей ошибки в пределах прежних ограничений времени, процесса и вывода.
- Передавать ошибки в callback только как хэш; сохранить немедленный отказ при явно определённой ошибке авторизации/доступа и все ограничения изоляции.
- До исправления воспроизвести проблему через настоящий вызывающий код без моделей. Сохранить закрытые результаты; новый живой запуск требует нового зафиксированного протокола.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `evaluation-results`: отличать промежуточное сообщение об ошибке от неуспешного завершения, сохранив критерии приёмки и защиту данных.

## Impact

Только проверочный `scripts/evals/contained-codex.ts`, связанные тесты и парные документы. Без изменений распространяемых скиллов, версии продукта, зависимостей, автоматических повторов, платного API или авторизации.
