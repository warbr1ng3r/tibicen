# Spec Delta

## ADDED Requirements

### Requirement: Native notifications await definitive outcomes
Стенд SHALL ждать окончательного исхода после общей ошибки в прежних пределах времени, процесса и вывода. Callback ошибки SHALL содержать только тип и хэш. Явная типизированная ошибка авторизации/доступа SHALL немедленно останавливать запуск. Неуспешное завершение, ненулевой код процесса или отсутствие завершённого хода SHALL исключать приёмку. Автоматические повторы SHALL NOT добавляться.

#### Scenario: A native error precedes a completed turn
- **WHEN** после общей ошибки ход успешно завершается с кодом процесса0 и соблюдены прежние ограничения
- **THEN** сообщение само по себе не останавливает сбор; callback содержит только тип и хэш
- **AND** приёмка всё ещё требует проверки исходников, конфигурации, владения и очистки

#### Scenario: The stream does not recover
- **WHEN** за ошибкой следует неуспешный ход, ненулевой код процесса или нет завершённого хода
- **THEN** запуск не принимается; факт ошибки сохраняется без исходных приватных подробностей

#### Scenario: Typed authentication or access rejection occurs
- **WHEN** ошибка содержит проверенный существующим разбором HTTP401 или403
- **THEN** стенд немедленно останавливается и проверяет очистку без повтора

## MODIFIED Requirements

### Requirement: Ordinary contained command results permit recovery
Стенд SHALL передавать корректные обычные результаты команд без изменений, включая ненулевые коды, не завершая сессию и не создавая терминальный сбой инструмента. Отсутствие необязательной диагностической связи SHALL NOT менять эту политику. Один результат команды SHALL NOT доказывать приёмку задачи.

#### Scenario: An ordinary command fails before another command
- **WHEN** исполнитель вернул корректный exit1 без явного отказа изоляции, а в пределах срока запрошена следующая команда
- **THEN** следующая команда может завершиться в том же контейнере
- **AND** исходный ненулевой результат остаётся видимым

#### Scenario: Optional diagnostics are unavailable
- **WHEN** необязательная диагностическая связь отключена по лимиту, но результат процесса корректен
- **THEN** восстановление обычной команды доступно
- **AND** неизвестная связь запросов не объявляется установленной

#### Scenario: The CLI reports the failed command before recovering
- **WHEN** CLI сообщил корректный завершённый результат команды с ненулевым кодом и статусом failed, затем успешную команду и завершённый ход
- **THEN** обе команды сохраняются, сессия остаётся доступной
- **AND** окончательные ошибки CLI, неуспешные ходы, отказанные/отменённые операции, неуспешные правки файлов и некорректные результаты команд не допускают приёмку
