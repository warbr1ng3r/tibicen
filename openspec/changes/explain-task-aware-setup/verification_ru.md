лексические отношения кандидатов. Обе ветки передают контекст в рекомендацию,
проверку и handoff. Нативная применимость требует отдельной оценки; без наблюдений
загрузка и использование остаются unverified.

## Помощь и сохранённые ограничения

Первые CLI-предложения показали обычный счётчик настоящего пользователя; ни одно
не применено. Тот же input через существующий API зафиксированной поставки с явным
home привязан к отдельным принадлежащим стенду папкам, новым digest и одобрениям.
Apply использовал те же runtime hooks, что CLI. HOME/идентичность окружения и
продукт не записывал данные в настоящую домашнюю папку пользователя. Это тест с помощью API, а не полная
нативная CLI-приёмка. A1 сохранил ошибку драйвера readFile с fd 0 до исправления
передачи ввода. При ней PATH из другого cwd выбрал Node 25.8.0; оставшееся выполнение
закреплено за абсолютным Node 24.15.0. Повторного выбора решения и повторного apply нет.

Явное чтение скилла/инструкций — помощь. Нативное поведение целевых хостов/моделей,
автообнаружение, общая совместимость и человеческая польза не проверены. Платный
API, сеть, учётные данные и нативные запуски не использовались.

## Независимое ревью

Ponytail review не нашло блокеров кода/запуска и заметило один пример памяти без
настоящей замены устаревшего правила. В обеих версиях теперь есть старое правило
показа нуля и требование заменить его, сохранив единицы суммы и заметку о
зависимостях. Ревьюер проверил исправление, изолированный home, точные файлы и
журналы проверок. Итоговое независимое ревью: Ship в указанной локальной области с явной помощью; оставшихся замечаний нет. Ревьюер проверил точные байты/права кандидата и текущей сборки, замену только home в планах, одобренные единственные apply/session/attempt, сохранность файлов и обе поправки памяти. Нативные запуски, автообнаружение, общая совместимость моделей и человеческая польза не проверялись. Канонический [отчёт](verification.md).
