# Proposal preview delta

Канонические требования и сценарии: [spec](specs/agent-infrastructure-lifecycle/spec.md).

## MODIFIED Requirements

### Requirement: Adopt explains the smallest necessary outcome

Прежний контракт сохраняется: понятные исходное состояние, находки, keep/change, проверки/границы и следующий шаг; точный план до согласия и допустимый no-change. Текстовый diff сохраняет все изменённые строки, опуская неизменные края за пределами трёх строк контекста. Достаточен один общий hunk от первой до последней правки, без алгоритма минимальных нескольких hunk. Добавление/удаление, пустые файлы, CRLF и последний перенос должны различаться. Полный согласуемый текст, исходные хэши, режимы и прежние одобренные планы не меняются/не нормализуются.

#### Scenario: Existing setup is sufficient
Сохранить пояснение достаточности, без выдуманной правки/сессии.

#### Scenario: Useful decisions have a missing connection
Сохранить заметки, точное минимальное подключение и прежнее согласие.

#### Scenario: A single line changes in a long instruction file
Точная замена и максимум три строки контекста с каждой стороны, корректные диапазоны; полный текст/хэш/режим связаны digest.

#### Scenario: A file boundary or line ending changes
Точно показать добавление/удаление, пустой файл, mode-only, CRLF/конечный перенос, не меняя байты.
