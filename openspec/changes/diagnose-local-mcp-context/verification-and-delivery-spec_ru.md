# Spec Delta

## ADDED Requirements

### Requirement: MCP diagnosis separates configuration and effective source

Диагностика MCP только для чтения SHALL изучать один выбранный сервер в явно
переданных источниках проекта. Она SHALL разделять переданный хост/версию,
выбор источника, корректность конфигурации, отключение и сведения о целевом
запуске. Порядок входов или наличие файла SHALL NOT устанавливать фактический
приоритет, установленные версии, соединение или использование инструмента.

#### Scenario: The same name occurs in two sources

- **WHEN** несколько записей определяют выбранный сервер без подтверждённого действующего источника
- **THEN** действие источников остаётся непроверенным, записи не сливаются
- **AND** выбор источника сохраняет границу переданного вызывающим свидетельства

#### Scenario: Correct local format has unknown target environment

- **WHEN** корректная запись есть, но целевой контекст запуска не установлен
- **THEN** доступность исполняемого файла, cwd и требуемого окружения остаётся непроверенной
- **AND** соединение и использование в задаче не становятся успешными из-за корректности конфигурации

### Requirement: MCP config inspection is bounded and redacted

CLI диагностики SHALL валидировать метаданные до чтения проекта и читать не
больше четырёх разрешённых обычных файлов проекта до 1 MiB каждый. Он SHALL
сохранять запрещённые пути и отклонять переходы к родителям, чувствительные пути
и символьные ссылки. Результаты SHALL содержать имена и фиксированные данные
статуса/причины, без сырых настроек, значений команды/аргументов/окружения или
содержимого исключений. CLI SHALL NOT исполнять код или разрешать секреты.

#### Scenario: Configuration contains credentials or file substitutions

- **WHEN** выбранная конфигурация содержит встроенные значения окружения или ссылку на файл
- **THEN** значения, содержимое ссылки и сырая ошибка не возвращаются
- **AND** файл ссылки не читается, неподдержанное содержимое получает ручное ограничение

#### Scenario: A requested source is unavailable

- **WHEN** доступ к источнику не удался, превысил границы или запрещён
- **THEN** диагностика фиксирует недоступный источник, не считая сервер отсутствующим
- **AND** не записывает состояние/файлы проекта и не запускает нативную команду

### Requirement: MCP readers retain host format boundaries

Диагностика SHALL распознавать ограниченный JSON Claude/Cursor, JSON stdio
Gemini и явно выбранную структуру JSON OpenCode V2. Удалённый транспорт,
неоднозначный JSON, неподдержанные поля и неизвестные состояния отключения/политик
хоста SHALL сохранять явные ограничения. Описательное чтение SHALL NOT расширять
адаптеры записи.

#### Scenario: Gemini contains a URL and command together

- **WHEN** запись сервера Gemini содержит удалённый URL вместе с локальной командой
- **THEN** применяется исход неподдержанного удалённого транспорта вместо корректного stdio

#### Scenario: OpenCode override replaces a record

- **WHEN** явно выбранный действующий источник выбирает запись V2 из нескольких определений
- **THEN** диагностика использует эту запись целиком, не наследуя команду или окружение нижестоящих источников
- **AND** отключение и неподдержанные данные V1/неизвестного формата остаются видимыми
