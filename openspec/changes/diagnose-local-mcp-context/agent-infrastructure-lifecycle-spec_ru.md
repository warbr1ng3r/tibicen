# Spec Delta

## ADDED Requirements

### Requirement: Init and adopt explain actionable MCP outcomes

Оба входных сценария SHALL связывать полезный запрос или симптом MCP с выбранным
сервером, сведениями о действующем источнике, текущей конфигурацией и минимальным
необходимым исправлением либо нативным следующим шагом. Прежние поддержанные
механизмы записи и точное согласование SHALL оставаться определяющими. Нативные
команды, способные запускать серверы, SHALL сохранять границы исполнения/доверия;
диагностическое название SHALL NOT означать выполнение только для чтения.

#### Scenario: Supported record needs one correction

- **WHEN** у подтверждённого поддержанного локального источника показан дефект конфигурации
- **THEN** агент предлагает точный необходимый upsert/remove через прежний механизм записи
- **AND** посторонние записи, настройки и решения владельца сохраняются
- **AND** после согласованного исправления повторяется та же ограниченная диагностика без утверждения о соединении

#### Scenario: Native source or target process remains unknown

- **WHEN** доступные разрешённые сведения не устанавливают полезной диагностикой источник или контекст запуска
- **THEN** агент объясняет конкретное ограничение и один нативный следующий шаг
- **AND** не угадывает путь и не ослабляет доверие к папке, фильтрацию секретов или решения об отключении
- **AND** не навязывает новую анкету или смену хоста/модели

#### Scenario: A valid setup needs no change

- **WHEN** в изученной области необходимость исправления не установлена
- **THEN** результат может сохранять конфигурацию с явными ограничениями
- **AND** не создаёт новую сессию или компонент только ради фиксации активности
