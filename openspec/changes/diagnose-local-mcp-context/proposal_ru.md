# Proposal

## Why

Прежние проверки MCP валидируют выбранные локальные записи, но не объясняют,
какой источник определяет сервер и почему внешне корректная настройка всё равно
не даёт инструментов. После исследования 1.3 и пакета контекста задачи владелец
согласовал полный сценарий диагностики/исправления без рутинных пауз согласования.

## What Changes

- Добавить диагностику одного сервера только для чтения с явными источниками,
  выбранным хостом/версией, состоянием отключения/переопределения и наблюдениями
  целевого запуска.
- Читать разрешённые настройки проекта через ограниченный код первой стороны;
  возвращать только имена/статусы, без текста настроек, значений команды/аргументов
  или окружения.
- Поддержать прежний JSON Claude/Cursor, ограниченный JSON Gemini и явно
  выбранный JSON OpenCode V2. Сохранить все существующие контракты изменений.
- Подключить init/adopt к одному объяснению с приоритетом нативных средств и
  точным поддержанным исправлением либо оставшимся нативным действием, без
  неявного запуска MCP или обязательной анкеты.
- Завершить целевые проверки, приёмку standalone CLI и независимое ревью в одной
  сводной записи проверки с соседними русскими переводами.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `verification-and-delivery`: ограниченная диагностика MCP без вывода содержимого
  с отдельными результатами источника, статической конфигурации, целевого
  контекста и недоступного соединения/использования.
- `agent-infrastructure-lifecycle`: понятная диагностика/исправление MCP в обоих
  входных сценариях с сохранением доверия к нативному запуску и прежних
  согласованных областей записи.

## Impact

Новое общее представление/валидатор MCP, ограниченное чтение проекта и команда
CLI; целевые тесты, устанавливаемые инструкции и парные руководства. Прежние
`mcp-verify`, механизмы записи и сохранённые схемы остаются совместимыми. Не
добавляются зависимости, адаптеры записи, разрешение секретов, проверка здоровья
сервера, автоматическая установка, платные API, изменение учётных данных,
версия пакета, коммит или публикация.
