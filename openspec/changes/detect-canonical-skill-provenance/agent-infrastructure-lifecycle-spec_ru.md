# Маркер установленного Tibicen

Основные требования — [spec.md](specs/agent-infrastructure-lifecycle/spec.md).

Scan считает каталог скилла установленным Tibicen только при наличии его
`package.json` с каноническим `name` и непустой строкой `version`. Одно имя
каталога не подтверждает происхождение; двойник без маркера считается сторонней
инфраструктурой и сохраняет подсказку improve.

- Двойник `.agents/skills/tibicen-init/` без маркера остаётся сторонним.
- Подлинная установка любого опубликованного выпуска сохраняет init/not-configured,
  когда в проекте нет иной агентской инфраструктуры.
- Сторонний скилл под другим именем сохраняет improve.
- Маркер относится только к полному пути своего каталога относительно проекта.
  Он не идентифицирует двойника в корне, вложенном или соседнем проекте.
- Повреждённый JSON, чужое имя или отсутствующая версия не устанавливают
  каноничность; обычному стороннему содержимому не выдумывается scan gap.

Это локальный признак для маршрутизации. Дословное копирование маркера
не отличает подмену от подлинной поставки и не доказывает аутентичность.
