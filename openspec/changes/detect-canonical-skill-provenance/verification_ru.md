# Проверка маршрутизации по маркеру

Основная версия — [verification.md](verification.md).

## Интеграционное ревью Codex — 20 ноября 2026 года

Возвращённый набор маркеров терял родительские префиксы проекта. Root воспроизвёл,
как подлинный вложенный маркер делает отдельного двойника в корне каноническим:
новая регрессия упала до исправления (5 passed / 1 failed), затем исправленный
scan и прежний набор прошли 22/22. Корень, вложенные и соседние каталоги
проверяются по полным путям. В отрицательный тест добавлена подлинная база с
маркером, чтобы он не проходил только из-за отсутствия маркера у базы.
Независимое повторное ревью: Ship.

[Оценка интеграции](../../../docs/evals/results/2026-11-20-consent-coverage-assessment/README.md)
фиксирует общий gate, отдельную standalone-сборку и пределы свидетельств.
Неудача замороженного A5-i3 сохранена; локальная регрессия не является новым
поведенческим наблюдением.

Финальный общий `pnpm test`: 1 209 всего / 1 207 passed / 0 failed / 2 прежних skip,
exit 0. Отдельная сборка и копия вне checkout прошли все 116 payload-хэшей/режимов,
оба изолированных self-test и 14 настоящих CLI-вызовов. Оценка по ссылке отдельно
сохраняет первую неудачу общего gate и неизвестную причину оффлайн-контроля.
Оба интеграционных изменения завершены и остаются Unreleased.
