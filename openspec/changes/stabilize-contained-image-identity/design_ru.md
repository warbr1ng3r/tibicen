# Решения по идентичности образа

Независимая диагностика сопоставила двенадцать сохранённых ответов. Текущий хеш всего inspect безопасно отказывает, но без доказанного изменения исполняемого образа останавливает разрешённое наблюдение.

- Фиксируются версия отпечатка, ID, ОС, архитектура, variant либо null, полные Config и RootFS.
- Ключи объектов рекурсивно упорядочиваются; порядок массивов сохраняется. Config и RootFS не сокращаются до одного entrypoint.
- Нужны корректные обязательные поля и непустой упорядоченный список SHA-256 слоёв. Проверки закреплённого ID, Linux arm64, root и watchdog сохраняются.
- Упорядочивание остаётся локальным для самостоятельного профиля, без лишнего дерева зависимостей.
- До следующей live-попытки фиксируются новые исходники/отпечаток и проводится независимое ревью. Остановленный кейс скилла не переписывается и не повторяется.

Проверяются две формы ответа, порядок ключей, изменения конфигурации/слоёв и неполные поля через настоящий seam профиля; затем focused-проверки, независимое ревью, полный offline-gate и равенство дистрибутива. Канонический [дизайн](design.md).
