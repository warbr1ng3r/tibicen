# Уточнение профиля контейнерного Codex

Отпечаток должен фиксировать версию формата, ID образа, ОС, архитектуру, необязательный variant, полные конфигурацию и файловую идентичность. Порядок ключей объектов не влияет на отпечаток; порядок массивов значим. Служебная оболочка inspect не входит в идентичность исполнения.

- При одинаковой идентичности и разных GraphDriver/Descriptor/Identity или порядке ключей повторная проверка принимает образ, сохраняя ограничения ID и изоляции.
- При изменении конфигурации, слоя или порядка слоёв проверка отказывает до запуска нативной задачи.
- При отсутствующих или некорректных обязательных конфигурации/файловой идентичности инспекция отказывает.
