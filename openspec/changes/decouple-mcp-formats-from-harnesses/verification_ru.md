# Verification

Перевод [канонической проверки](verification.md). 6 ноября 2026, Europe/Moscow.
Локальный Unreleased-пакет поверх прежних task-aware и MCP изменений. Версия
пакета и опубликованная 1.3.0 сохраняются. Коммита, push, публикации, платного API
и операций с личными настройками не было.

## Implemented scope

Любой корректный ID харнесса может выбрать один из восьми ограниченных форматов
либо общий `stdio-observation`. Модель/провайдер и каталог не ограничивают
диагностику. JSON/TOML-парсеры возвращают отдельные результаты; для произвольного
языка можно передать безопасные состояния/имена env с SHA-256 прочитанного UTF-8
текста. `reported-stdio`/`caller-observation` отличается от
`valid-stdio`/`parsed-format`; хэш не доказывает семантику или безопасность.
Изменившийся либо недоступный источник обесценивает наблюдение.

Добавлены ZCode native/shared JSON, актуальный Kimi Code JSON и подмножество
TOML Mistral Vibe. Сохранены прежние defaults, неопределённость источника/запуска,
границы чтения и безопасный вывод. Активация и подключение не подтверждаются.
Формат не даёт права записи: нужны совпадающие существующий харнесс, формат,
явно выбранный источник и точный разрешённый путь.

[Руководство форматов](../../../docs/MCP_FORMATS.md) содержит датированные
первичные источники, ограничения политик и общий путь для других харнессов,
включая YAML DeepSeek Harness и приложения GigaChat с настройками в коде.
Обновлены пять EN/RU пар и одна устанавливаемая инструкция для обоих сценариев.
Зависимости runtime не добавлялись.

## Review corrections

- Root нашёл приведение типа состояния: массив мог пройти проверку enum.
  Теперь нужен точный строковый тип, добавлена регрессия.
- Root нашёл принятие одиночного CR в TOML literal. Такой CR отклоняется,
  поддержанные CRLF/LF сохраняются.
- Независимое Ponytail review нашло Unicode-пробелы вне TOML-строк из-за общего
  trim. Теперь обрезаются только ASCII space/tab; NBSP/BOM отклоняются, Unicode
  внутри строк поддерживается.

На все исправления есть проверки. Независимый итоговый прогон MCP/CLI/ресурсов:
**62/62**, без пропусков. Ревьюер также сравнил 15 случаев определения таблиц с
Python TOML и проверил первичные контракты. Оставшихся замечаний к коду и
инструкциям не обнаружено.

Первая попытка локального acceptance-скрипта прошла сценарии и portable lifecycle,
но ошиблась в проверке лога: Node выбрал spec reporter вместо TAP. Harness теперь
явно запрашивает TAP. Логи `attempt-01-*` сохранены; это не итоговая приёмка байтов
и не дефект продукта. Исправленные во время реализации ожидания core-тестов
сохраняют прежнее различие состояния источника и выбранной конфигурации.

## Limits

Проверки офлайн, наблюдения переданы вызывающим в контролируемых fixtures.
Нативные приложения, MCP handshake, обнаружение инструментов, живые модели и
пользовательская полезность не проверялись. TOML — явное подмножество; иной
синтаксис использует наблюдения. Факты запуска остаются переданными сведениями.
Автоматическая запись — прежние Claude/Cursor, Codex сохраняет ручной helper.
Поведение сайта не менялось; новая браузерная матрица не требовалась.
