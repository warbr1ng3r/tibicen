# Proposal

Перевод [канонического предложения](proposal.md).

## Why

Локальная диагностика MCP выбирает разбор по четырём ID харнессов. Поэтому
неизвестный харнесс не может использовать известный контракт конфигурации.
Пользователю также нужна поддержка форматов ZCode, Kimi Code и Mistral Vibe.

## What Changes

- Явный формат выбирает ограниченный разбор независимо от ID харнесса;
  существующие запросы с форматом по умолчанию сохраняются.
- Для остальных форматов принимаются безопасные наблюдения с хэшем источника;
  они остаются сведениями от агента, а не подтверждённым результатом парсера.
  Запись в каталоге или отдельный парсер не обязательны для диагностики.
- Добавляются читающие адаптеры ZCode native/shared JSON, актуального Kimi Code
  JSON и документированного ограниченного подмножества TOML Mistral Vibe.
- Формат, активация в приложении, модель/провайдер, подключение и разрешённая
  запись учитываются отдельно в результате и обоих сценариях работы.
- Компактная EN/RU матрица контрактов, проверка установленного CLI вне исходного
  репозитория и независимое Ponytail review завершают пакет.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `verification-and-delivery`: диагностика по явно выбранному формату для
  неизвестных харнессов и дополнительные ограниченные читающие адаптеры.

## Impact

Диагностика MCP и тесты, устанавливаемая инструкция, парные руководства,
фиксация состава дистрибутива и трекер разработки. Границы чтения секретов,
точное согласование, запись, зависимости runtime и опубликованная 1.3.0
сохраняются. Личные настройки, запуск серверов, платный API, новая версия,
коммит, push и публикация в этот пакет не входят.
