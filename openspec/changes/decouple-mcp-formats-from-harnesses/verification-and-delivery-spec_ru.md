# Spec Delta

Перевод [канонических требований](specs/verification-and-delivery/spec.md).

## ADDED Requirements

### Requirement: MCP format choice is independent from harness identity

Диагностика SHALL принимать явный поддержанный формат для любого корректного
ID харнесса, сохраняя прежние значения по умолчанию. Свидетельства формата,
личность харнесса и активация различаются. Неизвестный формат сохраняет явное
ограничение; выбор формата не выдаёт право записи.

#### Scenario: An uncatalogued host uses a known contract

- **WHEN** неизвестный ID выбирает известный формат
- **THEN** читается этот контракт с сохранением исходного ID
- **AND** выбор отмечен как переданный вызывающим, активация не подтверждена

#### Scenario: No known contract is selected

- **WHEN** формат не указан или неизвестен
- **THEN** синтаксис и приоритет не угадываются по бренду или пути
- **AND** остаётся общий путь безопасных наблюдений

#### Scenario: Reader choice cannot obtain a writer

- **WHEN** неизвестный харнесс выбирает Cursor JSON либо Cursor выбирает другой контракт
- **THEN** одного выбора формата недостаточно для записи
- **AND** нужны существующий харнесс, совпадающий формат записи и явно выбранный точный путь

### Requirement: General MCP observations retain their evidence boundary

Любой корректный харнесс SHALL иметь возможность передать безопасные наблюдения
stdio с хэшем источника. Они отличаются от подтверждения парсером. Недоступный
или изменившийся источник обесценивает наблюдение. Метаданные содержат только
ограниченные состояния, хэши и имена переменных, не команды и значения.
Наблюдения не разрешают запись или исполнение.

#### Scenario: A host uses an otherwise unsupported configuration language

- **WHEN** хэш переданного stdio-наблюдения совпадает с источником
- **THEN** результат сообщает о наблюдении вызывающего и необходимых именах переменных
- **AND** явно переданные сведения запуска позволяют найти недостающие условия
- **AND** семантика, активация, подключение и использование не подтверждаются

#### Scenario: An observation becomes stale or contains executable data

- **WHEN** хэш изменился, источник недоступен или метаданные содержат команды/значения
- **THEN** старые сведения не становятся актуальным результатом парсера
- **AND** некорректные метаданные отклоняются до чтения проекта
- **AND** исходный код, YAML-теги и shell-фрагменты не исполняются

#### Scenario: A reported disable choice is preserved

- **WHEN** наблюдение с совпавшим хэшем сообщает об отключённом сервере
- **THEN** результат сохраняет отключение и происхождение сведений
- **AND** исправление автоматически не включает сервер

### Requirement: Additional MCP readers preserve native contract limits

Диагностика SHALL читать ограниченные форматы ZCode native/shared JSON,
актуального Kimi Code JSON и TOML Mistral Vibe. Поля и отключение учитываются
согласно выбранному контракту. Неподдержанный синтаксис, буквальные env и внешние
политики сохраняют ограничения. Чтение ограничено и безопасно, без исполнения
конфигурации или вывода приоритетов из порядка источников.

#### Scenario: ZCode native and compatibility sources differ

- **WHEN** выбран native mcp.servers либо shared mcpServers
- **THEN** применяется только выбранный контракт
- **AND** агент объясняет fallback и области без смешения записей и выдуманного приоритета

#### Scenario: Kimi has a disabled or nonlocal server

- **WHEN** сервер Kimi отключён либо выбирает нелокальную среду
- **THEN** сохраняется отключение либо ограничение целевой среды
- **AND** доверие к проекту не предполагается и не ослабляется

#### Scenario: Vibe uses a supported or unsupported TOML construct

- **WHEN** весь источник соответствует документированному подмножеству TOML
- **THEN** локальная запись разбирается без исполнения
- **AND** неоднозначность, дубликаты и неподдержанный синтаксис дают ручной шаг без сырых ошибок

#### Scenario: Two formats use different environment rules

- **WHEN** похожие записи имеют разные правила подстановки или буквального env
- **THEN** используется выбранный контракт без заимствования синтаксиса
- **AND** значения переменных и файлы по ссылкам не разрешаются и не раскрываются
