# Design

Перевод [канонического дизайна](design.md).

## Context

Существующая чистая диагностика объединяет выбор источника, безопасный результат
и сведения запуска для четырёх читающих адаптеров. CLI проверяет метаданные до
чтения максимум четырёх безопасных файлов проекта по 1 MiB. Общий процесс
инструкций/памяти уже допускает неизвестные ID харнессов.

## Goals / Non-Goals

Полезная диагностика для любого харнесса без списка разрешённых брендов/моделей.
Родные парсеры повышают уверенность для конкретных форматов и необязательны.
Существующие запись, согласование и свидетельства среды сохраняются. Запуск
серверов, новые записывающие адаптеры, API-клиенты и исполнение конфигов исключены.

## Decisions

1. Явный формат выбирается независимо от `agent`. Прежние значения по умолчанию
   и явный OpenCode V2 сохраняются. `formatEvidence` сообщает `caller-supplied`,
   `harness-default` либо `unverified`; `nativeActivation` остаётся `unverified`.
2. Общий результат использует восемь контрактов: `claude-code-json`, `cursor-json`,
   `gemini-cli-json`, `opencode-v2`, `zcode-native-json`, `zcode-shared-json`,
   `kimi-code-json`, `mistral-vibe-toml`, плюс общий `stdio-observation`.
   Запрос выбирает один контракт без угадывания по пути. Для записи нужны
   совпадающие существующий харнесс, формат и явно выбранный путь.
3. Для `stdio-observation` источник содержит
   `observation: {sourceHash, state: stdio|disabled|unknown, envNames: string[]}`.
   SHA-256 сравнивается с прочитанным UTF-8 текстом. Результат
   `reported-stdio` и `configuration.basis: caller-observation` отличается от
   `valid-stdio`/`parsed-format`. Хэш связывает прочитанный текст, но не доказывает семантику и не охватывает произвольный бинарный формат.
   Явные наблюдения целевой среды позволяют искать недостающие условия без
   выдачи записи. Старый/недоступный источник даёт unverified. Python, YAML-теги
   и shell не интерпретируются.
4. JSON использует существующий однозначный разбор. ZCode native читает
   `mcp.servers`, shared — `mcpServers`, отключение — `enable: false`. Kimi
   читает `mcpServers`, `enabled: false` и только локальный/default target;
   иной `environment_id` требует ручного шага. Vibe — `[[mcp_servers]]` и
   `disabled: true`. Непустые буквальные env остаются ручным ограничением.
5. Небольшой автономный TOML-парсер Vibe поддерживает однострочные строки,
   booleans, ограниченные числа, массивы, inline-таблицы, обычные секции и
   массивы таблиц. Дубликаты, неоднозначность и остальной неподдержанный синтаксис
   отклоняются во всём источнике. Shell-разбиение не выполняется.
6. Устанавливаемая инструкция начинается с возможностей и общего пути, затем
   объясняет пробелы источника/среды. Родные примеры — отдельные проверенные
   форматы. YAML/код DeepSeek Harness и SDK GigaChat не превращаются в JSON.

## Risks / Trade-offs

- Наблюдения могут ошибаться → отдельные происхождение и статус, семантика и
  активация/подключение/использование не подтверждаются хэшем.
- Похожий JSON различается → отдельные контракты и явные границы политики.
- TOML поддержан частично → отказ на неподдержанном синтаксисе и общий путь наблюдений.
- Выбор разбора может ошибочно дать запись → регрессионные проверки ID/формата/пути.

## Migration Plan

Совместимое дополнение Unreleased без новой версии. При новом модуле обновляется
фиксация состава дистрибутива; итоговые байты проходят полные проверки, автономную
поставку и независимое ревью. Старые результаты не переименовываются.
