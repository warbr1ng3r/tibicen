# Spec Delta

## ADDED Requirements

### Requirement: Locale-complete interaction feedback
Подписи, подсказки, ошибки установки/пресета, ход/успех/отказ копирования и сообщения скачивания SHALL соответствовать языку страницы, включая доступные тексты. Ошибочные поля SHALL сохранять связи с сообщениями, фокус и восстановление на обоих языках.

#### Scenario: Invalid values are rejected in either locale
- **WHEN** на английском либо русском переданы неверные имя, процесс, стиль ответов, агент, подсказка языка программирования, типа проекта либо запретный путь
- **THEN** одинаковое правило отклоняет значение с сообщением на языке страницы без скачивания
- **AND** браузерные ошибки имени/пути указывают поле и переводят фокус, раскрывают advanced при необходимости и исчезают после исправления

#### Scenario: Copy succeeds or fails
- **WHEN** посетитель копирует установку либо первый запрос
- **THEN** ход и успех копирования показаны на текущем языке
- **AND** если clipboard и fallback через выделение недоступны, локализованное сообщение объясняет ручное копирование

#### Scenario: A valid preset is downloaded
- **WHEN** посетитель отправляет валидный пресет на любом языке
- **THEN** preset.yaml скачивается локально с локализованным сообщением без сетевого запроса с ответами

### Requirement: Locale-independent installation and preset values
Язык страницы SHALL менять только представление. Равные выборы SHALL создавать побайтно равные команды установки и пресеты. ID агентов, токены менеджеров, schema, имена полей и defaults SHALL сохраняться; язык страницы SHALL NOT попадать в подсказку языка программирования.

#### Scenario: All installer choices remain equivalent
- **WHEN** выбран любой из трёх существующих менеджеров и трёх целей установки на любом языке
- **THEN** команда равна прежней закреплённой релизной команде для этого выбора
- **AND** default остаётся `npx skills@1.7.4 add https://github.com/warbr1ng3r/tibicen/tree/v0.1.0-alpha.1 -g --agent codex --skill tibicen-init tibicen-adopt --copy`

#### Scenario: UI language is separate from project preferences
- **WHEN** посетители скачивают одинаковые пресеты из EN/RU, включая пустые подсказки стека по умолчанию
- **THEN** результаты побайтно одинаковы, нового locale-поля либо языковой подсказки из языка страницы нет
- **AND** выбор языка программирования назван отдельно от переключателя языка страницы

#### Scenario: No-JavaScript locale navigation preserves privacy
- **WHEN** посетитель переходит EN → RU → EN без JavaScript и пытается отправить пресет
- **THEN** страницы читаемы, controls пресета отключены, ответы не передаются
