# Spec Delta

## ADDED Requirements

### Requirement: English-default bilingual static routes
Лендинг SHALL отдавать английский на базовом маршруте и русский на `ru/`. На обеих страницах SHALL быть доступная ссылка языка, видимая на мобильном и работающая без JavaScript; текст, title, description, html language и доступные подписи SHALL соответствовать языку.

#### Scenario: A visitor opens the base route
- **WHEN** посетитель открывает `/` либо `/tibicen/` с соответствующим hosting base, включая русский язык браузера или отключённый JavaScript
- **THEN** готовая страница английская, содержит установку, оба первых запроса и рабочую ссылку русского языка
- **AND** определение locale или автоматический редирект не требуются

#### Scenario: A visitor switches languages under a project base
- **WHEN** посетитель проходит по языковой ссылке с `/tibicen/` на `/tibicen/ru/` и обратно на desktop/mobile
- **THEN** текст и метаданные соответствуют языку, ресурсы/лицензии остаются внутри base, оба маршрута работают без JavaScript

### Requirement: Compact first-use and illustrative results
Лендинг SHALL размещать установку и оба первых запроса вместе после hero, до необязательного пресета. Он SHALL показывать один короткий процесс и явно иллюстративный пример до/после и отчёта: изменение инфраструктуры, сохранность приложения, проверки и непроверенную работу.

#### Scenario: A visitor starts without configuration
- **WHEN** страница открыта на любом языке
- **THEN** можно установить скиллы и скопировать init/adopt-запрос без заполнения пресета или возвращения к прежней секции
- **AND** пресет свёрнут, полные объяснения процесса не повторяются, имя manifest-файла не становится главной пользой

#### Scenario: A visitor examines the example
- **WHEN** посетитель читает пример результата
- **THEN** он явно назван иллюстрацией, а не измеренным либо гарантированным исходом
- **AND** различаются согласованное изменение инфраструктуры, сохранённые файлы приложения, проверки и непроверенное поведение агента

### Requirement: Evidence-scoped support and project links
Лендинг SHALL использовать общее обозначение coding agents в основном обещании. Он SHALL сохранять реальные цели установки, различать проверенную доставку, эксперименты и app-упражнения, показывать ограничения платформ и ссылки на исходники/релиз/английские инструкции рядом с установкой. Сторонние notices SHALL оставаться доступны.

#### Scenario: A visitor evaluates installation support
- **WHEN** посетитель выбирает Codex, Claude Code либо Cursor
- **THEN** показано различие проверенной доставки macOS/Node24/Codex и экспериментальных целей; скопированный скилл в ZCode не выдаётся за всеобщую поддержку
- **AND** ограничения исполнения команд на Windows и основные английские инструкции доступны до установки

#### Scenario: A visitor follows project links
- **WHEN** посетитель использует ссылки у установки или в footer на любом языке
- **THEN** исходники, release notes и инструкции установки/обновления/удаления ведут в реальный Tibicen-репозиторий и английскую документацию
- **AND** notices AstroWind и Starwind доступны внутри hosting base
