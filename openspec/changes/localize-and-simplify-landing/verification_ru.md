# Verification

Локальная реализация проверена 28 октября 2026 года до коммита и публичной выкладки. Следующие разделы сохраняют результаты этого локального этапа; отдельная квитанция публикации приведена ниже. Оба статических маршрута используют общую вёрстку; опубликованные alpha-скиллы и release tag/assets не менялись.

## Delivered behavior

- Английский на базовом маршруте, русский на `ru/`, видимые EN/RU-ссылки без автоматического locale-редиректа. Оба работают без JavaScript; переход сбрасывает несохранённую форму.
- Переведены страница/компоненты/доступные подписи/noscript, metadata, ошибки и сообщения копирования/скачивания. Язык страницы не становится подсказкой языка программирования проекта.
- Установка и оба первых запроса вместе после hero; один короткий процесс и явно иллюстративные до/после/отчёт. Необязательный пресет свёрнут, выводимые из проекта подсказки — в advanced.
- Реальные source/release/английские docs-ссылки и фактические tested/experimental/platform ограничения. Токены установщика и схема/данные пресета сохранены; без новых зависимостей, аналитики и сервисов.

## Review and repair

Независимое ponytail-review проследило оба маршрута, base-ссылки/ресурсы, компоненты и доступные тексты, все ветви ошибок, clipboard fallback, приватность скачивания, неизменность данных/команд и заявления о поддержке. Итог: Ship.

Браузерная приёмка обнаружила реальное схлопывание меню WebKit после переноса подсказок в advanced. Inline-высота Select может устареть после прокрутки при фокусе и изменения стороны меню. Первый широкий CSS override вызвал регрессии других движков и был отклонён. Итоговое небольшое исправление сохраняет прежние placement/верхние ограничения и место для одного пункта: минимум popup 56px, списка 44px. Исходная регрессия и все 12 низких окон проходят; финальное независимое review приняло это исправление. Package/runtime patch и lockfile не менялись.

Приватные логи, неудачные попытки, скриншоты и пробы сохранены в локальном архиве свидетельств; это не публичные артефакты. Финальный браузерный лог — `playwright-final.log`; отклонённые попытки сохранены отдельно.

## Публикация: 28 октября 2026 года

Проверенные исходники опубликованы коммитом [`31694d4`](https://github.com/warbr1ng3r/tibicen/commit/31694d4b234efc82064b8a1799f7a179a6541041). [Полный offline CI](https://github.com/warbr1ng3r/tibicen/actions/runs/40689855224) прошёл; [GitHub Pages](https://github.com/warbr1ng3r/tibicen/actions/runs/40690279699) успешно развернул тот же коммит. Независимое сравнение всего публичного дерева подтвердило совпадение всех **473 файлов** с проверенным кандидатом, включая шесть обновлённых PNG-эталонов.

Приёмка публичного сайта подтвердила:

- [Английский корень](https://warbr1ng3r.github.io/tibicen/) и [русский маршрут](https://warbr1ng3r.github.io/tibicen/ru/) возвращают HTTP 200; восемь проверенных ресурсов также возвращают 200.
- В обеих языковых версиях браузерные проверки прошли: проверенные команды установки идентичны, скачанные локальные пресеты совпадают побайтно.
- Переключение EN → RU → EN работает без JavaScript. При русском языке браузера корень по умолчанию остаётся английским; автоматического перенаправления нет.
- Во время этих проверок не обнаружены ошибки браузера, ошибочные HTTP-ответы или сетевые запросы с ответами формы.

Это обновление исходников и лендинга, без нового релиза скиллов или изменения runtime. Tag `v0.1.0-alpha.1` по-прежнему указывает на distribution commit [`db03ebc`](https://github.com/warbr1ng3r/tibicen/tree/db03ebc988af1e38ea9f62c02027945ba40660fc); release assets сохранены. Проверки публикации не расширяют подтверждённый охват агентов/платформ и не доказывают пользу людям.
