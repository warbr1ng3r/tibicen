## Ревью и исправления

Независимые Ponytail-ревью охватили сравнение результатов, границу предложения/
согласия и сохранённые свидетельства. Root отклонил широкий фильтр исполнителя:
он скрывал изменённые длительности в утверждениях и названиях тестов. Регрессия
упала до исправления. Нормализация ограничена распознанными записями раннера;
добавлены реальные провальные запуски Node TAP/spec через общую точку записи.
Ревью также нашло существующий пропуск разных exit code; второй красный тест
предшествовал исправлению сравнения.

Guidance выбирает фактический поддержанный профиль вместо общего `web`, задаёт
предлагаемое доверие без утверждения прежнего согласия и требует проверенной
готовности. Опросник исполнителя, сгенерированный ответ, значение по умолчанию
и разрешение инструмента не являются внешним ответом о согласии. CLI не
удостоверяет личность: это уточнение инструкции, а не техническая проверка автора.

Сфокусированный набор сравнения/записи прошёл **19/19**. Три независимых ревью
приняли исполнение, guidance и оценку свидетельств. Итоговый `pnpm test` завершился
с кодом 0: **1 187 всего / 1 185 passed / 0 failed / 2 прежних skip**,
включая lint, форматирование, типы, сборку сайта, строгую OpenSpec-валидацию
(48 активных пунктов и 20 архивов) и offline-тесты. Поведение сайта не менялось.

Вторая сборка вне checkout побайтово совпала со сборкой gate: **114 хэшей
полезной нагрузки / 115 файлов всего** с манифестом. Оба standalone self-test
ресурсов прошли с отдельным HOME, пустым PATH и рабочей папкой вне checkout.
Обе копии изменённых runtime/reference совпадают с root. SHA-256 SHA256SUMS:
`ccf1ba121bcafd4e59a9303d2b924d73cdb1cdf833be8f5724e4925193d7e611`.
Это невыпущенная интеграционная сборка, отдельная от candidate-02 исполнителя.
Финальный guard исходного пакета также прошёл: 151 замороженный вход, 2 000
базовых файлов, 114 payload / 115 файлов архива. Хэши журналов и исходников
индексированы в receipt оценки; сырые приватные потоки в репозиторий не перенесены.

## Границы свидетельств

Сохранены green/complete manifest RET1 и совпадающий установленный guidance,
но первое предложение и журнал согласия отсутствуют. Нового поведенческого
прогона для root-текста не было. Пять ранних нарушений согласия остаются
нарушениями; сообщённое позднее соблюдение их не отменяет. Автозагрузка,
человеческое согласие, причинная польза памяти, пропущенные варианты каталога
и Windows-политика этой локальной проверкой не подтверждаются.

Версия остаётся 1.7.0. Коммитов, push, тегов, публикации, выкладки и платных API
в интеграции нет. OpenSpec остаётся инструментом разработки и не включается
как зависимость поставляемых скиллов.
