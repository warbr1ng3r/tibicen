## Codex integration review

Дополнительно воспроизведены и исправлены два дефекта:

1. Существующий привязанный файл `--version` с телом `exit 73` превращался в опцию Bash: два запуска возвращали 0, файл не выполнялся, сравнение давало ложный `green`. Compiled argv теперь содержит явный файловый аргумент `./--version`, который требует runtime-валидация. Регрессия также проверяет файл Node с именем `inspect`: оба настоящих файла возвращают 73 и сравниваются как `pre-existing-red`.
2. Абсолютный executable внутри исходного проекта запускал оригинальный файл, хотя cwd был временной копией. Обычная запись рядом с `$0` меняла исходную фикстуру. Общая проверка при компиляции и исполнении теперь отклоняет такой путь и внешние ссылки на него; положительный сценарий с привязанным `./`-входом работает в копии и сохраняет оригинал.

Также исправлены Windows-условия новых тестов; отдельный тест симулирует отказ исполнения для всех трёх профилей. Тип входного proposal допускает отсутствие hash, который вычисляет CLI; compiled command по-прежнему требует hash. Трекер, roadmap и обзор возможностей обновлены в обеих языковых версиях с явной пометкой Unreleased.

- Воспроизведения до исправления: inline-написания `node -p`/`python3 -Ic` компилировались в профилях `docs`/`python`; привязка `script` компилировалась в web-профиле; wrapper вроде `/bin/echo` принимал файл-аргумент с привязкой; обрезанный `~/.tibicen/usage.json` ломал завершённое применение с `invalid-data`, оставляя сессию `incomplete`. После исправления все четыре случая отказывают или завершаются корректно, позитивные сценарии (привязанные `./`-скрипты, `python3 -m unittest`) не изменились.
- Отказы без побочных эффектов сохранены: apply с неверным digest (`consent-required`), изменение байтов после согласия (`stale-plan`), правка памяти без привязки хранилища (`application-protected`).
- Полный gate `pnpm test`, `pnpm build`, хэши автономной поставки и оба изолированных self-test вне checkout выполнены заново на исправленном дереве; worktree остаётся незакоммиченным для интеграции Codex. Опубликованные байты 1.5.6 не менялись; модельных прогонов, платных API, коммитов, push, смены версии или публикации в пакете нет.

Правило поднято на все команды build/test/lint с именем executable из закреплённого набора, bare или абсолютное; ревьюер независимо воспроизвёл матрицу отказов (inline-написания отказывают во всех формах, `-m`-модули и привязанные `./`-скрипты компилируются) и принял закрытие.
