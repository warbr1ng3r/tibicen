# Proposal

## Why

Согласованный сайт Cloudflare уже публикуется автоматически. Второй полный лендинг на ручном GitHub Pages создаёт разные публичные точки входа. Владелец согласовал основной сайт Cloudflare с сохранением прежнего адреса контрольных сумм.

## What Changes

- Использовать tibicen.pages.dev в актуальных ссылках, homepage пакета и метаданных обычной статической сборки.
- Заменить четыре маршрута GitHub Pages небольшими статическими перенаправлениями с сохранением языка и типа страницы, видимой ссылкой и работой без JavaScript.
- Сохранить maintenance/index.json по старому адресу побайтно равным каноническому исходнику; не переносить channel и не переписывать релизные записи.
- Ручной workflow GitHub Pages публикует только перенаправления и индекс. Автодеплой Cloudflare сохраняется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `landing-experience`: один основной публичный origin, сохранение старых входов и адреса контрольных сумм.

## Impact

Метаданные/config лендинга, homepage пакета, парные актуальные инструкции, статический HTML, workflow GitHub Pages и отдельные тесты. Скиллы/runtime, версия, платные сервисы и аккаунты не меняются. Публикация согласована; для новых коммитов нужно явное разрешение, поскольку прежнее охватывало только два файла автодеплоя.
