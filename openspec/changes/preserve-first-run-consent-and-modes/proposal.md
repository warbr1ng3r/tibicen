# Proposal

## Why

The closed first-run observation exposed ambiguous consent wording for generated journals and a confirmed evaluator defect: restaging normalized approved 0600 files to 0644. Clarify the existing approval contract and preserve ordinary file modes so future observations can assess the actual setup.

## What Changes

- Distinguish exact user-file diffs from bounded generated service records; obtain explicit clarification when a user requires unavailable future bytes and retain the unchanged CLI application path.
- Add optional per-file permissions to the contained evaluator input, defaulting to 0644, validated before launch and included in the existing input freeze.
- Carry collected permissions through the maintained setup continuation and independent check; preserve existing path, privacy, execution and cleanup boundaries.
- Add offline regressions and independent review. Preserve all closed observations and published 1.5.0; no model rerun, commit or publication is selected.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `agent-infrastructure-lifecycle`: make consent presentation for generated service records explicit without weakening exact-plan approval.
- `evaluation-results`: preserve declared ordinary file modes through contained restaging, freeze and reconciliation.
