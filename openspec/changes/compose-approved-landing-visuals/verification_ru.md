# Проверка — согласованная композиция лендинга

Согласованная композиция A/C/B реализована на обоих языках: статичное дерево примера, короткий диалог с запросом и предложением, отдельная схема границ настройки перед FAQ. Иконка `.tibicen/` — папка с часами справа внизу. Память, скиллы и подключения необязательны. Полные примеры init/adopt сохранены в изначально закрытом нативном раскрывающемся блоке, включая работу без JavaScript.

Браузерные проверки охватывают раскрытие и выбор кейса с клавиатуры без JavaScript, ширины 280/320/390 пикселей, интерактивные цели 44 пикселя, буфер обмена и переносы. Просмотрены реальные скриншоты EN/RU. Первая новая проверка на 280 пикселях обнаружила высоту hero 361 пиксель; декоративные отступы исправлены до успешного финального прогона. Также исправлены переносы русских названий модулей на узком экране. Ревью удалило устаревшее описание переключателей из Unreleased; опубликованные разделы changelog сохранены.
