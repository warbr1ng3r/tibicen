# Spec Delta

## ADDED Requirements

### Requirement: Distinct truthful illustration roles

The bilingual landing SHALL use a rich static hero example, a short ordinary-request/proposal conversation and a separate setup-boundary diagram. Optional memory, skills and connections SHALL be explicit. Example paths SHALL NOT imply universal output. The `.tibicen/` example SHALL use a folder with a lower-right clock marker.

#### Scenario: A visitor scans the page

- **WHEN** either language landing is opened
- **THEN** the hero shows one possible setup without stage controls, the workflow shows a request and proposal, and the boundary diagram precedes FAQ
- **AND** installation/preset behavior is preserved and prototype controls are absent

#### Scenario: A visitor needs the complete example

- **WHEN** the visitor opens the native details under the short workflow, including without JavaScript
- **THEN** both existing init/adopt cases remain selectable with their starting state, exact proposed diff, approval, result and preservation limits
- **AND** the examples remain labeled illustrative rather than recorded success

#### Scenario: A visitor uses a narrow screen or keyboard

- **WHEN** the visitor views either language at 280/320/390 CSS pixels or navigates by keyboard
- **THEN** illustrations and controls reflow without horizontal overflow or clipped labels, the hero stays compact, and native disclosure/example selection remains usable
