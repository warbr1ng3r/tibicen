# Design

## Context

См. [proposal](proposal.md). Владелец утвердил частный макет D и иконку папки с часами. В Astro уже есть общая локализация и нативный выбор init/adopt. Прототип задаёт внешний вид, его код не переносится напрямую.

## Goals / Non-Goals

**Goals:** статическая двуязычная композиция, целостные небольшие компоненты, сохранённые примеры и компактный мобильный блок.

**Non-Goals:** состояние браузера, новая зависимость, выпуск скиллов, изменение установки/пресета, скрипты прототипа и параллельный native-eval.

## Decisions

- Переписать ProjectPreview и удалить старые радио-стадии/CSS; необязательные элементы без фиксированных путей памяти/скиллов.
- Небольшие Astro-компоненты диалога/границ, если это сохраняет целостность разметки; совместно использовать только необходимую повторяющуюся геометрию папки/часов, без общего пакета иконок.
- Текущие данные и нативные контролы InteractionExamples сохранить внутри закрытого details под коротким процессом. Упрощённый mock потерял бы важные подробности.
- В нижних B/C убрать повтор заголовка проекта и списков необязательных компонентов. Порядок установки, FAQ и пресета сохраняется.
- Проверять существующими pnpm-командами: EN/RU, no-JS раскрытие/выбор примера, копирование и reflow; добавить осмысленную регрессию на изменённое поведение.

## Risks / Trade-offs

- Высота наполненного блока → сохранить проверку мобильной компактности, не уменьшать области интерактивных элементов.
- Подробности скрыты → нативное раскрытие клавиатурой и понятная локальная подпись.
- Пути примера принимают за гарантию → метка примера и явно необязательная группа.

## Migration Plan

Изменение сайта после ревью/проверок; приватная история не входит в публичную копию. Точный source CI, единственная выкладка Pages, проверка deployment и полученных файлов. Откат — последующая правка исходников/сайта; опубликованные скиллы 1.5.2 и неизменяемые файлы выпуска сохраняются.

Перевод delta хранится как `spec_ru.md` в корне change: CLI допускает в папках delta только канонический `spec.md`.
