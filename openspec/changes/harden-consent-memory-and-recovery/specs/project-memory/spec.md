## ADDED Requirements

### Requirement: Durable owner decisions remain outside replaceable setup policy

Setup guidance SHALL keep project-owned decisions and rules outside replaceable Tibicen policy blocks. A mixed existing block SHALL require an explicit reviewed repair preserving owner text before policy replacement or removal. One selected memory store SHALL remain user-owned, with unrelated notes and competing unselected files preserved.

#### Scenario: A previous setup mixed owner decisions and generic policy

- **WHEN** adopt finds owner sections inside a replaceable block
- **THEN** it proposes an exact repair moving those sections outside the block with their content preserved
- **AND** later policy replacement or removal preserves those sections and the selected memory notes

### Requirement: Memory handoff uses an explicit applicable reading route

Guidance SHALL connect the selected memory from the applicable host instruction entrypoint when supported. Unknown discovery or unsupported native writes SHALL retain an explicit read fallback and its assistance limit. Agent-initiated host-native memory writes SHALL wait for exact consent and SHALL NOT silently substitute for the approved store. Automatic host persistence SHALL remain an explicit external control limitation.

#### Scenario: A host entrypoint cannot be written by the supported runtime

- **WHEN** the host uses a native file outside Tibicen's supported write scope
- **THEN** the recommendation uses an approved supported common instruction file with an exact explicit reading step, or discloses the unavailable connection
- **AND** structural presence does not establish native discovery, actual reading or fresh task use

#### Scenario: Native memory is available during research

- **WHEN** an agent can write a harness-native memory file before the project proposal is approved
- **THEN** setup remains read-only and retains the selected portable store in the proposal
- **AND** host memory is neither a competing store nor a substitute for the approved connection
