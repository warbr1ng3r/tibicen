## ADDED Requirements

### Requirement: Explicit pinned sources have a read-only CLI check
Tibicen SHALL предоставлять `source-check --input FILE_OR_STDIN_DASH` для проверки массива закреплённых источников по действующим правилам происхождения, состава, лицензии и блоклиста. Команда SHALL возвращать компактные проверенные сведения либо структурированный отказ без изменения проекта и пользовательского профиля.

#### Scenario: A named source is already selected
- **WHEN** repo, полный SHA и выбранные файлы известны и переданы JSON-массивом через stdin либо файл
- **THEN** команда проверяет этот точный источник и возвращает сведения о происхождении и лицензии
- **AND** инструкция агента направляет его к этой проверке без обязательного поиска кандидатов
- **AND** проект, state, manifest, usage и пользовательский cache остаются без записей

#### Scenario: A selected source is ineligible
- **WHEN** выбранный hash не совпадает, файл отсутствует, лицензия не подтверждена либо repo/SHA заблокирован
- **THEN** команда возвращает структурированный отказ существующего валидатора
- **AND** отказ поиска или локальные байты не превращают источник в проверенный

#### Scenario: Input is invalid or the source is unavailable
- **WHEN** вход не является допустимыми данными источников, опция не поддержана либо источник недоступен
- **THEN** команда сообщает структурированную ошибку без записи и скрытой установки

#### Scenario: A checked source is later installed
- **WHEN** после положительной проверки пользователь согласовал точный план
- **THEN** применение повторно проверяет допуск источника и актуальный блоклист
- **AND** прежний результат source-check не заменяет согласие и проверку при записи
