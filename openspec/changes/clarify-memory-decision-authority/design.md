# Design

## Context

The returned project still produces `0.00 EUR` from the shared zero-price formatter while a receipt line uses the owner-selected wording. Memory was then annotated with a receipt-only exception. Root can reproduce the failed functional result and inspect exact files; exported worker tool events and model routing are unavailable.

## Goals / Non-Goals

Clarify the short policy that survives after Tibicen is removed. Preserve ordinary authorized updates to verified facts and explicit user corrections. Do not build a memory service, semantic validator or new approval gate for every note; do not claim text can enforce model compliance.

## Decisions

1. Add the owner-authority boundary to all three copyable policy variants, rather than only to a guide a later worker will not have. Test their content and keep the existing proposal-compilation check.
2. Retain the memory-only fixture and scorer unchanged. An instruction containing the distinguishing answer cannot identify causal memory use. A separately frozen combined-use study can be useful, but is a different question, not permission to bypass the stopped packet's admission rule.
3. Assess mechanics and behavior separately. The no-op adopt driver actually compiled and applied a zero-change plan, updating service history; it is not a native no-proposal/no-session observation. A file's beforeHash supports CLI reading, not worker comprehension.
4. Keep failed and refused attempts. Reinstantiation under disposable HOME changed usageFile/digest and required another synthetic controller approval; successful returned CLI JSON is not an exported native tool trace.

## Risks / Trade-offs

- Stronger wording may still be ignored → report the change as guidance only until a separately admitted GLM observation is available.
- A verified fact could be mistaken for a user correction → explicitly preserve owner meaning while recording the mismatch separately; authorized explicit correction still replaces a decision.
- Historical grades could be diluted → preserve the original failed functional result and the strict memory-only admission refusal.
