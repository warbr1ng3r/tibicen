# Design

## Context

Общий форматтер возвращает для нуля `0.00 EUR`, а строка чека — выбранный владельцем текст. Агент затем добавил в память исключение «только для строк чека». Root воспроизводит функциональный провал и проверяет файлы; экспорт tool-событий и маршрутизация модели рабочих сессий недоступны.

## Goals / Non-Goals

Уточнить короткую политику, остающуюся после удаления Tibicen. Сохранить обычное разрешённое обновление фактов и явных пользовательских исправлений. Не создавать сервис памяти, семантический валидатор или одобрение каждой заметки; текст не принуждает модель к соблюдению правил.

## Decisions

1. Граница полномочий входит во все три копируемых варианта политики. Контракт текста проверяется вместе с прежней проверкой компиляции proposal.
2. Фикстура и scorer memory-only неизменны. Ответ в инструкции не позволяет доказать причинное использование памяти. Смешанное использование — отдельный заранее зафиксированный протокол, а не обход остановленного пакета.
3. Механика отделена от поведения: no-op driver создал и применил пустой план, изменив служебную историю. beforeHash доказывает чтение CLI, а не понимание агентом.
4. Прежние неудачи сохраняются. При смене disposable HOME изменились usageFile/digest и потребовалось новое синтетическое согласие. Возвращённый JSON не равен экспортированной нативной трассе.

## Risks / Trade-offs

- Модель может проигнорировать уточнение → это изменение инструкции, а не новый поведенческий успех.
- Факт реализации можно принять за изменение решения → смысл владельца сохраняется, расхождение записывается отдельно; явное исправление пользователя остаётся допустимым.
- Оценку можно ослабить задним числом → функциональный failed и отказ допуска memory-only сохраняются.
