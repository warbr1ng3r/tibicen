# Инструкции для разработки

- Используйте pnpm 11.21.0, закреплённый в package.json, с pnpm-lock.yaml и скриптами репозитория.
- Границы продукта и MVP описаны в docs/PRODUCT_VISION.md; прочитайте этот документ.
- Для существенных изменений поведения используйте OpenSpec: храните требования, сценарии и задачи вместе с изменением. Небольшие текстовые и CSS-правки можно выполнять напрямую.
- Ведите порядок этапов в docs/DEVELOPMENT_PLAN.md, если файл существует; не дублируйте там подробные задачи изменений.
- Архивные изменения с пометкой retrospective считайте восстановленными записями, а не доказательством прежнего согласования или исполнения.
- Создавайте коммиты и переписывайте историю только по явному поручению пользователя.
- OpenSpec и сгенерированные им скиллы разработки не должны становиться зависимостями распространяемых скиллов Tibicen.
- Для выбора тикетов, параллельной работы и интеграции прочитайте docs/agents/issue-tracker.md и связанное текущее усилие.
- При изменениях документации проекта следуйте языковым правилам и соглашению о переводах в CONTRIBUTING.md.
