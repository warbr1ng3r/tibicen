# Project decisions

- **OpenSpec.** Integrate OpenSpec into a user project only when it fits the request and the owner approves it. See [project scope](../docs/PRODUCT_VISION.md#13-target-product-first-release-and-implementation-order).
- **Releases.** When closing an owner-authorized stable release, verify the public assets before updating both skills in the maintainer's working Codex. Follow the [release checklist](../docs/RELEASING.md#maintainers-working-codex-installation) for the exact distribution SHA, backup, checks and installation receipt.
