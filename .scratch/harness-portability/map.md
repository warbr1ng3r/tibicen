# Harness and model portability

Labels: wayfinder:map
Status: resolved
Assignee: none

## Destination

The owner clarified that a descriptive catalog alone does not achieve the goal:
Tibicen must serve the diversity of harnesses and LLMs, without making Codex,
Claude Code and Cursor the product's entry gate. Keep Tibicen a temporary setup
utility inside the user's existing agent, with two skills and approved exact
changes. A harness, provider and model are different facts. Do not build a new
agent runtime or require new provider credentials to configure a project.

## Decisions so far

- The three read-only audits are complete. The smallest real route reuses brandless AGENTS setup and the explicit universal installer, accepts valid unknown hints, and keeps model/provider choice in the caller host. Native formats and automatic probes remain separate supported operations.
- The [change](../../openspec/changes/archive/2026-11-05-enable-harness-independent-workflow/proposal.md) has complete English planning artifacts and passes strict validation. Independent plan review is Ship after the ownership correction; translations and exact manual-route acceptance are complete. Three disjoint implementation lanes are complete; root integration and independent reviews are complete.

- The 13-profile feature is committed/pushed as public `93d9305`; normal CI passed.
  It remains useful evidence/catalog groundwork, not universal native support.
- Candidate-01 for intended 1.3.0 is retained as an intermediate unpublished
  snapshot. Its local gate/build, 94-payload standalone and three-target local
  delivery checks passed. H01/H02 were prepared/reviewed but never dispatched;
  both remain unconsumed after this scope correction. No release is inferred.
- The remaining file-write, shared-rule, installer and automated-probe restrictions
  need separate investigation. Existing exact consent, secret/path, application
  preservation and startup/auth controls remain requirements.
- Use [OpenSpec](../../openspec/) for the resulting substantial change. This map
