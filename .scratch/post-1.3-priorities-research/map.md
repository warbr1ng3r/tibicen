Labels: wayfinder:map

## Destination

Test the proposed next workfronts against fresh internet research and the actual
published 1.3 baseline. Produce an evidence-backed ranked recommendation with
concrete cases, existing alternatives, uncertainty and limits. Research only.

## Notes

The owner explicitly requested fresh research after asking where the earlier
recommendations came from. Three agents own disjoint source lanes; root owns
baseline, independent counterevidence and synthesis. Use the research skill.
Existing studies are history, never relabeled as newly discovered demand.
Forum anecdotes, vendor descriptions and observed benchmark outcomes have
different evidential roles. No population-frequency, willingness-to-pay or
Tibicen-benefit claim follows from source counts.

## Decisions so far

- The baseline is published 1.3.0, not the dated 1.1 snapshot. Memory, adopt
  diagnosis, bounded version-aware guidance and universal installation already
  exist. New research does not reopen completed release gates.


- [Context and memory](issues/01-context-memory.md): scope-specific explanation
  and native inspection merit comparison; a universal graph is not justified.
- [Integrations](issues/02-integrations.md): version/scope-aware local stdio
  repair is a concrete candidate; existing native remedies and status matter.
- [Reuse and updates](issues/03-reuse-updates.md): preserve ownership and current
  decisions; a new setup manifest has no established incremental value yet.
- [Synthesis](issues/00-synthesis.md): paired findings and focused evidence review
  complete. Six EN/RU pairs, 112 local Markdown destinations and whitespace checked;
  no implementation, native/model calls, paid API, commit or publication.


Repository Prettier configuration excludes Markdown, so its invocation did not
rewrite these documents. Local-link, pair/status and whitespace checks above
are the actual validation; no runtime test suite was run for this research.


## Out of scope

Implementation, a new release, credentials, paid API, live trials, automatic
updates, installs, personal data collection, recruitment and public messages.
